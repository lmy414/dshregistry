dsh-ai-image-design

DSH（DeepSeek Harness）技能插件：AI 图像生成工作流。

提示词质量规则（50-150 词/自包含/真正不同）、风格指南（写实/动漫/插画）、批量与派生提示词（并行概念/串行-并行/A-B 变体）、参考图库研究与品牌一致性、审校迭代。受 wshobson/agents 的 meigen-ai-design（38k★ MIT）启发的中文原创精简版。

安装

dsh plugin add dsh-ai-image-design

触发方式

描述中包含"AI 生图 / 图像提示词 / logo 概念 / 批量产图 / 品牌视觉 / 图片风格"等关键词时自动触发。

能力

  • 提示词质量三规则
  • 三种风格指南（写实/动漫/插画）
  • 并行/派生/A-B 批量工作流
  • 品牌一致性与审校迭代
