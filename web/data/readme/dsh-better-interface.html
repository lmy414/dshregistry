dsh-better-interface

DSH（DeepSeek Harness）技能插件：界面质量技能系列。

六大维度技能（UI 细节/排版/颜色/可访问性/布局/产品写作）+ 三个元技能：better-interface 跨学科评审、variant（一版 UI 生成多个真正不同的变体+选择器实测）、explain-interface（给 URL/截图逆向解释效果与最小重建）、interface-review（对改动/分支/PR 跑全维度评审）。受 jakubkrehel/skills（3.9k★）启发的中文原创精简版。

安装

dsh plugin add dsh-better-interface

触发方式

描述中包含"打磨界面 / 界面评审 / 多版本变体 / 这个效果怎么做的 / 排版配色 / UX 文案"等关键词时自动触发。

能力

  • 六维度界面打磨（UI/排版/颜色/可访问性/布局/写作）
  • variant 多版本实测
  • explain-interface 逆向解释
  • interface-review 全维度评审
  • 对比度/焦点态/键盘支持达标
