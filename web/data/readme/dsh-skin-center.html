dsh-skin-center | DeepSeek Harness 皮肤中心(官方插件)

给 DeepSeek Harness 换肤的官方插件:一行命令安装,不改宿主源码,npx 用户可用。

35 套内置皮肤(含 14 套开发者经典配色)+ 一张图自定义 + 皮肤包导入/导出,多标签实时同步,首屏零闪屏。

An out-of-tree plugin bundle for DeepSeek Harness: 21 built-in skins plus one-image custom themes. One command to install, zero host source patches.

快速开始

要求:DeepSeek Harness 0.1.0-rc.6 及以上、机器上有 pnpm。

dsh plugin --profile web add dsh-skin-center
dsh web

没有全局 dsh 命令就先 npx @deepseek-ai/dsh@latest,或把第一行换成 npx @deepseek-ai/dsh plugin --profile web add dsh-skin-center。装完打开 http://127.0.0.1:3080,设置 → 通用设置 → 皮肤,点一下就换。

升级与卸载同样一行:

dsh plugin --profile web update dsh-skin-center   # 升级
dsh plugin --profile web remove dsh-skin-center   # 卸载(选择与自定义图保留在 ~/.dsh/skins/)

功能

  • 加法安装:官方外观行(浅色/深色/跟随系统)原样保留,皮肤行出现在它下面;默认「默认」,装完不改变任何现有外观。
  • 零宿主源码改动:不覆盖任何宿主文件、不打源码补丁。界面钩子(消息气泡、会话面板、视图页签、主按钮、详情栏、应用框架)由插件在浏览器运行时盖章;宿主升级最坏情况是个别效果暂时退化为纯换肤,不会装不上。
  • 35 套皮肤:ACG 系(QQ 怀旧、初音、原神、火影等 21 套,源自上游项目)+ 开发者经典 14 套(Gruvbox、Nord、Dracula、Tokyo Night、Solarized、One Dark/Light、Rosé Pine、Catppuccin——全部为开源配色)。
  • 皮肤包导入/导出:一个 JSON 就是一套皮肤(四色种 + 外观 + 边框),导入即用、导出即分享——社区可以互相传皮肤包。
  • 一张图自定义:传一张自己的图,取色派生全自动。
  • 首屏零闪屏:换肤选择持久化在 ~/.dsh/skins/selection.json,Host 在 HTML 里内联首屏配色与属性。
  • 多标签同步:BroadcastChannel,一个标签换肤,所有标签实时跟随。
  • QQ/XP 标题栏:chrome 皮肤激活时出现,可收起、可开合侧栏。

它长这样

侧栏、输入框、会话列表都是 DSH 原生控件,功能一点没动。

皮肤选择器 自定义(选图)

用一张图做你自己的皮肤

皮肤选择器的第一项就是「自定义(选图)」,选一张 PNG、JPG 或 WebP,剩下的全自动:浏览器本地 96px 采样取色、按画面明暗自动调蒙版浓度保证文字可读、1920px 长边重编码成 WebP 按内容哈希存进 ~/.dsh/skins/。原图不出本机,上传只走同一台机器上的 DSH Host。

皮肤是怎么实现的

一套皮肤 = 一份 JSON(四个色种 + 外观 + 边框风格)。构建期从色种保对比度推导出完整色阶(OKLab 空间计算,保持与原生色板每级的对比关系),21 套 × 8 项对比度契约不达标直接构建失败;所有规则收口在 body[data-dsh-skin] 属性下,切回「默认」即刻还原、零残留;背景层固定视口,开会话、滚长对话、开合侧栏都不动。

想加皮肤:往 src/styles/skins/themes/ 扔一份 JSON,跑 npm run build:skins && npm run build。

插件架构三件事:

  1. 宿主半(Node):注册皮肤 CSS / 背景图 / 选择读写 / 更新检查四组路由,并在 index HTML 里内联首屏配色(tapIndex,先于任何 JS)。
  2. 浏览器半:__ModuleLoader__ 包裹的 CJS bundle,经官方浏览器名册(/plugins/<id>/client.js)加载;负责设置行(settings.general.item 插槽)、DOM 盖章、标题栏 DOM 岛与跨标签广播。
  3. 持久化:自有文件 ~/.dsh/skins/selection.json(宿主的浏览器 settings RPC 目前对第三方命名空间白名单关闭,插件自带状态通道)。

版本与更新检查

设置面板底部显示「皮肤系统 vX.Y.Z · DSH <宿主版本>」,「检查更新」由 Host 侧代理请求 GitHub Releases(浏览器不直连第三方);发现新版时按钮变为「复制更新指令」,粘出来就是一条 dsh plugin --profile web update dsh-skin-center。

从源码构建

npm install       # esbuild 等构建依赖
npm run build     # → lib/(宿主半 ESM + 浏览器半包裹 bundle + 拍平的 skins.css)
npm run build:skins  # 改了 themes/*.json 后重新生成

本地试装:dsh plugin --profile web add file:$(pwd)。
