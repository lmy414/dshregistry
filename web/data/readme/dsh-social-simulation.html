dsh-social-simulation

DSH（DeepSeek Harness）技能插件：百万 agent 社交模拟。

可扩展的开源社媒模拟器：LLM agent 逼真模仿 Twitter/Reddit 上多达一百万用户——23 种动作（follow/comment/repost）、兴趣与热度推荐算法、动态环境实时适配；研究信息传播、群体极化、羊群行为等复杂社会现象。受 camel-ai/oasis（5k★）启发的中文原创精简版。

安装

dsh plugin add dsh-social-simulation

触发方式

描述中包含"社交模拟 / 百万 agent / 信息传播研究 / 群体极化 / 羊群行为 / 内容传播测试"等关键词时自动触发。

能力

  • 百万 agent 规模模拟
  • 23 种动作空间
  • 兴趣/热度推荐算法
  • 动态环境实时适配
  • 社会现象研究（传播/极化/羊群）
  • 交互数据收集
