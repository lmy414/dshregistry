DSH Plugin: UI Session Archive

中文 | English

为 DeepSeek Harness 网页版提供会话归档与还原管理功能，让你把暂时不用的会话从主侧边栏隐藏归档，并在底部的折叠列表中随时查看历史与一键还原。

适用人群与场景

适合日常对话较多、希望保持侧边栏干净清爽，同时又需要完整保留历史会话以便随时回溯和恢复的开发者与用户。

核心特性

  • 一键归档与还原：在会话操作菜单中一键归档；在侧边栏底部折叠面板中一键还原到原工作区。
  • 纯插件化 Slot 挂载：通过 sidebar.workspaces.archive 动态注入，卸载插件后不留任何多余 UI DOM。
  • 无损生命周期保障：归档仅在活动列表中隐藏会话，不删除任何底层的会话日志或上下文数据。
  • 历史随时可读：即使处于已归档状态，依然可以直接点击打开并查看历史对话记录。

极简安装与使用

请把经过评审的提交安装进 Web profile。仓库自带 dsh.bundle 配置和预构建运行文件，通过 Git 安装无需在本地执行构建：

dsh plugin --profile web add github:OpenSaozi/dsh-session-archive#<commit-sha>

安装后刷新页面，左侧边栏底部会自动出现“已归档会话 (n)”折叠区域。

兼容性说明

本插件要求 DeepSeek Harness 中的 @deepseek-ai/dsh-client-ui-workspace 包已声明 sidebar.workspaces.archive 子 Slot。

存储与隐私安全

插件仅调用宿主提供的注册表级归档接口，不独立持久化任何提示词、模型回复或敏感凭据。

模型体验

请求上下文与条件

模型看到的内容

无。归档与还原操作不向模型发送任何额外提示词、消息、工具定义或请求字段。

Token 影响

直接 token 数为零。

KV Cache 影响

无；归档与还原操作不会发起或改变模型推理请求。

已知限制与暂缓事项

  • 仅限文字与标准会话展示——归档面板主要用于会话的查看与还原，不在归档列表内部直接提供重命名等复杂管理动作。
