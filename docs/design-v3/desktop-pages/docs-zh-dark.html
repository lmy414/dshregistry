关于本站

dshregistry 是一个社区驱动的 DSH 插件搜索引擎。我们的爬虫自动扫描 GitHub、dshfind 与 DSH Hub 上带有 dsh-plugin 标识的开源仓库，提取元数据并建立倒排索引，方便用户快速检索和发现可用的 DSH 插件。

本站仅存储插件的元数据信息（名称、描述、作者、Stars 等），不镜像或托管任何插件代码。所有插件的源码均存储在其各自的源仓库中。数据每 6 小时自动同步一次。

提交插件

想要让你的 DSH 插件被 dshregistry 收录？有两种方式：

  1. 1
    给你的 GitHub 仓库添加 dsh-plugin topic
  2. 2
    （推荐）在 package.json 中声明 dsh.registry 元数据字段，便于爬虫提取更完整的信息
  3. 3
    爬虫每 6 小时自动扫描一次，符合条件的仓库会在下次同步时自动收录
也可以通过 GitHub Issue 主动提交，附带上你的仓库链接和简要说明。

数据 API

dshregistry 是纯静态站点，所有数据以 JSON 形式公开，可自由调用。

/data/plugins.json # 全部插件索引 /data/search.json # 搜索索引（倒排） /data/trending.json # 24小时增长榜 /data/plugin/:name.json # 单个插件详情

API 为静态文件，无速率限制，但请合理使用。
