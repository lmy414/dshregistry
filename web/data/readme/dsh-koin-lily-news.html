技术架构

  • 平台：DeepSeek Harness（DSH）Web —— 正式插件（非动态插件）
  • Host 半段：koinNews Remote 服务（koinNews/load search progress images）+ koin_research 工具
  • Client 半段：conversation.view「百合资讯」标签页
  • 依赖能力：web（搜索）、llm + agentDefaultModel（AI 提炼）、slots/timer/connection（页面）。均为 DSH 标准组件，开箱即用；shell 缺席时自动降级为仅 web.fetch 抓图。

安装

方式一：dsh plugin（推荐，自动注册 bundle 层）

# GitHub 安装（仓库内 package.json 位于仓库根目录）
dsh plugin --profile web add github:<你的用户名>/dsh-koin-lily-news

# 或 npm 安装（发布到 npm 后）
dsh plugin --profile web add dsh-koin-lily-news

安装完成后 重启 DeepSeek Harness（组合在启动时加载）。

方式二：手动安装（不依赖 pnpm）

  1. 把本目录复制（或 junction 链接）到 profile 的 node_modules：

    • Windows：C:\Users\<你>\.dsh\profiles\web\node_modules\dsh-koin-lily-news
    • Linux/macOS：~/.dsh/profiles/web/node_modules/dsh-koin-lily-news

  2. 在 C:\Users\<你>\.dsh\profiles\web\cordis.patch.yml 追加：

    - insert:
    - id: dsh-koin-lily-news
      name: 'dsh-koin-lily-news'

  3. 重启 DeepSeek Harness。

说明：profile 安装的插件通过 $DSH_HOME/profiles/node_modules 的自动愈合链接 解析 @deepseek-ai/* 运行时依赖（与官方插件一致），无需自行安装这些包。

使用

  • 会话标题栏点击 「百合资讯」 标签；输入番名回车即搜；「↻ 强制刷新」重新联网。
  • 对话中直接说“查一下 XX 的最新进度”，AI 会调用 koin_research 工具。

开发

  • lib/index.js（Host，ESM）：KoinNewsService extends TypertRemoteService， @Remote 端点经 Typert Gateway 的 SRC 标记发现（无需生成 typert manifest； 该实现以 Remote() 普通调用等价装饰器语义，兼容无装饰器语法的 Node 构建）。
  • lib/client.js（Browser）：window.__ModuleLoader__.load({ id, factory }) 单文件 bundle（DSH 浏览器模块内核格式），require 解析 react 与运行时服务。
  • 改完直接替换 lib/ 下文件即可生效（重启后），无构建步骤。

📌 使用提示

  • 💾 缓存：打开页面展示上次结果（顶部琥珀色提示），不自动重搜；
  • ↻ 刷新：「↻ 强制刷新」强制重新联网检索；
  • 🔎 换番：输入新番名回车即搜，AI 自动生成该作品别名查询计划；
  • ⚠️ 数据说明：内容来自公开网络搜索，AI 头条仅供参考，请以官方渠道为准。

🐛 已知限制

  • 部分站点反爬（manhuagui、plex 等）抓图失败，词条保持纯文字；
  • 部分搜索源混入同名词条（如「死了都要爱」歌曲），AI 头条会尽量甄别；
  • 动态插件随进程重启消失，需重新 define/run（或方式三转正式插件持久化）。
