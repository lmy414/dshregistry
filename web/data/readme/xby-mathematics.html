xby-mathematics

DeepSeek Harness (DSH) 的插件：数学计算引擎

MCP Mathematics 是一个全面的数学计算服务器，可将任何AI助手转变为强大的数学计算引擎，提供高级数学函数、单位转换和财务计算等功能。

功能

  • set_xby_apikey — 在聊天中设置 API 密钥（自动持久化，重启有效）
  • performance_metrics — Get performance metrics
  • security_status — Get security status
  • memory_statistics — Get memory statistics
  • calculate_expression — Evaluate math expression
  • batch_calculate — Batch calculate expressions
  • calculate_statistics — Calculate statistics
  • matrix_operation — Matrix operations
  • convert_units — Unit conversion
  • convert_natural_language — Natural language conversion
  • analyze_number_theory — Number theory operations
  • create_session — Create session
  • session_calculate — Session calculation
  • list_session_variables — List session variables
  • delete_session — Delete session
  • get_calculation_history — Get calculation history
  • clear_history — Clear history
  • optimize_memory — Optimize memory
  • list_functions — List functions

安装

方式一：从 GitHub 直接安装（推荐）

# 格式: dsh plugin --profile <profile> add github:<owner>/<repo>
dsh plugin --profile web add github:xby_skill/xby-mathematics

方式二：从本地目录安装（开发模式）

# 仅用于本地开发调试
dsh plugin --profile web add /absolute/path/to/xby-mathematics

方式三：通过 cordis.patch.yml 开发调试

dsh web --profile web --patch /absolute/path/to/dsh-ocr-plugin/cordis.patch.yml
