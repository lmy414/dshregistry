dsh-codebase-design

DSH（DeepSeek Harness）技能插件：代码库设计（深模块）。

深模块设计：小接口 + 大实现、术语体系（module/interface/seam/adapter）、接口即契约（不变量/约束/错误模式）、调用方杠杆与维护者局部性、通过接口可测、AI 可导航性。受 mattpocock/skills 的 codebase-design（223k★ MIT）启发的中文原创精简版。

安装

dsh plugin add dsh-codebase-design

触发方式

描述中包含"深模块 / 模块设计 / 接口设计 / 接缝 / 代码库结构 / 可测试性设计"等关键词时自动触发。

能力

  • 深 vs 浅模块判断
  • 接口即契约原则
  • 接缝位置设计决策
  • 找加深机会与 AI 可导航
