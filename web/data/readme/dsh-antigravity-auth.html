Antigravity OAuth Plugin for DeepSeekHardness

[!IMPORTANT] 此插件可能违反 Google 服务条款，使用此插件即表示您已阅读并知晓以下内容：

  1. 这是一个非官方工具，未经 Google 认可
  2. 您的 Google 账号可能会被暂停或永久封禁，您须承担使用此插件的所有风险

安装

需要 DeepSeek Harness（dsh），Node 版本 ^22.19 || >=24。

dsh plugin add github:UE-DND/dsh-antigravity-auth

首次安装时 pnpm 会拒绝运行 git 依赖的 prepare 构建脚本。按 dsh 提示，在 profile 的 pnpm-workspace.yaml 中加入：

allowBuilds:
  dsh-antigravity-auth: true

然后重新执行上面的 add 命令，安装后重启 dsh web，打开 设置 后进入 Antigravity栏使用 Google 登录
