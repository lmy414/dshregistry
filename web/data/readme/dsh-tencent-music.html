:musical_note: dsh-tencent-music

DeepSeek Harness (DSH) 专属的 QQ 音乐播放器插件，支持浮动播放面板、个性化电台、歌单导入与智能体 (Agent) 语音/文本点歌。

功能特性 • 安装指南 • 配置选项 • 智能点歌

dsh-tencent-music 是一个为 DeepSeek Harness 量身定制的音乐服务插件。它通过底层对接 QQ 音乐桌面端协议，提供从搜索、播放到个性化推荐的全链路服务，并深度融合了 DSH 的 Agent 智能体工具体系，让你可以在与 AI 对话的过程中无缝享受音乐。

[!NOTE] 本插件依赖于 @deepseek-ai/cordis 与 DSH 的 Web UI 注入框架。使用前请确保你的 DSH 宿主环境版本兼容。

功能特性

  • :desktop_computer: 无缝 Web UI 集成：提供顶栏快捷唤醒入口与可折叠的浮动播放器面板，支持进度拖动、音量控制及多种循环模式。
  • :robot: Agent 智能点歌：注册了 music 智能体工具，支持用户使用自然语言控制播放器（如点歌、切歌、音量调节、开启电台）。
  • :radio: 个性化电台与推荐：内置猜你喜欢 (Guess)、雷达推荐 (Radar)、新歌首发等多种电台模式，支持播放列表的无感续拉。
  • :mag: 全方位检索与导入：支持按单曲、歌手、专辑、歌单或歌词进行深度搜索，并且可以直接通过 QQ 音乐歌单 ID 或分享链接一键导入（如输入 201 导入“我喜欢的音乐”）。
  • :level_slider: 全档位高解析音质：支持从 128k MP3、320k HQ 到 SQ 无损 (FLAC)、Hi-Res 以及臻品母带 (AI Master) 的全档位音质。
  • :closed_lock_with_key: 快捷安全登录：播放器内嵌 QQ / 微信扫码登录，持久化存储多端 OAuth 凭据，重启自动恢复会话。

[!TIP] 当遇到无权限播放的 VIP 歌曲时，系统会自动平滑降级，获取并播放 30 秒官方试听片段 (RS02)，确保播放队列不会中断。

安装指南

建议通过 DSH CLI 工具进行本地化安装与挂载：

# 在工作区执行添加插件命令
dsh plugin --profile web add ./dsh-tencent-music

安装完成后，请重新启动 dsh web 并在浏览器中刷新，即可在页面顶栏看到音乐播放器图标。

配置选项

在 DSH 的原生设置 -> QQ 音乐 面板中，你可以自定义以下行为：

  • Agent 智能体注入：动态开启或关闭 AI 智能点歌工具（即 music 工具）。
  • 默认音质偏好：可设定首选音质，包括 标准 (128k)、超清 (320k)、无损 (FLAC) 及 高解析 (Hi-Res)。
  • 默认循环模式：可选择 列表循环、单曲循环 或 随机播放。
  • 默认自定歌单 ID：配置启动时默认载入的歌单（例如使用 201 默认加载“我喜欢的音乐”）。
  • 初始启动音量：自定义默认音量。

智能点歌

通过在聊天框向 Agent 发送自然语言指令，你可以轻松操控播放器：

  • "放一首周杰伦的晴天"
  • "开启猜你喜欢电台"
  • "播放今日推荐歌曲"
  • "下一首" / "暂停" / "继续"
  • "把音量调大一点"
  • "帮我导入歌单 201"
  • "看看现在在放什么歌"
