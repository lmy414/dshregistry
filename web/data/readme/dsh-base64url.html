dsh-base64url · Base64URL 编解码

Base64URL 编解码。纯 Node 实现，零第三方运行时依赖，peer-only 依赖（随 DSH 宿主加载）。 Base64URL 编解码 — a DeepSeek Harness (dsh) plugin. Pure Node, zero runtime dependencies.

工具 Tools

  • base64url_encode
  • base64url_decode

安装 Install

dsh plugin --profile web add dsh-base64url
# 或任意 profile：dsh plugin --profile <name> add dsh-base64url
