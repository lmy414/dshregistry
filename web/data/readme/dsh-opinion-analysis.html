dsh-opinion-analysis

DSH（DeepSeek Harness）技能插件：多 Agent 舆情分析。

像聊天一样提需求，智能体自动分析国内外 30+ 社媒与数百万条大众评论：5 类专业 Agent（Query 搜索/Media 多模态/Insight 私有库/Report 报告）+ 辩论主持人，Agent"论坛"链式思维碰撞与辩论避免同质化、多模态短视频解析、公私域数据融合、交互式 HTML 报告。破信息茧房还原舆情原貌、预测走向辅助决策。受 666ghj/BettaFish（42k★）启发的中文原创精简版。

安装

dsh plugin add dsh-opinion-analysis

触发方式

描述中包含"舆情分析 / 品牌声誉 / 热点事件分析 / 大众评论 / 多 Agent 辩论 / 破信息茧房"等关键词时自动触发。

能力

  • 30+ 社媒覆盖 + 评论下钻
  • 四类 Agent + 辩论主持人
  • Agent"论坛"链式辩论协作
  • 多模态短视频解析
  • 公私域数据融合
  • 交互式 HTML 报告
