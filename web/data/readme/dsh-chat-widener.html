dsh-chat-widener

Widen the DeepSeek Harness Web UI conversation content area. The shipped chat column is 748px (--dsh-chat-content-width); this plugin overrides it — default 1200px, configurable — so messages, tables and the composer all render wider (Doubao-web-style). Pure CSS injection, no host logic, no vendor-file patching, survives dsh upgrades.

把 DeepSeek Harness Web UI 对话内容区加宽。官方对话列宽为 748px （--dsh-chat-content-width），本插件默认覆盖为 1200px（可配置）， 消息、表格与输入框一起变宽。纯 CSS 注入：无宿主逻辑、不打补丁、升级不失效。

Config / 配置

key meaning / 含义 default / 默认
width content width, px / 内容区宽度 1200

Sane range [748, 2400]; out-of-range values fall back to 1200.

Install / 安装

dsh plugin --profile web add dsh-chat-widener        # npm（发布后）
# 或本地开发: dsh plugin --profile web add link:/path/to/dsh-chat-widener
# 然后重启 dsh web

dsh plugin requires pnpm on PATH.

Tune / 调参

Edit ~/.dsh/profiles/web/cordis.patch.yml:

- id: chat-width
  name: 'dsh-chat-widener'
  config:
    width: 1400

Restart to apply. / 重启生效。

Preview without restart / 不重启预览

Paste into the browser DevTools console (Ctrl+Shift+I → Console):

const s = document.createElement('style');
s.textContent = '[data-conversation-scroll]{--dsh-chat-content-width:1200px;--dsh-composer-card-max-width:calc(var(--dsh-chat-content-width) + 32px)}[data-conversation-scroll] [class*="userStack"]{max-width:100% !important}';
document.head.append(s);

Uninstall / 卸载

dsh plugin --profile web remove dsh-chat-widener

No residue — the plugin only injects a <style> element at runtime. 无残留——插件只在运行时注入一个 <style> 元素。

Scope / 边界

This plugin's only job is the conversation content width. No buttons, no persistence, no other surfaces. / 本插件唯一职责就是对话内容宽度：不加按钮、 不持久化、不涉及其他界面。
