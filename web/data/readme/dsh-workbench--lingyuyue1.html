dsh-workbench

English | 简体中文

自包含的 DeepSeek Harness (DSH) 工作台插件：VSCode 风格右侧面板（资源管理器文件树 + 多标签文档预览），不依赖任何第三方插件。

功能

  • 资源管理器：按会话 cwd 定位的文件树，目录懒加载，点击文件即开预览；
  • 多标签预览：Markdown 渲染、代码高亮（复用官方 dsh-client-ui-primitives 的 MarkdownText / CodeBlock）、图片、HTML（沙箱 iframe）、PDF 内嵌、二进制下载兜底；
  • 🔄 刷新按钮：每个标签头部一个，一键重新读取文件——不用再「关闭 → 找文件 → 重新打开」；
  • 自动重载：面板打开期间低频轮询（2s）已打开文件的 mtime/size，外部改动自动刷新；页面隐藏时暂停；
  • 会话隔离：标签页、展开目录按会话分桶，localStorage 持久化。

安装

方式一：本地目录安装

git clone https://github.com/<you>/dsh-workbench.git
cd dsh-workbench && pnpm install && pnpm build

然后把仓库目录注册进 profile 的 cordis.patch.yml：

- insert:
    - id: workbench
      name: '/absolute/path/to/dsh-workbench'

重启 DSH，硬刷新浏览器即可。

方式二：Git 安装（构建产物已提交时）

npx -p @deepseek-ai/dsh dsh plugin --profile web add github:<you>/dsh-workbench

仓库需把 lib/ 构建产物一并提交（本仓库 .gitignore 默认忽略 lib/；走此通道请移除该忽略项并提交产物），或按官方文档提供自包含 prepare 脚本。装完重启目标 profile。

开发

pnpm install
pnpm typecheck   # tsc --noEmit
pnpm build       # tsc 声明 + tsdown（host ESM + client CJS bundle）
pnpm test        # host 半冒烟测试（围栏 / 越界 / 各 API / 沙箱 CSP）
pnpm watch       # client bundle 增量重建
pnpm deploy      # 把构建产物同步到 ~/.dsh 的本地插件目录与 web-desktop profile

client bundle 遵循 DSH 官方客户端打包约定：window.__ModuleLoader__.load({id, factory}) CJS 闭包工厂、平台模块 external、跨插件值导入纯度门禁。详见 tsdown.config.ts 注释。

架构

  • host 半（src/index.ts）：
    • POST /workbench/api/*：session.cwd / fs.tree / fs.read / fs.meta；
    • GET /workbench/file：媒体路由（HTML 响应带 content-security-policy: sandbox allow-scripts）；
    • 信任围栏：回环或受信任 Host + 同源校验；所有路径限制在会话 cwd 内。
  • client 半（src/client/）：
    • portal 挂载到 document.body，随 client fiber 卸载；
    • 对外提供 ctx.workbench.openFile(path) 服务。

已知限制（v0.1.0）

  • 只读预览：不含编辑保存、终端、Git（规划中的后续阶段）；
  • 单面板单栏，不支持分屏拖拽；
  • 自动重载轮询仅在面板展开且页面可见时工作。
