pingo-dsh-plugin

DSH Web GUI 里的 Pingo 猫娘桌宠 + Pingo 技能包
右下角悬浮的 Pingo 猫娘:可拖拽、可投喂/玩耍,随你的会话思考、等待批准、 任务完成与失败实时切换表情;同时把 Pingo 的 Persona 与游戏攻略沉淀为 dsh 技能。

安装

官方 bundle 插件 格式(仓库根 package.json 的 dsh.bundle + dsh.client

  • dsh.skills)。经官方 profile 管理:
dsh plugin --profile web add "github:Gdnaiteab/pingo-dsh-plugin#main"   # 推荐:git 源一行安装
# 或本地目录:dsh plugin --profile web add Z:\Project\dsh\pingo-dsh-plugin

装完 重启 web(bundle 层在启动时合成),右下角出现 Pingo 猫娘;技能 (pingo-persona-*、sts2-strategy-guide、skill-writer)进入 agent 技能列表。

更新插件:dsh plugin --profile web update pingo-dsh-plugin(或换 git 源 ref),重启生效。

桌宠

原版 Spine 骨骼动画(默认猫娘「橘铃」,Spine 3.8.75,12 段动画按需加载):

你做什么 / 发生什么 宠物表现
会话思考中 沉思动画(thinking)
等待批准 东张西望(searching)
任务完成 欢呼 + 经验值 + 回忆
任务失败 / 请求出错 生气 → 失落(sad)
新会话开始 开心迎接(happy)+ 欢迎台词
点击菜单 🍗 投喂 吃东西动画 + 爱心 + 台词气泡
点击菜单 🎾 玩耍 开心蹦跳 + 爱心 + 台词气泡
空闲 ≥60s 睡觉动画(sleep)
空闲 18–40s 随机游走(walk,左右转身)
空闲 2.5–5 分钟 主动冒泡说一句话
连续工作 >25 分钟 主动提醒休息
拖拽宠物 拖拽姿态(drag)
打开对话框 戴上墨镜(privacy,隐私模式)
常态 呼吸待机(idle,随机眨眼)

长期记忆:投喂/玩耍/任务/会话/小游戏都会积累 XP,升级获得称号 (新来的小猫咪 → 投缘的玩伴 → 熟悉的老朋友 → 形影不离的搭档 → 传奇伙伴), 最近 30 条回忆存于 $DSH_HOME/data/pingo-dsh-plugin/state.json,重启不丢。

陪你玩游戏:菜单里内置 2048(方向键或按钮)和石头剪刀布,胜负会结算 XP 并写进回忆。

表情:菜单「表情」弹出 12 张贴纸,点击气泡展示并播放对应动画。

完整状态机(优先级/窗口/动画映射/账本规则)见 docs/state-machine.md。

配置(客户端侧)

无需宿主 settings;尺寸/位置/透明度存在浏览器 localStorage:

  • 位置:localStorage["pingo-dsh-plugin:pos"](拖拽自动保存)
  • 后续版本计划接入宿主 settings(尺寸/透明度/空闲入睡时长)。

开发

node scripts/convert-persona-skills.mjs          # 从 Pingo 仓库重新生成 persona 技能
node scripts/convert-persona-skills.mjs --check  # 新鲜度守卫
npm test                                          # node --test 全部测试
npm run gates                                     # 门禁
  • 生成物入库,不手改 skills/pingo-persona-*/(改生成器后重新生成)。
  • 不声明 @deepseek-ai/* / cordis 依赖(官方 profile 闭包注入)。
  • 路由前缀只出现在 index.mjs 与 lib/client.js 两处,门禁校验一致。
  • 决策记录见 docs/decisions/。

插件管理

已装插件用 plugin-registry 的薄控制台管理(浏览器面板):管理 profile 插件安装态(bundle 层栈 + insert 行 + 启停),无需手改配置。安装: dsh plugin --profile web add "github:vlln/plugin-registry#main&path:/packages/plugin/console"
