xby-time-zone

DeepSeek Harness (DSH) 的插件：时区管理服务

一个全面的MCP服务器，提供全球时区管理和时间转换功能，适用于全球业务协调、旅行规划和开发运维。

功能

  • set_xby_apikey — 在聊天中设置 API 密钥（自动持久化，重启有效）
  • get_current_time — 获取指定时区的当前时间
  • convert_time — 在不同时区之间转换时间

安装

方式一：从 GitHub 直接安装（推荐）

# 格式: dsh plugin --profile <profile> add github:<owner>/<repo>
dsh plugin --profile web add github:xby_skill/xby-time-zone

方式二：从本地目录安装（开发模式）

# 仅用于本地开发调试
dsh plugin --profile web add /absolute/path/to/xby-time-zone

方式三：通过 cordis.patch.yml 开发调试

dsh web --profile web --patch /absolute/path/to/dsh-ocr-plugin/cordis.patch.yml
