项目 Agent 管理

DeepSeek Harness 插件，为多项目（任务）提供独立工作区，一个项目（任务）对应一个工作区及会话，主要实现三个隔离：

  • AGENTS.md —— 项目专属提示约束
  • PROGRESS.md / PLAN / SPEC / DECISIONS.md —— 任务状态与进度文档
  • 项目内 .dsh/skills / .agents/skills —— 技能与知识

通过这三个核心要素的隔离，防止多项目间规则、任务进度等互相污染串扰，便于多项目平行推进。

安装和卸载

GitHub 安装（最新 main）：

dsh plugin --profile web add "github:Urbanrook/agent-project-manager#main"

npm 安装（发布后）：

dsh plugin --profile web add @urbanrook/agent-project-manager

卸载：

dsh plugin --profile web remove @urbanrook/agent-project-manager

卸载只移除插件本身；项目工作区、注册表、开发日志仍留在磁盘，需手动删除。

生效方式：安装后 host 侧改动需重启 DSH 才生效。最简单是重启电脑后重新打开 DeepSeek Harness；或运行插件附带的批处理重启 DSH：node_modules/@urbanrook/agent-project-manager/scripts/restart-dsh.cmd（若自定义启动命令，先设 DSH_RESTART_CMD）。

使用示例、关键指令

  • 首次启动自动建立主管工作区；侧边栏左下 🧩 Agent-project-manage 打开管理面板。
  • 面板：新建项目（自动写 AGENTS.md + 开发日志.md）、换图标、显示/归档、删除、主管职责。
  • 主管会话（可选）：可通过 project_assign_task <项目id> <标题> <内容> 写计划给项目下达任务。
  • 项目会话：project_export_summary <项目id> → 把计划的完成/未完成情况汇总成报告（相当于开发计划），导出到共享目录供查看。
  • 其它：project_list 查看注册表、project_new_project 建项目、project_unregister 注销、project_set_active_session 设主会话。

兼容 DSH 版本、已知限制、注意事项

  • 兼容：DSH 0.1.x（基于 0.1.1-rc.2 开发）。
  • 项目隔离非 OS 沙箱：bash/pwsh 内 cd、符号链接可绕过路径检查。
  • 归档单向：取消「显示」归档后，会话不自动恢复（harness 无反归档 API）。
  • 删除：仅注销注册表（可选连文件删），不删会话日志。
  • 可选补丁：会话列表「手风琴」可在面板内一键应用（未应用时面板提示按钮），也可手动运行 scripts/apply-accordion-patch.mjs。
