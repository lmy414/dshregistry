dsh-hallmark-design

DSH（DeepSeek Harness）技能插件：拒绝 AI 味的 UI 设计。

为 brief 选宏观结构 + 21 主题之一，跑 57 个 slop 测试门 + 预输出自我批评，拒绝所有 LLM 训练成的分布默认值——不同 brief 产出不同网站而非同一模板换色。四动词：构建 / audit 审计（打分不改）/ redesign 重构（保留文案+IA+品牌）/ study 提取 DNA（宏观结构/字体配对/颜色锚点，拒绝像素克隆）。受 Nutlope/hallmark（25.8k★）启发的中文原创精简版。

安装

dsh plugin add dsh-hallmark-design

触发方式

描述中包含"不要 AI 味 / 设计得像人做的 / slop 审计 / redesign / 提取设计 DNA / 主题化网页"等关键词时自动触发。

能力

  • 21 主题 + 宏观结构匹配
  • 57 slop 测试门 + 自我批评
  • audit / redesign / study 三动词
  • Custom 从头设计模式
  • 自包含 HTML + CSS 交付
