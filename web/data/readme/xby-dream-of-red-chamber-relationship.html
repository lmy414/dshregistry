xby-dream-of-red-chamber-relationship

DeepSeek Harness (DSH) 的插件：《红楼梦》人物关系图谱

关于《红楼梦》人物之间关系的知识图谱。

功能

  • set_xby_apikey — 在聊天中设置 API 密钥（自动持久化，重启有效）
  • get_schema — Get the schema of the graph database, includes nodes, their properties, and relationships.
  • execute_read_cypher — MCP Tool to execute a read Cypher query on the graph database.

安装

方式一：从 GitHub 直接安装（推荐）

# 格式: dsh plugin --profile <profile> add github:<owner>/<repo>
dsh plugin --profile web add github:xby_skill/xby-dream-of-red-chamber-relationship

方式二：从本地目录安装（开发模式）

# 仅用于本地开发调试
dsh plugin --profile web add /absolute/path/to/xby-dream-of-red-chamber-relationship

方式三：通过 cordis.patch.yml 开发调试

dsh web --profile web --patch /absolute/path/to/dsh-ocr-plugin/cordis.patch.yml
