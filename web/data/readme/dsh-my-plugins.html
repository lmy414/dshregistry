dsh-my-plugins

DeepSeek Harness（DSH）网页界面插件：在设置 → 插件页新增「我的插件」标签，以双列卡片形式集中展示你自己安装的插件，无需在加载器条目列表里逐一辨认。

每个插件卡片点击后展开详情：

  • 配置状态：已启用 / 已停用
  • Cordis 状态：已挂载、加载中、挂载失败、等待依赖、卸载中、未挂载（卡片右上角状态点同步着色）
  • 插件介绍：读取插件包 package.json 的 description
  • 顶部搜索框支持按模块名 / 条目 id / 介绍关键词过滤，卡片计数实时更新

为什么有用：DSH 默认的「插件」页展示的是 Loader 条目（含系统内置条目与伪模块），分不清哪些是自己装的。本插件只筛选用户安装的插件，并直接给出挂载健康状态。

界面预览

我的插件标签页

「我的插件」标签：搜索框 + 双列卡片。点击卡片展开配置状态、Cordis 状态与插件介绍。

功能特性

  • 自动识别用户安装的插件（排除系统条目与伪模块，见 lib/index.js 判定规则）
  • 双列卡片 + 展开详情（配置状态 / Cordis 状态 / 插件介绍）
  • 插件介绍自动读取各插件包 package.json 的 description
  • 搜索过滤 + 数量统计
  • 中英文双语界面（跟随 DSH 界面语言）
  • 浏览器半部经 POST /my-plugins/api/list 调用宿主半部，带同源与回环信任围栏

安装

需要 DSH CLI 与 pnpm（dsh plugin 内部转发到 pnpm）。

# 从 GitHub 安装：
dsh plugin --profile web add github:Ycet/dsh-my-plugins

# 本地目录安装（开发）：
dsh plugin --profile web add dsh-my-plugins@link:/path/to/dsh-my-plugins

包声明了 dsh.bundle 补丁层（见 package.json 与 cordis.patch.yml），dsh plugin 会自动把加载项合入 profile 的 bundle 层，无需手动编辑 cordis.patch.yml。手动方式：

# ~/.dsh/profiles/<profile>/cordis.patch.yml
- insert:
    - id: my-plugins
      name: dsh-my-plugins

使用方法

  1. 安装并重启网页应用：dsh web
  2. 打开 http://127.0.0.1:3080 并刷新页面
  3. 进入 设置 → 插件，点击「我的插件」标签
  4. 卡片展示用户安装的插件；点击卡片展开「配置状态 / Cordis 状态 / 插件介绍」，右上角搜索框可过滤

工作原理

flowchart LR
    A[浏览器半部 lib/client.js<br/>「我的插件」页签] -->|POST /my-plugins/api/list| B[宿主半部 lib/index.js<br/>路由 + 信任围栏]
    B --> C[枚举 Loader 条目]
    C --> D[过滤用户安装的插件]
    D --> E[读取插件包 description]
    E -->|JSON 响应| A
  • 宿主半部 lib/index.js：注册 /my-plugins/api 前缀路由（list 方法），枚举 Loader 条目 → 按「伪模块排除 / 安装闭包判断 / 补丁层 insert 匹配」三条规则筛选用户插件 → 读取各插件包 package.json 的 description 返回。
  • 浏览器半部 lib/client.js：向 settings.plugins.tab 槽位注入「我的插件」页签，双列卡片渲染 + 展开详情 + 搜索过滤。
  • 信任围栏：非回环 Host 需在 webRuntime.trustedHosts 白名单内，且拒绝 cross-site 请求与跨源 Origin。

配置说明

本插件无任何配置项。安装后即生效。
