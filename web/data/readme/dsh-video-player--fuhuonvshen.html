🐟 dsh-video-player（摸鱼播放器）

一个悄悄藏在 DeepSeek Harness 聊天输入框里的视频播放器～写代码写到想摸鱼的时候，不用切窗口，也不用开小屏，在输入框里就能偷偷看视频啦 (✧ω✧)

功能

  • 视频就藏在输入框里：不占全屏、不挡界面，看起来就是个普通的聊天页面。鼠标移开输入框，视频悄悄出现；鼠标移回来，又变回正常输入框，谁也看不出你在摸鱼～

  • 自动暂停 & 无缝继续：鼠标在输入框上打字时，视频自动暂停，进度给你记牢；鼠标一移开，视频就从刚才的位置接着播，一分不差。

  • B 站原生播放：暂停、恢复、拖进度条全部精确，不会一暂停就从头来。YouTube、Vimeo 和 mp4 直链也都支持。

  • 竖排控制条：在输入框右侧，透明背景不碍眼——播放/暂停、进度条、时间、换视频、关闭，一应俱全。

使用方法

  1. 复制视频链接（B 站 / YouTube / Vimeo / 直链都行）
  2. 按 Ctrl+Alt+V，或者点控制条的 🎬
  3. 粘贴链接，回车，开播！

快捷键

按键 作用
Ctrl+Alt+V 弹出粘贴链接框
Ctrl+Alt+M 锁定/解锁视频（锁定时视频固定显示，可以直接点视频操作）

控制条：⏯ 播放/暂停 · 进度条 · 时间 · 🎬 换视频 · ✕ 关闭

与其他插件兼容

和皮肤类插件一起用也没问题～比如配 dsh-deep-whale（鲸鱼娘皮肤），视频区域会自适应跟随皮肤下的输入框尺寸，互不干扰：

安装

dsh plugin --profile web add github:fuhuonvshen/dsh-video-player

装完自动激活，刷新页面就能用啦～

注意事项

  • 视频只出现在输入框那一小块：鼠标在输入框上时是正常输入框，移开了才显示视频
  • 抖音这类禁止嵌入的网站暂不支持
  • 不保存播放记录，刷新后不留痕迹，放心摸鱼 🌊
