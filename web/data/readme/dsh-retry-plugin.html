dsh-retry-plugin

AI 访问报错（网络抖动、限流、服务器 5xx……）导致对话中断？装上这个插件，它会在回合报错后自动发送「continue」重新发起请求，并在输入框上方实时显示重试状态与当前次数，同时支持在设置中心调整重试参数，让对话无缝继续！

这是为 DeepSeek Harness（DSH）Web UI 打造的纯客户端插件：在浏览器里监听会话的回合错误，在输入框上方挂载重试状态栏，并提供设置面板。

功能特性

  • 🔁 自动发送「continue」 —— 回合以 turn/end(reason: error) 收尾报错时，自动通过 prompt 通道发送消息「continue」，让 AI 顺着上下文接着完成任务。
  • 📊 前端实时状态提示 —— 当发生错误并进入重试倒计时/重试中时，输入框上方即时浮现提示条（显示当前为 第 X / Y 次重试，并提供「取消重试」按钮）。
  • ⚙️ 原生设置面板集成 —— 在系统设置（Settings -> General）中提供可视化配置项，可一键开关插件并自由修改最大重试次数。
  • 🔢 默认 10 次预算 —— 每次重试消耗 1 次预算；连续失败达到上限后自动停止，避免无限请求。
  • ⏱️ 重试延迟 —— 每次重试前等待 2 秒（可配置），给瞬时网络故障留出恢复时间。
  • 🚫 永久性错误不重试 —— AUTH / QUOTA / INVALID_CREDENTIAL / CONTEXT_WINDOW_EXCEEDED 等错误码直接放弃，避免浪费 Token。
  • 🧠 历史会话不误触 —— 打开已完成的历史对话、切换会话都不会触发重试。
  • ✍️ 新消息重置预算 —— 手动发送新消息后，重试预算重新充满。
  • 🧹 自释放 —— 插件卸载 / HMR 时自动清理全部 DOM 样式、定时器与状态机。

搭配推荐

推荐搭配 dsh-sound-plugin 使用 —— 一款用于 DeepSeek Harness（DSH）的插件，可以让 AI 在结束工作后或向你提问时播放声音提醒你。配合自动重试，即使你暂时离开窗口，也能第一时间听到 AI 已完成任务或需要你介入的消息。

# 同样安装进 web profile
dsh plugin --profile web add dsh-sound-plugin

安装

前置要求

  • 已安装 DeepSeek Harness（dsh 命令可用）
  • pnpm

步骤

# 1. 把插件安装进 web profile
dsh plugin --profile web add dsh-retry-plugin

# 2. 启动或重启 web UI
dsh web

本地开发时，也可以在插件源码目录下安装本地副本：

dsh plugin --profile web add ./dsh-retry-plugin

卸载：

dsh plugin --profile web remove dsh-retry-plugin

配置

你可以直接在 DSH 界面中配置，无需手动改写代码：

  1. 打开 DSH Web 界面左下角的 设置 (Settings) -> 通用 (General)。
  2. 找到 AI 失败自动重试 (Auto Retry) 选项：
    • 勾选或取消「启用」开关。
    • 输入你期望的「最大重试次数」（例如 5 次或 10 次）。
  3. 设置立即生效，且会自动保存在浏览器本地。

(高级用法：也可以在浏览器的 DevTools Console 中通过 localStorage.setItem("dsh-retry.delayMs", "3000") 调整重试等待延时)
