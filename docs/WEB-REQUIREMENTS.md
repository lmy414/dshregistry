# dshregistry 网页端需求文档(设计师核对版 v2)

> 版本:v2(2026-08-16)。用途:供设计师出网页设计稿,前端按本需求实现。
> 项目:DSH(DeepSeek Harness)插件索引门户。**信任与透明是第一设计主题** —— 本站收录的插件默认"未审计",所有设计元素不得弱化风险提示。

## 2. 首页(插件列表页)

### 2.1 顶部
- 站点名 + 一句 slogan(中英:「DSH 插件索引 · 社区驱动」/ "DSH Plugin Index · Community-Driven")
- 导航:插件市场 / 关于
- **语言切换**(中 / EN,右上角,图标或文字按钮)
- (可选)统计条:收录插件数 · 分类数 · 更新时间(数据来自静态 `meta.json`,爬虫生成)

### 2.2 筛选与搜索区
- 搜索框:按插件名/描述即时过滤(前端过滤,无需提交)
- 分类筛选:chips 或下拉,分类固定为(双语标签):
  `全部 All / 工具 Tools / 视觉 Vision / 看板 Dashboard / 桥接 Bridge / 启动器 Launcher / MCP / 技能 Skills / 其他 Other`
- 排序:默认(最近更新) / Stars

### 2.3 插件卡片列表
每张卡片展示:
- 插件名 + 分类标签(小)
- 一句话描述(截断 1-2 行;**展示原文,不翻译**)
- 作者/仓库(GitHub 用户名)
- **三态徽章**(见 §5)
- Stars 数、最近更新时间(相对时间,双语格式)
- 入口:「查看详情」

布局:桌面网格(3 列左右),移动端单列。卡片可整体可点击。
**注意**:英文描述比中文长,卡片高度需容错(描述截断行数固定,不留死高度)。

### 2.4 状态
- 加载中骨架屏 / 空结果提示(双语)+ 清除筛选按钮

## 3. 插件详情页

URL 形如 `https://dshregistry.xyz/plugin.html?slug=dsh-vision`(可分享)。

### 3.1 头部区
- 插件名、分类标签、**三态徽章**(含解释)
- 一句话描述(原文)
- Stars / 最近更新 / 收录时间
- 「在 GitHub 查看」按钮(外链,新标签)

### 3.2 安装区(**页面核心,位于首屏内,不折叠**)
- 安装命令代码块 + 「复制」按钮(反馈"已复制")
  ```
  dsh plugin --profile web add github:<owner>/<repo>#<commit>
  ```
- ⚠️ **未审计声明**(见 §5.3 固定文案,中英两版;红色/琥珀色警示样式,紧贴安装命令,不可弱化、不可收进折叠)
- 基础检查状态:通过 / 未通过(说明见 §5.4)

### 3.3 介绍区
- 完整描述(README 摘要,原文;过长时"展开全文")
- 元信息表:作者 · GitHub 仓库 · 最新 commit(短 SHA)· 最近更新 · 收录时间

### 3.4 风险说明区(可折叠,默认展开)
- 说明文案(§5.3 展开版,双语):插件在 DSH 主进程内运行、无沙箱隔离、安装即执行全部代码、建议先查看源码
- 「在 GitHub 查看源码」按钮

### 3.5 相关推荐(可选)
- 同分类的其他插件 2-4 个,小卡片

## 5. 信任体系设计规范(设计师必读)

### 5.1 三态徽章(全站统一,双语文案)

| 状态 | 颜色 | 中文 | English | 悬浮提示 |
|---|---|---|---|---|
| 未审计 | 灰 | 未审计 | Unreviewed | 未经人工安全审计,无任何背书 |
| 社区认可 | 蓝 | 社区认可 | Community-Vouched | 社区反馈显示可用:收录≥30天、stars≥20或forks≥5、未被人工标记、作者账号≥90天 |
| 有风险报告 | 红 | 有风险报告 | Flagged | 被站长/人工标记为有风险,不建议安装 |

- 徽章在卡片、详情页、安装命令旁**三处都要出现**;颜色语义严格:灰=默认,蓝=达标,红=警告。

### 5.2 主色建议
- 基调:开发者工具的克制感(npm/GitHub 风格),浅色为主
- 主色:中性灰蓝;强调色:蓝(仅用于"社区认可"与主要按钮)
- 警示色:红/琥珀(仅用于风险场景,不做装饰)
- 字体:系统字体栈;**中英文混排需正常**(中文用系统 CJK,英文同栈);代码块等宽字体

### 5.3 固定文案(设计不可改写,提供中英两版)

> **中文**:安装前必读:此插件未经人工安全审计。安装后将以你运行 DSH 的用户权限执行任意代码,可读写你的文件、访问网络。仅安装你信任的来源。
> **English**: Read before install: This plugin has NOT undergone manual security review. Once installed, it will run arbitrary code with the permissions of your DSH process and may read/write your files and access the network. Only install from sources you trust.

### 5.4 基础检查(自动化,非安全保证)
- 文案:"通过基础检查(包结构/元数据/README 存在)。**不构成安全保证。**" / "Passed basic checks (package structure/metadata/README). **Not a security guarantee.**"
- 未通过时显示"未通过基础检查" / "Failed basic checks"。

## 6. 交互与行为

- 复制按钮:点击即复制 + 1.5s "已复制"反馈
- 搜索/筛选/排序:全部前端即时处理,无跳转
- 外链(GitHub、README):一律新标签打开
- **语言切换**:顶部按钮,切换即时生效;默认 `navigator.language` 前缀匹配(zh → 中文,其余 → English);选择存 localStorage
- 详情页:从首页卡片进入;浏览器后退可返回
- 滚动:页面轻量,无复杂动效;徽章提示用原生 title 或轻量 tooltip

## 7. 技术约束(告知设计师)

- 前端:HTML + CSS + 原生 JS(无框架、无构建、无动效库)
- 数据源:单个 `plugins.json` 静态文件,页面 fetch 渲染
- **多语言**:界面字符串走 `i18n/zh.json` + `i18n/en.json`(前端运行时切换);插件内容(名称/描述)保持原文不翻译
- 目标性能:首屏 < 100KB(按语言拆,不一次性加载两套文案)
- 响应式:桌面 1440px 优先,移动 375px 可用
- 可访问性:正文对比度 ≥ 4.5:1;交互元素有焦点态

## 8. 无后端说明(重要)

> **公网只有静态网页,没有任何接口。** 所有写操作(处理举报、维护黑名单、触发爬虫、更新数据)通过**飞书指挥服务器上的运维 AI**完成,不经过公网。

- 页面数据来源:`plugins.json` / `meta.json` / `blocklist.json` 三个静态文件,由服务器爬虫脚本定期生成(每 6h),上传静态目录即生效
- **v1 无举报/反馈入口**(不做在线表单,不做点击统计);后续社区(Discord)视客流再开放
- 对前端的要求:所有交互均为本地前端逻辑,无任何网络写请求

## 9. 交付物建议

- 设计稿:桌面 1440px + 移动 375px;首页 + 详情页 + 关于页;**中英两种文案状态各一版**(关键页)
- 组件明细:插件卡片 · 三态徽章 · 代码块 · 警示框 · 分类 chips · 统计条 · 语言切换
