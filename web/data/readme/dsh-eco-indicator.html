dsh-eco-indicator

DeepSeek Harness 插件：经济指标一键查询（World Bank 开放数据，无需 API Key）。

Query World Bank open economic indicators — GDP, inflation, trade, population, GDP per capita — by country and year range. No API key required.

功能

  • wb_indicator：按国家 + 年份区间查询任意世界银行指标（每行一年，缺失年份自动省略）
  • wb_countries：按名称片段或 ISO3 代码解析国家代码（给 wb_indicator 用）

常用指标示例：

代码 含义
NY.GDP.MKTP.CD GDP（现价美元）
NY.GDP.PCAP.CD 人均 GDP（现价美元）
FP.CPI.TOTL.ZG 通胀率（CPI 年增长率 %）
NE.TRD.GNFS.ZS 贸易占 GDP 比重（%）
SP.POP.TOTL 总人口
SL.UEM.TOTL.ZS 失业率（%）

国家代码：ISO3（CHN/USA/GBR）或区域（W 世界 / 1A 高收入 / 3E 低收入）。

安装

dsh plugin --profile web add dsh-eco-indicator
# 或从 GitHub 安装
dsh plugin --profile web add https://github.com/SIMON-WORLD/dsh-eco-indicator

安装后重启 harness，然后在对话里问：

查一下中国 2018-2023 的 GDP（现价美元）和通胀率

模型会自动调用 wb_indicator 返回逐年数据。

开发

npm run test   # 运行 node --test 单元测试（不依赖网络）
