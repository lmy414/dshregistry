神里印象 · Kamisato Impression（DeepSeek Harness 皮肤插件）

为 DeepSeek Harness 网页端打造的主题皮肤：以「神里之纹」的青→蓝绿→深藏青 与「神里绫华」的靛→冰蓝→金为双色体系，配原神 UI 风格的克制点缀。 不改动任何页面结构与布局，只覆盖颜色、标题字体与少量视觉样式。

  • 标题字体：汉仪文黑（汉仪文黑-85W/75W/65W/55W，即原神中文版 UI 字体）； 正文、小字号、代码字体保持 dsh 原样。
  • 浅色模式：青 × 靛（淡雅）；深色模式：深靛底 × 冰蓝辉光 × 金点缀（深而明）。
  • 右下角双水印：浅色 = 神里之纹（青，稍深）；深色 = 绫华之扇（冰蓝-金，明快）。

目录结构

├─ cordis.patch.yml        # 向 loader 插入 skin-kamisato 条目
├─ build-client.ps1        # 由 skin.css + 水印图 生成 lib/client.js
├─ resize-crest.ps1 / resize-fan.ps1  # 由参考图重新生成水印资源
├─ README.md / palette.md / LICENSE
└─ lib/
   ├─ skin.css             # 皮肤主样式（可读、可维护的唯一真源）
   ├─ kamisato-crest-wm.png# 340px 纹章水印（由参考图缩放而来）
   ├─ kamisato-fan-wm.png  # 340px 扇子水印（由参考图缩放而来）
   ├─ client.js            # 构建产物：内联 CSS + 双水印的浏览器 bundle（勿手改）
   └─ index.js             # Host 侧插件：/skin-fonts 字体路由

安装

从 GitHub（推荐）

dsh plugin --profile web add git+https://github.com/Danieltoraji/dsh-skin-kamisato.git

从本地目录

# 在任意目录执行（绝对路径直接透传；相对路径以当前目录为锚）
dsh plugin --profile web add "F:\coding\Projects\DSHarness\dsh-skin-kamisato"

dsh plugin add 会：① pnpm 装入 profile 依赖；② 因本包声明 dsh.bundle.patch， 自动把 dsh-skin-kamisato 追加到 profile 的 dsh.profile.bundles 层。

然后重启 dsh web 服务（插件集变更需重启生效）。重启后打开 http://127.0.0.1:3080，硬刷新（Ctrl+F5）即可看到皮肤。

卸载

dsh plugin --profile web remove dsh-skin-kamisato   # 再重启一次

调整皮肤（迭代）

  1. 修改 lib/skin.css（配色、字体、水印）；
  2. 重跑 powershell -File build-client.ps1 重新生成 lib/client.js；
  3. 硬刷新页面。若浏览器仍用旧 bundle（一般不会，/plugins/*/client.js 响应 no-cache），重启 dsh web 一次。

注意：本包通过 pnpm 链接进 profile 的 node_modules，所以直接编辑 工作区文件即生效，无需重装。

字体自托管说明

Chromium 对「按用户安装」的字体（%LOCALAPPDATA%\Microsoft\Windows\Fonts） 存在渲染回退：document.fonts.check() 为 true，但光栅化时静默不用。 本插件的 Host 侧会注册 /skin-fonts/<weight>W 路由，把本机安装的汉仪文黑 TTF 只读伺服给浏览器（@font-face 走正常字体加载管线），绕开该问题。 字体文件不复制、不随包分发（汉仪文黑为商业字体）；目标机器未安装时路由 404，字体栈自然回退，不影响其余皮肤。

  • 水印图片（lib/kamisato-crest-wm.png、lib/kamisato-fan-wm.png）由 用户提供的参考图（《原神》相关美术素材）缩放而来，内嵌于构建产物。 如用于公开发布，请自行确认素材使用授权；如不确定，可用你自己的素材替换后 重新构建（resize-crest.ps1 / resize-fan.ps1）。
  • 字体：仅按名称引用并在本机伺服已安装的正版汉仪文黑，不随包分发。

分享

把整个 dsh-skin-kamisato 文件夹拷给他人，目标机器执行 dsh plugin --profile web add <该文件夹路径> 并重启即可。皮肤完全自包含 （水印 base64 内嵌于 client.js），不依赖任何外部资源。注意：目标机器 需要自行安装汉仪文黑（正版授权）——插件只伺服本机已装的字体文件，不会 随包分发字体。

为什么不用「改 dist」的方式

直接改 dsh-web-frontend/dist 虽然免重启，但前端包一升级就被覆盖； 插件形式把皮肤装进 profile 依赖层，升级不丢、可装卸、可分享。 代价仅是插件集变更需要重启一次服务。
