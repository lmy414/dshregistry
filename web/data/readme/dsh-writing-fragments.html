dsh-writing-fragments

DSH（DeepSeek Harness）技能插件：写作探索（碎片挖掘）。

纯探索阶段的写作伴生技能：盘问用户、从第一句话捕获碎片、碎片异构（金句/主张/小场景/半想法/引语）、领航词是最有价值的碎片、单一文件追加不承诺结构。受 mattpocock/skills 的 writing-fragments（223k★ MIT）启发的中文原创精简版。

安装

dsh plugin add dsh-writing-fragments

触发方式

描述中包含"写作探索 / 收集素材 / 碎片 / 领航词 / 还没结构 / 想写点什么"等关键词时自动触发。

能力

  • 碎片定义与异构形态
  • 领航词挖掘（承重墙）
  • 从第一句捕获 + 单一文件
  • 与塑形/节拍的探索-开采分工
