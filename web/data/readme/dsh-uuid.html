dsh-uuid · UUID 生成/解析

纯 Node 实现，无网络、无外部服务。

安装

dsh plugin add dsh-uuid

安装后在 profile 的 package.json 的 dsh.profile.bundles 中加入 "dsh-uuid"。

安装

dsh plugin add github:uckkk/dsh-uuid

安装即在本机运行第三方代码，请自行审阅源码。
