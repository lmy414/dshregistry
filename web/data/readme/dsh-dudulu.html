dudulu（嘟一声）· DSH 任务完成提示音插件

Agent 回合完成（turn/end, reason.kind === 'completed'）时播放【嘟嘟噜~】提示音，干完活不用一直盯屏幕。失败 / 中断 / 等待审批 / token 超限 不响，子代理不响。

带设置面板：启用开关、音量滑条（拖动即试听）、提示音路径、文件上传（自动转码 48kHz WAV）。

安装

方式一：从 GitHub 安装（推荐）

dsh plugin --profile web add github:Cmjingahaha/dsh-dudulu
systemctl --user restart dsh-web.service

方式二：手动挂载

# 1. 克隆到本地插件目录
git clone https://github.com/Cmjingahaha/dsh-dudulu.git ~/.dsh/plugins-local/dudulu

# 2. 软链到 profile
ln -sfn ~/.dsh/plugins-local/dudulu ~/.dsh/profiles/web/node_modules/dudulu

# 3. 编辑 ~/.dsh/profiles/web/package.json：
#    "dependencies": { "dudulu": "file:../../plugins-local/dudulu" }
#    "dsh.profile.bundles": [ ..., "dudulu" ]

# 4. 重启
systemctl --user restart dsh-web.service

配置

重启后在 DSH 设置侧边栏打开「dudulu · 嘟一声」面板：

设置项 说明 默认值
启用 总开关 true
音量 0–100，拖动滑条实时试听 100
提示音路径 自定义音频文件绝对路径 ~/dudulu01.wav
上传 选本地音频文件，自动转码 48kHz WAV 并切为当前提示音 —

配置持久化在 settings 文档中，重启不丢。

触发与判定

怎样触发 何时不触发
Host 事件 session/event，event.type === 'turn/end' 且 event.data.reason.kind === 'completed' 失败 (error)、被打断 (aborted)、阻塞 (blocked)、token 超限 (max-tokens)、中断 (interrupted)
仅顶层会话（session.header.origin !== 'subagent' 且 delegationDepth === 0） 子代理 / workflow 子会话
去抖 1200ms 连续完成

Model Experience

本插件不向模型暴露任何工具——纯宿主事件驱动，模型无需感知它的存在，不影响模型行为与上下文开销。

播放链

pw-play（PipeWire 原生）→ ffplay → paplay → mpv，依次降级，找不到可用播放器则静默跳过。

已知限制

  • 需要宿主音频环境（PipeWire / PulseAudio 任一）；虚拟机内建议参考 PipeWire wiki: Stuttering Audio in VM 调整 api.alsa.headroom
  • 提示音文件过大会增加转码耗时（建议 < 1MB）
