dsh-aurora-skin

Three hand-tuned skins for DeepSeek Harness (DSH). Pure --dsw-alias-* token system, no core patches, persisted in localStorage.

✨ The skins

ID Name Mode Mood
aurora Aurora 极光 Dark Deep midnight navy · electric cyan · warm coral — aurora over a precision control room
paper Paper 纸本 Light Cool paper white · deep teal — feels like a research paper, made for daytime reading
hologram Hologram 全息 Dark Near-black · lime-cyan — distinctive terminal vibes, like a precision instrument

All three palettes were tuned by hand against the DSH --dsw-alias-* token surface (bg-base / layer-1..3 / overlay / border / label-* / brand / button / interactive / markdown / sidebar / scrollbar). Every value is a concrete CSS color — no var() indirection — so contrast holds across the whole UI.

📦 Install

dsh plugin --profile web add breaker505/dsh-aurora-skin

Or locally from this checkout:

cd ~/.dsh/profiles/web
pnpm add file:path/to/dsh-aurora-skin

Or clone directly:

git clone https://github.com/breaker505/dsh-aurora-skin

Then add "dsh-aurora-skin" to the dsh.profile.bundles array in package.json and restart dsh web.

🎨 Use

Open Settings → General → Aurora Skins and pick a skin, or click "Follow system" to revert to the built-in appearance.

The Aurora picker row is rendered above the dsh-skin row (slot order 15 vs 20), so curated skins show up first.

🧬 Design philosophy

  • Tokens, not code. The plugin only writes --dsw-alias-* custom properties on <body>. No DOM mutations, no overrides of internal DSH components, no monkey-patches.
  • Reversible by design. Selecting "Follow system" clears the override and the UI returns to the original DSH palette — there is no install-time patch to undo.
  • Hand-tuned palettes. Each of the three themes was dialed in token-by-token for contrast on both surface and text roles, in light and dark modes.

🔧 Develop

git clone https://github.com/breaker505/dsh-aurora-skin
cd dsh-aurora-skin
pnpm install

The lib/client.js is hand-written CJS that wraps the runtime-loaded factory via window.__ModuleLoader__.load — the same shape tsdown emits for the shipped ui-* packages, but with no build step. Edit it directly and reload dsh web.
