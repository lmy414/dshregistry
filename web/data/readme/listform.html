📋 ListForm · 万能智能记账本

ListForm 是一个万能智能记账本和信息汇总工具。支持支出账单、出货台账、运行日志等结构化数据记录，可附加图片/文档存档，支持自动归类、周期报表和定时提醒。

✨ 功能特性

📝 多功能记录

  • 支出账单：日常消费、购物记录
  • 出货台账：销售发货、库存管理
  • 运行日志：设备巡检、运维记录
  • 支持自定义表单模板

🖼️ 多附件支持

  • 图片拍照记录
  • 文档存档
  • 自动关联记录 ↔ 附件

🔄 智能归类

  • 自动识别记录类型
  • 按类别、日期、标签自动整理
  • 支持自定义分类规则

📊 周期报表

  • 日报 / 周报 / 月报自动汇总
  • 支出趋势图表
  • 分类汇总统计

⏰ 定时提醒

  • 到期提醒（账单还款、任务截止）
  • 周期提醒（每日/每周/每月）
  • 异常提醒（超预算、库存不足）

🚀 快速开始

安装

clawhub install list

使用方式

对话中触发关键词即可：

记一下吃饭花了68元     → 记录支出
记一下今天发了5箱货    → 记录出货
查看本月支出报表        → 查看汇总
提醒我每周一交房租      → 设置提醒

🛠 技术栈

  • OpenClaw 智能表单引擎
  • 结构化数据存储
  • 定时提醒系统
  • 自定义分类模型
