dsh-theme-factory

DSH（DeepSeek Harness）技能插件：主题工厂。

用预设专业主题（色板 + 字体配对）装饰幻灯片/文档/报告/HTML 落地页：展示看板 → 用户选择 → 确认后一致应用；也支持现场生成新主题；对比度与可读性纪律。受 Anthropic 官方 skills 的 theme-factory（Apache-2.0）启发的中文原创精简版。

安装

dsh plugin add dsh-theme-factory

触发方式

描述中包含"主题 / 美化幻灯片 / 视觉风格 / 配色字体 / 装饰文档 / 统一风格"等关键词时自动触发。

能力

  • 10 个预设主题库
  • 看板展示-选择-确认-应用流程
  • 现场生成新主题
  • 一致性/对比度/可读性纪律
