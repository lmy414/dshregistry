dsh-disk-cleaner

Windows 磁盘空间分析与安全清理插件。

定位

先看清哪里占空间，再决定哪些内容可以清理。插件会围绕扫描、解释、确认、清理和结果复核建立完整流程，默认保护系统目录、应用目录和用户重要文件。

计划能力

  • C 盘空间总览与分类占用分析
  • 临时文件、缓存、日志和大文件识别
  • 清理建议的原因、大小和风险说明
  • 清理前预览与用户确认
  • 白名单路径校验与回收站/隔离区优先
  • 清理进度、跳过原因和结果报告
  • 可撤销的清理历史

当前状态

仓库已创建，正在搭建扫描器、规则引擎和 Web 工作台。删除能力将在安全边界和测试完善后开放。

安全原则

AI 负责解释和推荐，确定哪些文件可以处理的必须是确定性的规则和白名单。插件不会默认删除任意路径，也不会把用户文件上传到外部服务。
