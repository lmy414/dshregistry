dsh-relationship-coach

DSH（DeepSeek Harness）技能插件：恋爱/关系军师。

把情绪支持、关系科学与可执行策略装进一个真正站在用户一边的 AI：先接住情绪再解决事、建立双方档案、分离事实/推测/未知、比较互惠/现实/风险/机会成本、给出可发送的话术/行动/观察窗口/停止条件；危险情境先保安全。受 powerycy/goutoujunshi（2.3k★）启发的中文原创精简版。

安装

dsh plugin add dsh-relationship-coach

触发方式

描述中包含"这句话怎么回 / 追求复联邀约 / 分析聊天记录 / 恋爱军师 / 关系建议 / 要不要继续投入 / 体面退场"等关键词时自动触发。

能力

  • 情绪落地 → 档案建立 → 事实/推测/未知分离
  • 互惠/现实/风险/机会成本四维比较
  • 首选建议 + 理由 + 可执行话术
  • 观察窗口与停止条件
  • 危险情境优先安全流程
  • 不预设性取向与性别角色
