dsh-git-branch-manage

English | 中文

A DeepSeek Harness (DSH) bundle — Git branch badge: shows the current git branch in the session header and the new-session hero page. Click the badge to switch / create / pull / fetch / push / delete local branches (IDEA-style directory tree, 7-day active branches).

Installation

dsh plugin --profile web add @wanghailong0419/dsh-git-branch-manage

Or install it together with the toolkit:

dsh plugin --profile web add @wanghailong0419/dsh-toolkit

Screenshots

Git Branch Badge Branch menu

Features

  • Current branch shown in the session header and the new-session hero page
  • Left-click: branch menu (local / remote, IDEA-style tree; local shows only branches active in the last 7 days)
  • Right-click: switch / pull / fetch / push
  • Create branch: pulls the current branch first, then creates and switches (with prefix suggestions)
  • Delete branch: local-only, safe delete (-d); refuses the current branch and remote branches
  • Switch confirmation dialog; dot-spinner loading while an action runs

Structure

lib/index.js    host half: BranchBadgeGateway (TypertRemoteService + @Remote)
lib/client.js   client half: badge / menu / hero chip (ctx.remote.$mount)
cordis.patch.yml bundle patch (auto-activated by dsh plugin add)
