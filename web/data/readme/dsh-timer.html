dsh-timer

DeepSeek Harness 定时计划任务插件：给消息设个执行时间，到点自动在当前对话里继续执行该任务（默认 full access 权限）。

安装

GitHub 安装（推荐）：

dsh plugin --profile web add github:life1996cou/dsh-timer

本地目录安装：

dsh plugin --profile web add file:/绝对路径/dsh-timer

注意：不要用裸相对路径（如 add ../dsh-timer），那是 pnpm 软链安装，会导致运行时解析失败。

使用

  1. 打开左侧栏底部的「计划任务」开关（开启后开关变绿色）。
  1. 在输入框写好要执行的内容。
  2. 点发送按钮旁的「计划」，设置执行时间：
    • 默认是当前时间（取整到下一分钟）。
    • 点「错高峰」一键跳到最近的空闲时段；再点一次取消并恢复原时间。
    • 高峰时段：北京时间 9:00–12:00、14:00–18:00，其余为空闲时段。
  1. 点「计划发送」→ 确认 → 任务进入左侧「计划任务」列表。
  2. 到点后，插件会在当前对话里自动继续执行该内容（不新开会话）。

任务状态

状态 含义
待执行 还没到执行时间
运行中… 已到点，正在执行
HH:MM（绿色） 执行完成，显示完成时间
失败 执行报错

其他

  • 「清空」一键删除所有任务。
  • 任务数量不设上限，可同时多个并发或按不同时间先后触发。
