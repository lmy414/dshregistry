dsh-agent-reach

DSH（DeepSeek Harness）技能插件：给 AI Agent 装互联网能力。

一键接入网页阅读、YouTube 字幕、RSS、全网搜索、GitHub、X、B站、Reddit、Facebook、Instagram、小红书、LinkedIn、V2EX、雪球、小宇宙——零配置即用 + 多后端路由（平台封了自动换）+ agent-reach doctor 诊断 + Cookie 仅存本地。受 Panniantong/Agent-Reach（73k★）启发的中文原创精简版。

安装

dsh plugin add dsh-agent-reach

触发方式

描述中包含"读网页 / YouTube 字幕 / 搜推特 / 看 B站 / 读小红书 / 查雪球 / RSS 订阅 / 联网能力"等关键词时自动触发。

能力

  • 15+ 平台覆盖（零配置优先）
  • 多后端路由自动切换
  • doctor 诊断一条命令
  • 隐私安全（Cookie 本地）
  • 一句话配置引导
