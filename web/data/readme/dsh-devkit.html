dsh-devkit

npm 上的包名是 dsh-netcafe-devkit —— dsh-devkit 已被他人占用。 仓库名不变,dsh plugin add github:... 的装法照旧。

JSON/YAML round-trip, JSON Schema validation, text diff, JWT decode, regex testing, SQL dialect transpiling, QR codes, timezone and unit conversion, page screenshots.

What & why

These are the operations an agent reaches for in the middle of something else. Doing them by prompting a model is slower, costs more and is not reproducible. transpile_sql runs a real parser (mysql, postgres, bigquery, snowflake, clickhouse, doris, starrocks), so syntax errors come back with line and column instead of a confident rewrite.

Every set ships what_can_you_do — describe a task in any language, get the exact tool plus a ready-to-run call.

Install

dsh plugin --profile <your-profile> add github:mario03690/dsh-devkit

Thin config layer only (one @deepseek-ai/dsh-mcp-client row, shipped as cordis.patch.yml) — no tool code runs on your machine. Built against the MCP client config shape of the dsh v0.1 developer preview; verified against the live endpoint on 2026-08-22.

Cost, quota, privacy

Mostly $0.001 per call and deterministic. Two exceptions that are not: sql_from_description ($0.01) calls a model, screenshot_url ($0.003) renders a page. Failed calls are not charged.

No signup for the free anonymous quota. Documents are processed in memory and not retained. The config URL carries ?s=dsh-dev — a channel tag identifying the install path, not you.
