dsh-color-contrast · WCAG颜色对比度计算器

WCAG颜色对比度计算器。纯 Node 实现，零第三方运行时依赖，peer-only 依赖（随 DSH 宿主加载）。 WCAG颜色对比度计算器 — a DeepSeek Harness (dsh) plugin. Pure Node, zero runtime dependencies.
