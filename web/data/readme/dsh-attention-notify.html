dsh-attention-notify

English | 中文

Native browser notifications for DeepSeek Harness (DSH). The plugin observes the existing DSH session-list feed and notifies for:

  • conversation and subtask completion
  • approval requests
  • questions awaiting an answer
  • plans awaiting review
  • completed, failed, or killed background jobs

It remains event-driven while the page is hidden; there is no visibility-gated polling. Clicking a notification focuses the browser and opens the matching session.

Install

dsh plugin --profile web add github:Unintendedz/dsh-attention-notify#v0.1.2

Restart dsh web, refresh the page, then click the bell in the sidebar footer and allow notifications. A successful permission grant sends one test notification; a dismissed or blocked prompt leaves visible site-settings guidance in the same row.

Uninstall

dsh plugin --profile web remove dsh-attention-notify

Restart DSH Web after removing the plugin.

Privacy and limits

  • Zero runtime dependencies. No server, shell execution, external requests, or telemetry.
  • Notification text contains the DSH session title or background-job label and may be visible in lock-screen previews.
  • The DSH page must remain open. A browser or operating system that suspends or discards the page also suspends a page-only plugin.

Development

npm install
npm test

npm test builds the browser bundle before running the built-in Node test runner.
