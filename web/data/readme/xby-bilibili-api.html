xby-bilibili-api

DeepSeek Harness (DSH) 的插件：B站API服务

一个为bilibili.com API提供服务的Model Context Protocol (MCP)服务器，支持获取用户信息、视频搜索等功能。

功能

  • set_xby_apikey — 在聊天中设置 API 密钥（自动持久化，重启有效）
  • get_user_info — Get information about a Bilibili user
  • get_video_info — Get detailed information about a Bilibili video
  • search_videos — Search for videos on Bilibili

安装

方式一：从 GitHub 直接安装（推荐）

# 格式: dsh plugin --profile <profile> add github:<owner>/<repo>
dsh plugin --profile web add github:xby_skill/xby-bilibili-api

方式二：从本地目录安装（开发模式）

# 仅用于本地开发调试
dsh plugin --profile web add /absolute/path/to/xby-bilibili-api

方式三：通过 cordis.patch.yml 开发调试

dsh web --profile web --patch /absolute/path/to/dsh-ocr-plugin/cordis.patch.yml
