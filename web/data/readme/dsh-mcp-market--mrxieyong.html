dsh-mcp-market · MCP 服务管家

DeepSeek Harness Web 的 MCP 市场与管理插件：

  • 左侧边栏顶部入口行（新建会话/技能中心行下方，DOM 注入，与技能中心/任务板同机制）： 点击打开「MCP 服务管家」弹窗 —— 类似 Trae 的 MCP 市场体验。

  • 会话顶部栏：另有一个 MCP 图标快捷入口，共用同一个弹窗。

  • 市场：右上角「+ 添加 MCP Servers」→「从市场添加」——模板列表（Apifox 公有云/私有化、 Apipost 云端/私有化、MasterGo、Pixso 远程/本地；Figma 官方仅支持 OAuth 暂不支持直连、 蓝湖官方暂无 MCP，均以说明卡提示）。点击模板只是快捷方式：打开与「手动配置」相同的页面， JSON 预填模板骨架，令牌、项目 ID、私有化地址由你在 JSON 里自行补入。

  • 手动配置：右上角「+ 添加 MCP Servers」→「手动配置」——粘贴完整 mcpServers JSON （Claude Code .mcp.json 格式，支持一次粘贴多台、支持 // 注释），确认后保存。

  • 我的服务：Trae 式列表（头像 + 名称 + 下拉箭头），点击展开：启用/停用、编辑（预填当前配置 JSON）、 删除、查看完整配置；来自其他来源的 MCP 配置以只读方式展示。

工作原理

每个 MCP 服务器 = 一个 @deepseek-ai/dsh-mcp-client 插件实例行，由本插件维护在 $DSH_HOME/profiles/web/cordis.patch.yml 的托管区域内：

# >>> dsh-mcp-market managed region >>> …
- insert:
    - id: mcp-market-apifox
      name: '@deepseek-ai/dsh-mcp-client'
      config:
        serverName: apifox
        transport: stdio
        command: npx
        args: ['-y', 'apifox-mcp-server@latest', '--project=…']
        env:
          APIFOX_ACCESS_TOKEN: '…'
# <<< dsh-mcp-market managed region <<<

DSH 的 loader 会热加载 cordis.patch.yml：保存/启停/删除后立即生效，无需重启 dsh web；新增服务会自动连接 MCP 服务器并把工具注册为 mcp__<serverName>__<toolName>，模型可直接调用。

安装

插件声明了 dsh.bundle（自带 cordis.patch.yml 自注册），一条命令即装即用，无需手工追加注册行：

# GitHub 源（推荐，插件市场同款安装路径）
dsh plugin --profile web add github:Mrxieyong/dsh-mcp-market

注：npm 上的 dsh-mcp-market 包名已被另一作者的无关插件占用，请使用上面的 git 源安装。

安装后 loader 热加载生效（首次安装时在浏览器里刷新一次页面）。卸载：

dsh plugin --profile web remove dsh-mcp-market

插件通过 dsh.bundle.patch 自注册，卸载后无需手工清理注册行；面板内删除全部服务后， 托管区域即可移除。

本地开发

node build.mjs          # dist/index.js（host）+ lib/client.js（client）
node --test tests/*.test.mjs
  • host 侧入口 dist/index.js：注册 /api/mcp-market/* 路由（仅限回环请求）， 通过 ctx.webServer 挂载。
  • client 侧入口 lib/client.js：以 window.__ModuleLoader__.load 工厂形式加载， react 系为平台种子模块（无需打包进 bundle）；通过 ctx.slots.inject("sidebar.footer.action", …) 注册左侧边栏入口。

注意事项

  • Token 明文保存在本机 cordis.patch.yml 中（与 DSH 生态其他 MCP 管理方式一致）， 请勿把该文件提交到版本库。
  • Figma 官方远程 MCP 仅支持 OAuth 2.0（不支持 PAT），DSH 纯 HTTP 客户端暂无法直连； Pixso 请使用 token 方式（面板模板已内置正确请求头）。
