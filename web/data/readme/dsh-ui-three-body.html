三体智子（dsh-ui-three-body）

🔥 给 DeepSeek Harness 装上「会开智的智子」：每次对话注入驯兽内核，让 AI 真正听懂人话；悬浮一颗会眨眼、会东张西望、会闪现的恐怖大眼睛，11 款动态皮肤任你切换。一条命令安装，不改 dsh 源码。


智子悬浮演示：原色人眼 / 写轮眼 / 万花筒 / 轮回眼 / 三体智子等 11 款皮肤，瞳孔旋转 + 幽灵闪现


智子菜单：驯兽四式 / 需求剖析 / 皮肤循环切换 / 休眠

✨ 为什么值得装（爆款推荐）

亮点 说明

🎭 11 款动态皮肤 原色（人眼）、深渊、宇宙死瞳、写轮眼、万花筒、轮回眼、三体智子、白眼、血瞳、尸瞳、魔瞳——瞳孔旋转/脉冲、血雾、灰烬、火舌全动态

🗣 反人类气泡 初始化弹出「我这是在哪里？被困在显示屏里了？」等惊悚台词（40% 概率，可关）
🔒 零消耗保证 AI 模式 = token 总闸：关闭时智子纯装饰、每轮零 token（实测铁证）；休眠仅暂停活动
⚙️ 一键直达 悬浮浮层 ⚙️ 直达「设置 → 三体」；菜单一键 /tame、需求剖析、填输入框（新会话也能填）

适合：想让 AI 更听话的打工人 / 喜欢恐怖萌宠的桌面党 / 三体与火影双厨 / 在意 token 成本的效率党。

🎭 悬浮智子

  • 11 款皮肤（设置 → 三体 或 菜单循环切换）： 原色（真实人眼黑瞳）/ 深渊 / 宇宙死瞳 / 写轮眼（三勾玉旋转）/ 万花筒 / 轮回眼（波纹脉冲）/ 三体智子（六边形质子旋转） / 白眼（放射纹旋转）/ 血瞳 / 尸瞳 / 魔瞳
  • 动态层：瞳孔动画 + 光晕脉冲 + 冲击波 + 皮肤特效（血雾/灰烬/火舌/幽灵光带/雷霆/毒泡/星点）
  • 行为：随机眨眼、眼睛跟随鼠标（命令式 GPU 合成，零 re-render）、东张西望（rAF 丝滑，不受鼠标控制）
  • 幽灵模式：鼠标静止 n 秒（3-60s 可调）→ 100% 闪现到远离原位的随机点；东张西望/原地休息可配置开关
  • 初始气泡：40% 概率弹出反人类台词（可随「活物行为」开关关闭）

🧠 内核（开智内容）

lib/kernel.js，三档 × 双语：

档位 token/轮 说明
minimal ~100 极简铁律 + 一句流程
balanced（默认） ~387 三铁律 + 驯兽四式
full ~550 balanced + 官网示例

人设可配：语气（傲慢/温和/热忱）、自称（本尊）、称呼（主上）——首次唤醒弹窗定规矩。

🔒 Token 管控（本次重点改善）

设置 语义 默认
智子活动（内核开智） 不休眠 开
AI 模式 token 总闸：决定是否注入内核 关
休眠（菜单/悬浮点击） 完全暂停 -
  • AI 模式关 = 每轮零智子 token（实测：内核段不在 prompt、无工具、无 LLM 调用）
  • 休眠 = 暂停活动（不注入 + 智子休眠态）
  • beast_analyze 剖析工具默认关（每次调用多一次模型请求）

⚙️ 设置 → 三体

悬浮智子 → 菜单 → ⚙️ 三体设置（或 设置 → 三体）：

  • 智子活动（内核开智）+ AI 模式
  • 悬浮智子开关、尺寸（小/中/大）
  • 皮肤（11 款分段选择）
  • 幽灵模式：开关、间隔秒数、东张西望、闪现
  • 内核档位 / 语言 / 语气 / 自称 / 称呼你
  • 需求剖析工具 / 内核覆盖（自定义内核文本）
