dsh-cyberpunk-theme

一个用于 deepseek-harness（DSH）Web 界面的赛博朋克主题插件。基于官方主题扩展点（ctx.theme / @deepseek-ai/dsh-client-ui-theme），纯视觉定制，不改变模型、agent 或提示词。

效果特性

  • 深蓝黑底色 + 霓虹青主色（#00f0ff）+ 品红点缀（#ff2a6d）
  • 顶部 / 右侧霓虹灯带（LED strip 质感）
  • 光标跟随光晕、按钮 hover 发光、输入框聚焦呼吸脉冲
  • 标题辉光呼吸、滚动条青→粉渐变
  • 对话区底部霓虹倒影 + 角落光斑
  • 设置 → 常规 →「主题皮肤」行，一键切换 浅色 / 深色 / 跟随系统 / 赛博朋克
  • 快捷键 Cmd/Ctrl + Shift + P 在赛博朋克与普通深色之间切换

安装

从 GitHub 克隆并安装：

git clone https://github.com/zjwzjw1018-git/dsh-cyberpunk-theme.git
dsh plugin --profile web add ./dsh-cyberpunk-theme
dsh web

web 是内置的 Web profile，首次使用会自动初始化；换成你自己的 profile 名即可。 若已发布到 npm，也可用 dsh plugin --profile web add dsh-cyberpunk-theme 一键安装。

安装后打开 设置 → 常规，在「主题皮肤」行点选「赛博朋克」即可生效（选择会持久化）。重启 DSH 后插件会自动激活赛博朋克主题。

卸载

dsh plugin --profile web remove dsh-cyberpunk-theme

自定义配色

所有颜色集中在 client.js 的 TOKENS 对象里（覆盖 --dsw-alias-* 变量）：

  • 主色 #00f0ff → 想换品红就改成 #ff00e5
  • 底色 #0a0f1e → 更黑就 #05070a
  • 灯带 / 光晕在文件顶部的注入 CSS 里调整

改完重新执行 dsh plugin 或直接替换 node_modules 里的文件，刷新页面即可。

打包结构

dsh-cyberpunk-theme/
├── package.json        # dsh.bundle + dsh.client 声明
├── cordis.patch.yml    # host 组合树的插入行
├── index.js            # host 侧入口（空 apply）
└── client.js           # 浏览器端 bundle（主题注册 + 设置行 + 特效）
