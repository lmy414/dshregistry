表情包（biaoqingbao）· DeepSeek Harness 插件

让 DeepSeek Harness 里的助手学会用表情包表达自己的情绪与语气。

⚠️ 先说清楚：这是一个第三方社区插件，代码完全开源（MIT）。插件会在你的电脑本地读写图库数据，AI 识图/自动配图等功能会调用你 DSH 里已配置的模型服务（对应文字和图片会发送给模型服务商）。安装即代表你信任本插件来源。 当前 DeepSeek Harness 处于开发者预览阶段（v0.1），插件接口可能随版本演进。

这是干什么的？

你有没有想过，让聊天助手在开心的时候发一张「嘿嘿嘿」的猫猫图，在你委屈的时候回你一张「抱抱」？

这个插件就是干这个的：助手有情绪的时候，会主动调用 express 工具配一张表情包发给你。表情包从哪来？你自己传！传得越多，助手越懂你喜欢什么风格。

它能做什么

  • 😀 情绪配图：助手感受到开心、委屈、心疼、得意、无语等情绪时，自动挑选最合适的一张表情包
  • 🗂️ 图库管理：多选上传（PNG/JPG/WebP/GIF），浏览、搜索、编辑标签
  • 👍 反馈调教：表情卡片上有「喜欢/不喜欢」按钮，点一点，选图会越来越合你心意
  • 🏷️ AI 识图：用你 DSH 里已配置的模型自动给图片打标签（描述/情绪/场景/关键词），支持单张和批量
  • 👀 自动配图观察器（可选）：每轮对话分析情绪波动，有戏的时候悄悄提醒助手发图
  • 🗣️ 方言口音（可选）：东北话、河南话、上海话、粤语、台湾腔、四川话、陕西话、北京话、新疆话，9 种方言随你挑，助手说话自带家乡味
  • 🎭 学我说话（可选）：分析你平时的聊天记录，提炼你的打字风格，让助手模仿你说话
  • ⚙️ 设置页：侧栏「表情包」入口打开管理面板，配图开关、观察器、识图模型、方言、学我说话全部可视化设置

安装

dsh plugin --profile web add <包名>

装完重启 dsh web，侧栏底部出现「表情包」入口：

  1. 打开「表情包」→ 上传你有权使用的图片（可多选）
  2. 聊天中，当助手有情绪时它会主动发图；也可以直接对它说「发个委屈的表情包」
  3. 在表情卡片上点「喜欢 / 不喜欢」调教选图

也可以从 GitHub 安装：dsh plugin --profile web add github:moononnn/DeepSeek-Harness-biaoqingbao

数据与隐私

  • 图库、偏好、使用记录全部保存在本地 ${DSH_HOME}/plugin-data/biaoqingbao/
  • 插件不会上传你的聊天记录
  • AI 识图、自动配图、学我说话会使用 DSH 已配置的模型路由，对应内容会发送给模型服务商
  • 卸载插件不会删除图库数据

兼容性

  • 需要 DeepSeek Harness v0.1（rc 系列）及 Node.js 20+
  • Web 模式完整支持；headless 模式下工具可用但无管理面板

开发

npm run check   # 语法检查（lib + client）
npm test        # 核心逻辑单元测试（node:test，零依赖）

核心纯函数（打分、偏好、标签清洗、频率门控）在 lib/core.js，可独立测试。

与 Hana 版的关系

本插件是 moononnn/hanako-biaoqingbao（Hana 社区表情包插件）针对 DeepSeek Harness 的移植版：Hana 版的工具注册、图库管理、偏好反馈、AI 识图、方言口音、学我说话等核心机制全部保留，按 DSH 的插件体系（dsh.bundle + Cordis）重新实现。
