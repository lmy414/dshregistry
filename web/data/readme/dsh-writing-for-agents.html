dsh-writing-for-agents

DSH（DeepSeek Harness）技能插件：写给 agent 的文档。

写 AGENTS.md/CLAUDE.md/技能/指针文档的方法论：上下文指针与触发分支、双层预算（上下文/认知负载）、信息层级（步骤/参考/渐进披露/就近聚合）、完成标准（可检查+穷尽）、领航词与正向表达、剪枝纪律。受 mattpocock/skills（223k★ MIT）启发的中文原创精简版。

安装

dsh plugin add dsh-writing-for-agents

触发方式

描述中包含"写 AGENTS.md / 写给 agent / 技能文档 / 指针 / 渐进披露 / 领航词 / agent 指令"等关键词时自动触发。

能力

  • 上下文指针与一分支一触发
  • 双层预算与信息层级
  • 完成标准与领航词
  • 正向表达与剪枝纪律
