dsh-prototype

DSH（DeepSeek Harness）技能插件：原型验证。

用可丢弃代码回答设计问题：分支选择（逻辑/状态模型 vs UI 变体）、一次命令可运行、默认无持久化、跳过打磨、状态表面化、完成后归档为一手来源。受 mattpocock/skills 的 prototype（223k★ MIT）启发的中文原创精简版。

安装

dsh plugin add dsh-prototype

触发方式

描述中包含"原型 / prototype / 验证逻辑 / 状态模型感觉 / UI 探索 / 快速验证"等关键词时自动触发。

能力

  • 逻辑 vs UI 分支选择
  • 可丢弃代码六规则
  • 状态表面化与无持久化
  • 验证决策并入真代码 + 归档
