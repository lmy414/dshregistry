DSH Prompt Rail

English | 中文

Prompt Rail is a compact vertical quick-jump rail for the DeepSeek Harness Web conversation view. One mark represents one loaded ordinary user prompt. Hover or keyboard focus shows its preview; clicking scrolls to that prompt.

Behavior

  • The rail stays vertically centered beside the session sidebar.
  • Every mark has a 10px high hit slot, while its default visible mark is an 8px by 3px light line.
  • Hover/focus makes the current mark 28px wide and dark; nearby marks taper to 20px, 14px, and 10px.
  • Clicking records the selected prompt. When the pointer leaves, all marks return to their default length while the selected mark stays dark.
  • Assistant, tool, command, steering, and injected-context rows are excluded. A one-prompt conversation still renders one mark.

One-command installer for source checkouts

The Web view needs the conversation.chat.navigator slot. The installer supports both cases:

  • a Harness checkout that already declares the slot: builds Harness and installs Prompt Rail;
  • a known earlier Harness revision: applies the matching small compatibility patch, then builds and installs Prompt Rail.

The current release supports the pre-slot revision fe2dc3101960bcb17ce4c6f7204b68a70200ed3d. It refuses an unknown or dirty checkout before changing source files.

Keep the Prompt Rail checkout beside the official Harness checkout, then run this single installer command from the Harness root:

node ../dsh-prompt-rail/compat/install.mjs

A different source location or profile is explicit:

node /path/to/dsh-prompt-rail/compat/install.mjs --harness-root /path/to/deepseek-harness --profile web

The installer runs pnpm install, regenerates the public client-slot catalog, builds Harness, and adds this plugin to the selected profile as a local link: dependency. Keep the Prompt Rail checkout at that path. It does not start a long-running server; start Web afterwards:

pnpm dsh web

Windows install and restart

For a Windows source checkout, run the batch file from the Harness root:

.\plugins\dsh-prompt-rail\install-and-restart.bat

It safely stops only a Node process identified as dsh web on port 3080, runs the installer, starts a fresh Web server, waits for the port, and opens the page. If another application owns port 3080, it stops instead of terminating that application. An independently cloned plugin works the same way: from the Harness root, run ..\dsh-prompt-rail\install-and-restart.bat.

When a newer official Harness revision has not yet merged the slot, update Prompt Rail first. Its installer must contain an exact compatibility patch for that revision.

Install or update on compatible Harness

After publishing a tagged GitHub release, a Harness build that already declares the slot can install the immutable release archive directly:

dsh plugin --profile web add https://github.com/Zzzzkd/dsh-prompt-rail/archive/refs/tags/v0.1.0.tar.gz

Restart dsh web after installation. Run the same command with a newer tag to update.

Development

The development layout expects sibling checkouts:

workspace/
├─ dsh/                       # DeepSeek Harness checkout
└─ dsh-prompt-rail/

Then run:

pnpm install
pnpm run check

lib/ is committed because profile installation loads the prebuilt Host and browser files without running package build scripts.

Release checklist

  1. Add an exact compatibility patch for every supported pre-slot Harness revision.
  2. Run pnpm run check and exercise node compat/install.mjs --apply-only in a clean matching checkout.
  3. Commit source, lib/, compat/, README files, screenshot, and lockfile.
  4. Push a v0.1.0 tag and create a GitHub Release from that tag.
  5. State the compatible Harness versions and revision hashes in the release notes.
