dsh-wayfinder

DSH（DeepSeek Harness）技能插件：大工程决策地图。

把超大工程规划为 issue 跟踪器上的共享地图：命名目的地、决策票据（解析决策非执行切片）、逐个解析直到路径清晰、按名字引用、地图只做索引。受 mattpocock/skills 的 wayfinder（223k★ MIT）启发的中文原创精简版。

安装

dsh plugin add dsh-wayfinder

触发方式

描述中包含"大工程 / 方向不明 / 决策地图 / 先解决决策 / wayfinding / 规划庞大任务"等关键词时自动触发。

能力

  • 目的地命名与地图结构
  • 决策票据（非构建切片）
  • 按名字引用与索引化地图
  • 路径清晰即交接

许可
