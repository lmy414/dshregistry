👁️ Eyes · 全球热点监控与市场影响分析

Eyes 是一个全球热点事件监控与影响分析工具，覆盖全球局势、地缘冲突、重大政策、创新技术等可能影响经济和市场的事件，并按行业、汇率、大宗商品链路自动分析传导影响。

✨ 功能特性

🌍 全球热点实时监控

  • 覆盖政治、经济、科技、军事等全领域
  • 事件分级体系：P0（全球重大） / P1（重大政策） / P2（常规事件）
  • 自动判断事件对 A 股、汇率、大宗商品的影响链路

📰 三大定时推送

时段 时间 内容
🌅 早间综览 08:00 过去12小时全球大事 + A股开盘前瞻
⏰ 整点扫描 09:00-19:00 每小时检测是否有新事件，有则推送
🌆 晚间复盘 20:00 全天热点回顾 + 明日关注板块

📊 行业影响分析

  • 按用户偏好行业自动分析（半导体、AI、光模块、新能源等）
  • 热点事件 → 行业利好/利空 → 相关个股影响
  • 汇率、大宗商品传导链路可视化

🔔 智能推送

  • P0 事件：立即推送
  • P1 事件：限时窗口内推送
  • 无重大事件时自动跳过，不打扰

🚀 快速开始

安装

clawhub install eyes

使用方式

直接触发关键词即可：

今日热点      → 查看当天全球大事
大眼看世界    → 最新热点事件汇总
国际市场      → 全球市场动态
今晚热点      → 晚间热门事件回顾

🛠 技术栈

  • Python 脚本（事件采集 + 影响分析引擎）
  • OpenClaw 定时任务（全天候自动监控）
  • Brave / MiniMax Search（全球资讯搜索）
  • 事件分级 + 行业影响传导模型
