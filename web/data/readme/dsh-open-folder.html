dsh-open-folder

DeepSeek Harness / DSH Web UI 插件：在会话页头（Session Header）最右侧的 conversation.session.header.utilities 区域，向 “Session log” 按钮的左边增加一个 “打开工作区” 按钮。

点击按钮后，插件读取当前 Session 的 cwd（当前工作区），通过 Host 的 workspaces.openPath() 调用操作系统打开该文件夹。

功能

  • 使用 conversation.session.header.utilities 列表插槽，不动标题旁的 conversation.session.header.actions 区域。
  • 注册时使用 order: -10，因此会排在默认 order: 0 的 “Session log” 按钮左侧。
  • 按钮在会话没有可用 cwd 时自动禁用。
  • 纯浏览器插件，Host 侧为无操作入口。

文件

dsh-open-folder/
├── package.json       # 包元数据 + dsh.bundle / dsh.client 声明
├── index.js           # Host 侧无操作入口
├── index.d.ts         # Host 侧类型
├── client.js          # 浏览器侧插件（ModuleLoader bundle）
├── client.d.ts        # 浏览器侧类型
├── cordis.patch.yml   # 组合包补丁：把 dsh-open-folder 插入配置
└── README.md

安装

cd C:\Users\Jason-Woo\Desktop
dsh plugin --profile <你的profile> add .\dsh-open-folder

安装后启动 Web UI，打开任意工作区会话，在页头右侧 Session log 左边即可看到 “打开工作区” 按钮。

说明

  • 按钮调用的是 Host 的 workspaces.openPath(cwd)，因此打开的是当前 Session 真正的工作目录，而不是浏览器前端路径。
  • 若当前会话没有 cwd（例如空白/异常会话），按钮会处于禁用状态。
