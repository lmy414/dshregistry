每天早上，情报已替你巡完一圈互联网

🛰️ luxueliu-intel-scout — AI 情报巡检：GitHub 与开发者社区每日自动巡逻，去重、打分、中文提炼，产出「速览+详情」两层日报，挂上计划任务无人值守。

每日自动巡检公开互联网（GitHub / 开发者社区 / 科技源），抓取候选情报 → 网关模型初筛打分 → 本地化摘要 → 生成日报，可经 Windows 计划任务无人值守运行。用于持续追踪 AI 工作流、上下文工程、agent 协作等领域的最新实践。

由 luxueliu 制作并开源。这不是 RSS 阅读器：它有去重状态、多模型打分、中文提炼和产出样例里那种「速览 + 详情」两层日报格式——是给自己训练的私人情报参谋。

设计原则（脚本内置）：只读公开来源；不克隆仓库、不安装任何东西；密钥只从环境变量 / secrets.env 读取；可选的中转模型调用只发送候选元数据，不发送本地私人内容。

不配网关也能跑：纯抓取模式零依赖零费用；配了 LiteLLM 网关才解锁模型打分与中文提炼。

组成

文件 作用
intel_scout.py 主巡检器：搜索公开源 → 去重 → 打分 → 输出候选与简报
intel_chinese.py 中文本地化层：调用网关模型把候选翻译/提炼为中文报告
source_scout.py 数据源扩展巡检器：管理多来源分组（含登录态存在性检查，不读取不解密 cookie）
intel-scout.ps1 手动 / 计划任务入口（环境变量可配模型、条数、输出目录）
daily-source-scout.ps1 数据源巡检的日常入口
register-intel-scout-task.ps1 / register-daily-source-scout-task.ps1 注册 Windows 计划任务
examples/20260824_情报简报_样例.md 真实产出样例（公开科技快讯，速览+详情两层结构）

运行前提

  • Python 3.12+（标准库为主）
  • 可选：本地 LiteLLM 网关 + 环境变量 LITELLM_MASTER_KEY（不配置则跳过模型环节，纯抓取仍可用）
  • GitHub 匿名限额不够时可配 GitHub token（环境变量，不写死在代码里）

快速开始

# DSH 插件（进入市场 / 侧栏；脚本仍在包内）
dsh plugin --profile web add luxueliu/luxueliu-intel-scout

# 小样本试跑（不调任何模型）
powershell -File intel-scout.ps1
# 或注册成每日计划任务（默认 NO_MODELS=1，显式打开才花钱）
powershell -File register-intel-scout-task.ps1

输出目录默认在脚本同级 情报巡检/，可用环境变量覆盖。
