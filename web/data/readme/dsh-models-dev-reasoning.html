dsh-models-dev-reasoning

Fill DeepSeek Harness llm-pi-ai thinking levels from models.dev for third-party / relay models.

启动后读取 models.dev 官方思考档位，写入尚未配置 reasoningEfforts 的 llm-pi-ai 模型。已有配置不会被覆盖。none 映射为 DSH 的 off。

Config / permissions

No plugin config. Injects settings and writes only missing llm-pi-ai.providers.*.models[].reasoningEfforts.

Network: https://models.dev/api.json, fallback https://api.github.com/repos/anomalyco/models.dev/tarball/dev. Cache: %TEMP%\dsh-models-dev-reasoning.json (24h).

No install prepare script.

Install

dsh plugin --profile web add github:aerince/dsh-models-dev-reasoning

Restart DSH Desktop. Thinking levels appear on the model picker for matched third-party models.

Verify

dsh --profile web --dump-config

Confirm models-dev-reasoning is in the composed tree. Then open a llm-pi-ai model that models.dev documents as a reasoner and check the thinking-level selector.

Remove

dsh plugin --profile web remove dsh-models-dev-reasoning

Pinned install

dsh plugin --profile web add github:aerince/dsh-models-dev-reasoning#a6c53fc
