dsh-client-ui-vibecontroller

Floating DualSense controller overlay for the DeepSeek Harness web surface: lights up pressed buttons and fires vibe-coding instructions straight from the gamepad.

Features

  • Live DualSense overlay in the web GUI — pressed buttons light up, sticks track your input
  • 左摇杆 (L3) — push to move the plugin; hold to show every button's bound function
  • 右摇杆 (R3) — push ↑/↓ to raise/lower the model's reasoning level; push ←/→ to cycle the active model
  • △ (Triangle) — breathing orange glow when a session awaits approval/answer; press to jump between those sessions
  • ✕ (Cross) — confirms restart / voice send / compaction; otherwise sends "同意，执行吧"
  • ○ (Circle) — cancels pending actions, stops running tasks
  • Direction pad — plan mode / permission presets / sidebar / new session
  • L1 compaction, L2 restart, R1 goal pause/resume, R2 "continue", Create screenshot, Options settings
  • Settings: keep overlay/cursor in screenshots, display size (5–200%), opacity

Install from GitHub

Requires pnpm on PATH (used by the dsh plugin command).

dsh plugin --profile web add github:squirrelbullet/dsh-client-ui-vibecontroller
# or, for a specific tag:
# dsh plugin --profile web add github:squirrelbullet/dsh-client-ui-vibecontroller#v0.1.0

If you previously installed this plugin manually (the old copy-based flow), the profile's ~/.dsh/profiles/web/cordis.patch.yml still contains a manual insert row for ui-vibecontroller. The bundle layer now inserts that row itself, so revert the profile patch to [] before restarting — two inserts of the same id make the loader throw duplicate loader entry id.

Restart the harness (dsh --profile web) — the overlay appears once a DualSense is connected.

A dsh plugin command is a thin forwarder over pnpm inside the profile directory. Installing the package from git automatically activates it as a profile bundle (the package declares dsh.bundle.patch), and the web surface discovers its client bundle via the package's dsh.client manifest — no manual copying.

Update

dsh plugin --profile web update dsh-client-ui-vibecontroller

Manual (dev) deployment

cp export/lib/client.js ~/.dsh/profiles/node_modules/dsh-client-ui-vibecontroller/lib/client.js

then restart dsh --profile web. The assets/ folder holds the controller PNG layers, the button-position tool (coordinate-tool.html) and the label anchor tool (label-tool.html).
