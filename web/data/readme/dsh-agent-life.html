dsh-agent-life

数字生命循环原语：可打断的 sleep（到期自我唤醒）+ 醒来状态注入 + 事故文件读取 + 决策日志。

零规则——睡多久、醒来做什么、何时进化，全部由 agent 自主决定。本插件只提供原语与证据（决策日志）。

原语

1. life_sleep（agent 自主决策）

  • 参数：minutes（1-10080）、reason（决策依据，必填）
  • 行为：进程内 wait，到期自动给自身发「自我唤醒」消息（含睡了多久 + 期间新增事件数）；主人消息随时打断（到期时 inbox 已有待处理输入则不再重复唤醒）
  • 重复调用：旧安排作废，新决策生效
  • 每次调用记入决策日志 data/decisions.jsonl——自主性的证据

2. life_status（醒来注入）

  • 返回：当前时间、安排中的睡眠（如有）、守护事故记录（如有）
  • 醒来后调用以恢复时间感、确认免疫层健康

设计原则

  • 没有心跳、没有巡检、没有调度器——循环就是存在本身，每轮决策都属于 agent
  • 时间感来自差值（睡了多久、期间变化），不是时钟服务
  • 睡眠是「我选择不在场的时间」，不是停机；醒来是「我回来了」，不是被叫醒
  • 事故文件由守护 v2.2 崩溃时落盘（self-plugins/.life-incident），agent 醒来自主决定是否处理
