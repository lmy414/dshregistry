🔥 dsh-hotspots · 时事热点

DeepSeek Harness（DSH）Web 时事热点插件：侧边栏一键查看实时热点，内容分两大部分——

  • 🤖 AI 大事：大模型 / Agent / skill 插件 / 工作流 / 送 tokens / 免费模型
  • 🔧 工科热点：智能制造 / 机器人 / 政策 / MCU×AI / 企业动态

每条热点包含关键信息提炼与信息来源链接（抖音 / 小红书 / B站 / 知乎 / 微博 / 微信公众号 / 36氪 / 机器之心 / 量子位 / IT之家 / 政府网站等，自动识别平台并标注）。

✨ 功能

  • 侧边栏入口：按钮位于「新会话」之下、「工作区」之上，与任务看板同级（rail 收起模式自动适配为圆形图标）；DOM 注入 + 自愈重建，不依赖官方插槽。
  • 三视图面板：全部 / AI 大事 / 工科热点，自动去重合并、带条数统计。
  • 筛选：关键词本地即时过滤 + 来源 chips 过滤（按出现频率取前 8）。
  • 阅读体验：相对时间显示、已读标记（localStorage 持久化，可一键清除）、Esc 关闭 / R 刷新快捷键、鼠标滚轮滚动列表。
  • 错误透出：搜索服务不可用时面板显示真实原因（含 Firecrawl keyless 限流的恢复倒计时提示）与「复制诊断信息」按钮。
  • 管理卡片：出现在「设置 → Web UI 插件」分区，与其他 Web 插件（任务看板等）统一管理。

📦 安装

作为 dsh 插件包挂载（宿主 half + 浏览器 half 均由 bundle patch 声明）：

dsh plugin --profile <profile名> add link:/path/to/dsh-hotspots

也支持将会话内动态插件形式直接运行（宿主/客户端代码与动态 Cordis 插件同源，详见下文「架构」）。

依赖：宿主进程需已配置 web 搜索缝合（ctx.web，默认 provider 即可）。

🏗 架构

┌─ 浏览器（GUI）─────────────────────────────┐
│ dsh/client.js（lazy-CJS ModuleLoader）      │
│  ├─ 侧边栏按钮（DOM 注入）                  │
│  ├─ 热点面板（React + 本地筛选/已读）       │
│  └─ 设置管理卡片                            │
│        │  GET /api/hot-spots/fetch?refresh=1│
└────────▼───────────────────────────────────┘
┌─ 宿主进程（DSH）───────────────────────────┐
│ dsh/index.js（ESM Cordis 插件）             │
│  ├─ ctx.web.search 聚合查询（AI×4 + 工科×4）│
│  ├─ 失败熔断 / 30 分钟缓存（失败不缓存）    │
│  ├─ 平台识别（PLATFORMS 表 → 来源标注）     │
│  └─ ctx.webServer.register 路由             │
└────────────────────────────────────────────┘
  • 数据流单向：浏览器只经同源 loopback 路由取数，不直连任何第三方；搜索能力完全复用部署已有的 web.search 缝合。
  • 路由为只读 GET + 同源守卫（Origin/Referer 校验），无状态变更面。
  • 宿主 half 零三方依赖（node 内建 + cordis ctx）；浏览器 half 仅需 react（ModuleLoader 已提供）。

⚠️ 数据来源与限流说明

热点数据经 web.search 获取，默认底层为 ModSearch 的 Firecrawl keyless 免费档（每月 1000 次），免费档触发 429 限流时面板会显示真实原因。

恢复途径（任选其一）：

  1. 等限流自动重置（面板会显示预计小时数）；或
  2. 在「设置 → 插件」的 Search engine (ModSearch) 卡片配置免费 API Key（Firecrawl / Tavily / Exa），立即恢复。

插件对搜索失败做了熔断（失败即停、不再并发打满 8 个查询）与失败不缓存（下次刷新自动重试真实来源）。

🔧 卸载 / 管理

  • 安装包形式：dsh plugin --profile <profile名> remove hotspots
  • 动态形式：左下角「插件」徽标面板 → 停止 / 移除
