dsh-web-noOpenBrowser

让 dsh 启动 Web 模式后不再自动打开浏览器。

deepseek harness从0.1.0-rc.8开始，服务启动后默认打开浏览器访问http://127.0.0.1:3080。 如果你不希望这个行为，可以使用本插件。

原理

@deepseek-ai/dsh-web-app 通过 Cordis patch 行 id: web-runtime 暴露 openBrowser 配置， 其值来自 CLI 的 --no-open 标志（经 webStartup 服务注入，默认 true）。

本插件贡献一层 bundle patch，以 id 命中该行并将 openBrowser 整体覆盖为 false。 由于 patch 替换整份 config，故同时重述了 printUrl / surfaceContext / trustedHosts 三个键。

安装

前置要求：已安装 DeepSeek Harness 及其 CLI（dsh 命令可用）。

方式一：直接通过 GitHub 安装（推荐）

dsh plugin --profile web add github:lovezi0/dsh-web-noOpenBrowser
# 锁定版本：dsh plugin --profile web add github:lovezi0/dsh-web-noOpenBrowser#v0.1.0

方式二：clone 后本地安装（开发 / 修改源码场景）

git clone https://github.com/lovezi0/dsh-web-noOpenBrowser.git
cd dsh-web-noOpenBrowser
dsh plugin --profile web add .    # 装入 web profile（profile 名按你的实际配置调整）

注：本插件为纯 Cordis bundle patch（仅 cordis.patch.yml），零 JS、零构建，方式二无需 npm install / npm run build。插件未发布到 npm registry，不支持 dsh plugin add <包名> 的 npm 源安装。

卸载：

dsh plugin --profile web remove dsh-web-noopenbrowser

验证

# 离线验证覆盖生效（dump-config 与真实启动共用同一 applyEntryPatches，不会漂移）
dsh --profile web --dump-config | Select-String -Pattern "web-runtime|openBrowser"
# 预期看到 web-runtime 行的 openBrowser: false

# 实跑验证
dsh --profile web
# 启动后不应再打印：dsh web: opening the default browser; pass --no-open to disable

与 dsh --no-open 的区别

--no-open 需要每次手动加；本插件是持久化默认关闭，一次安装、长期生效。
