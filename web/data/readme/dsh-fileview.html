dsh-fileview

DSH（DeepSeek Harness）插件：让远程浏览器（通过 LAN/VPN 访问 DSH Web 的设备）能在 GUI 里直接查看、编辑、浏览工作区文件。

为什么需要它

DSH 的 host.openPath 被钉死在仅回环可用（PRIVILEGED_METHODS），远程页面点击文件链接必然 403，而 HTTP 层没有通用文件内容端点。本插件补齐这条链路，安全围栏与 DSH 其余表面一致：同源校验 + 绝对路径白名单。

功能

  • 远程页面点文件链接 → 打开 GUI 内浮层查看器（全文本、可滚动、可选中、可编辑、可保存，触摸友好）
  • 左缘「文件」把手 → 目录浏览（多根切换、面包屑、上一级）
  • 回环页面（本机）保持系统默认程序打开，行为不变
  • 编码阶梯：BOM（UTF-8 / UTF-16LE / UTF-16BE）→ UTF-8 → GB18030；保存时保留原编码、BOM 与换行符（CRLF/LF）
  • 二进制文件：图片（PNG/JPG/GIF/WebP/BMP）直接显示，其余给出提示
  • 大文件（> 2MB）分页只读浏览
  • 保存为原子写（临时文件 + rename）

安装与配置

config.roots 是必填的读写路径白名单（绝对目录；子路径放行，其余 403）。config.writeRoots 可选，把保存收窄到子集。未配置时插件安全降级（不注册任何路由），不会让 dsh web 启动失败。

- insert:
    - id: fileview
      name: dsh-fileview
      inject: [webServer]   # 必须：等待 webServer 服务就绪后再注册路由
      config:
        roots:
          - 'D:\workspace'
          - 'C:\Users\me\projects'
        writeRoots:          # 可选：仅允许保存到 D:\workspace
          - 'D:\workspace'

改完组合后重启 dsh web（bundle 层 patch 不热重载）；只改客户端 client.js 刷新页面即生效。

安全设计

  • 同源守卫：浏览器请求带 Origin 时必须与 Host 一致（hostname 比较，容忍反代改写端口）；无 Origin 的调用（如 tailnet 上的 curl）放行，与 /api 姿势一致
  • 路径白名单：绝对路径 + 大小写不敏感包含检查；越权/遍历一律 403
  • 保存限制：内容 6MB 上限；GBK/GB18030 文件拒绝在线保存（无法无损转回），只读预览

兼容性

  • 路径语义面向 Windows；编码阶梯依赖 Node 的 ICU（gb18030 解码）
  • 开发/测试环境：DSH rc.8
