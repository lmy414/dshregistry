安装

需要已安装 DSH 且 dsh web 可正常启动。

从本地目录安装（开发/自托管）：

pnpm install
pnpm build
dsh plugin --profile web add link:$(pwd)
# 重启 dsh web，然后刷新浏览器页面

从 npm 安装（发布后）：

dsh plugin --profile web add dsh-video-bg

替换成你自己的视频：把压缩好的循环片段放到 assets/background.mp4（MP4 / H.264，1440p 或更低，建议 10~15 秒循环）后重新构建，或直接 fork 本仓库。

配置

无配置项。换视频 = 替换资产文件。

已知限制

  • 不透明度滑杆：0 = 调好的半透明观感（与右侧面板同一程度），100 = 完全不透明、背景被完全挡住。0 档可读性由轻量遮罩承载（想要更暗用皮肤中心的 背景遮挡）。搭配半透明皮肤（如 dsh-web-ui 的 鲸吟 whale-song）是可选增强，会再加一层磨砂质感。
  • 浏览器禁止带声音自动播放：音频默认静音，点右下角按钮开启。
  • 视频背景持续占用 GPU 解码，素材请保持短小低分辨率；标签页隐藏暂停是主要防线。
  • 每份安装只支持一个视频。

安全模型

宿主路由（/api/video-bg/video.mp4）仅 GET/HEAD，只流式返回包内固定的单个文件（无路径输入），并拒绝跨站请求（Sec-Fetch-Site / Origin 围栏），与 dsh-web-ui 皮肤中心策略一致。不涉及凭据、用户数据或远程执行。

演示

  1. 启动 dsh web 打开界面。
  2. 刷新页面——视频在界面背后播放，静音。
  3. 用右下角浮动控件：显示器图标按钮还原原背景（再点恢复视频）、播放/停止按钮控制启停、喇叭开/关声音、背景遮挡滑杆（0 = 最透明同右侧面板，100 = 完全挡住）、最后一个滑杆调音量。
  4. 隐藏标签页几秒再回来——播放自动恢复（后台时已暂停）。
  5. 在皮肤中心背景控件里拖 背景遮挡 压暗视频，或设置背景模糊。
