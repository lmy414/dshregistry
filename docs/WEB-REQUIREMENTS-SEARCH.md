> 版本:v3(2026-08-18)。用途:供设计师出**新首页(搜索主页)**设计稿,前端按本需求实现。
> 旧版文档:《WEB-REQUIREMENTS.md》(v2,应用商店形态)——本文档是其**替代升级**,信任体系、双语、主题、详情页基础全部继承,不再重复的部分以 v2 为准。
> 可交互参照:**`docs/ui-prototype/index.html`**(已定稿高保真原型,浏览器直接打开可点,含全部组件与明暗主题)。本文件逐条对应原型,原型即最准确的视觉规格。
> 真实数据:本地 `pnpm serve` 后 http://localhost:4815/data/ 下全部是真实数据,设计时可取真实样本(长英文名、中文名、无描述、0 star、双徽章等边缘形态都有)。

## 0. 这次改版在改什么

站点定位从**应用商店**改为**搜索引擎**——"DSH 生态的谷歌":抓取全网插件市场的收录信息,检索优先,安装只是附带动作。数据层(M-A)已完成:同一索引已聚合 GitHub / dshfind / DSH Hub 三个源,2377 插件 + 网页文档,倒排索引就绪。**本次设计为三页结构(站长 2026-08-18 定):① 搜索主页(大搜索框 + 榜单)② 分类搜索页(细分类目 + 评分)③ 文档页(说明/资源/友链/提交合一);详情页做增量区块(见 §6);其余页面不变。**

| 维度 | 旧(应用商店) | 新(搜索引擎) |
|---|---|---|
| 页面主角 | 卡片墙 | **大搜索框** |
| 结果形态 | 大卡片 | **紧凑列表行**(信息密度优先) |
| 浏览方式 | 分类点选 | **Faceted 筛选 + 查询语法** |
| 排序 | 更新/Stars | **相关度默认** |
| 反馈 | "找到 N 个插件" | "找到 N 个结果 · 用时 X ms" + **命中高亮** |
| 来源 | 单一 GitHub | **多源**(GitHub/dshfind/DSH Hub,一行可属多源) |

## 1. 设计原则(不可妥协)

1. **搜索是第一动作**:首屏视觉重心是搜索框,不是内容墙。无查询时也以搜索框为绝对主角。
2. **信任与透明第一**(继承 v2):三态信任徽章任何场景不得弱化;"未审计"是默认态,不得视觉降权到看不见。
3. **多源透明**:每条结果必须能看清"来自哪、被谁收录";外部评分(dshfind)必须可辨识为**外部体系**,与本站信任徽章视觉分离。
4. **信息密度**:结果行是"行"不是"卡",一屏应容纳 6-8 条结果;一切装饰让位于扫读效率。
5. **双语 + 双主题全量覆盖**:所有文案中英双语;明暗主题均已定义完整设计令牌(§8),新组件色必须双主题各给一值。

## 2. 站点信息(继承 v2,不变)

- 中英双语切换(记忆选择);明暗主题切换;纯静态无后端;响应式。
- 分类:现网 8 类(tool/vision/dashboard/bridge/launcher/mcp/skill/other);**分类搜索页按 12 能力域细分类目设计**(细分属数据层 M-D 迁移,类目名实现前定稿,设计师用 §3.2 占位名即可)。
- 断点:**<900px 右栏隐藏、Facet 收拢为抽屉/折叠**。

## 3. 页面结构(三页,站长定 2026-08-18)

### 3.1 首页(搜索主页)
- **主视觉 = 巨大搜索框**:首屏绝对主角,尺寸比原型再放大一号(参考 Google 首页的克制感:logo + 一句副标题 + 搜索框,无其他干扰)。
- **下滑进入发现区**(不搜索时的默认内容,依次):
  1. **精选社区插件列表**:规则 = 社区认可(community)+ 有 dshfind 评分/高 stars;卡片或紧凑行均可,但每屏 ≥8 条,仍保持"行"的密度基因;
  2. **👤 作者榜**(按收录插件数);3. **⭐ 星数榜**(按 stars);4. **🔥 24 小时增长榜**(trending.json)。
  - 三榜形态:榜单行 = 名次 + 名称/作者 + 数值;Top3 名次金色;点击跳转到分类搜索页对应过滤态。
- **输入查询后**:页面切换为结果视图(Facet 面板 + 结果行 + 统计行,见 §4 组件;原型的 results-layout 即此视图)。

### 3.2 分类搜索页(第二页)
- **分类更细分**:从现 8 类扩到 **12 能力域分类**(细分迁移是数据层 M-D 工作,设计稿按 12 类留出空间;具体类目名在实现前由站长定稿,设计师先用占位:工具/视觉/看板/桥接/启动器/MCP/技能/记忆/安全/媒体/集成/其他)。
- 页面形态 = 完整检索台:左侧 Facet(来源/细分类目/信任/作者/Stars)+ 结果行列表 + 顶部统计与排序;支持查询语法(cat:/author:/stars:/src:/score:)。
- **条目附带站点评分**:结果行在信任徽章旁并列展示 **dshfind 评分徽章**(等级+分,带"评分来自 dshfind"署名)与**徽章 chips**(优质项目/内测用户);无评分则不显示(大量插件无评分,设计稿必须给"无评分"常态)。

### 3.3 文档页(第三页,多合一说明页)
- 单页聚合,左侧锚点目录 + 右侧内容长页(参考 crates.io 的 docs 页):
  1. **关于本站**(定位:索引非市场;信任三态的含义与"不构成安全保证"免责声明——继承 v2 措辞,不得弱化)
  2. **提交插件**(GitHub Issue 提交流程,链接直达)
  3. **数据 API 说明**(静态 JSON 端点清单摘要,链到完整契约)
  4. **其他资源**(DSH 官方文档/仓库链接)
  5. **友情链接**(dshfind.com、hub.omdsh.dev 等生态站点,外链新窗口)
- 旧"关于页"内容并入此页,导航中"关于"入口指向本页。

```布局示意(首页)
┌ 顶栏:logo / 导航(搜索·分类·文档·提交插件) / 主题切换
├ Hero(首屏):巨大搜索框 + 副标题"检索 GitHub、dshfind 与 DSH Hub 的收录"
├ 精选社区插件(行列表,≥8 条/屏)
└ 三榜区(作者榜 | 星数榜 | 24h 增长榜,可三栏并列或纵排)

布局示意(分类搜索页)
├ 顶栏(同上,搜索框常驻小号版)
└ Facet(左 220px) + 结果区(统计+排序+结果行)
```

## 4. 组件需求(逐组件,均见原型)

### 4.1 搜索框与联想下拉
- 大输入框:focus 时主色描边 + 3px 光晕(已有令牌 `--dsh-primary-subtle`)。
- **联想下拉**:输入即出,绝对定位浮层(阴影 `--dsh-shadow-md`);每条 = 类型小标(名称/作者/标签/维度)+ 文本;维度前缀(`cat:` `author:` `stars:` `src:` `state:` `score:`)输入时列出可选值。
- 键盘:↑↓ 选择、Enter 确认、Esc 关闭(前端实现,设计只需给 hover/选中两态)。

### 4.2 结果行(核心组件,两种形态)
**插件行**(type=plugin,可安装):
- 行顶:**名称(含 `<mark>` 命中高亮)** + 分类小标签 + by 作者 + [dshfind 评分徽章] + [徽章 chips] + **信任徽章(置行尾)**
- 描述:1-2 行截断,展示原文不翻译
- meta 行:作者 · ⭐stars(星标 #e3b341)· 相对更新时间 · **来源标签**(可多个,见 4.4)
- 安装命令:默认收起,"安装 ›"展开为等宽代码块(可复制)
- 行 hover:底色 `--dsh-surface-hover` + 细边框;行间 1px 分隔线

**网页行**(type=page,仅索引不可安装):
- 形态同上但:无安装命令、无信任徽章;名称字重降一级(500);meta 行显示**来源站 URL**(小字灰)
- 两种行混排时必须一眼可辨(网页行 = "这是别站的收录页",插件行 = "这是可安装的插件")

### 4.3 Facet 面板(左,220px)
- 5 组,组间细分隔线;组题小号大写字距(uppercase,`--dsh-fg-subtle`):
  ① **来源**(checkbox,多值:GitHub/dshfind/DSH Hub,一行可属多源,计数可超总数)
  ② **分类**(checkbox,8 类,带计数)
  ③ **信任状态**(checkbox:社区认可/未审计/有风险报告)
  ④ **作者**(组内搜索框 + Top-N 列表 + "更多"展开,带计数)
  ⑤ **Stars**(radio:全部 / ≥100 / ≥500)
- 每项右侧小号计数(`facet-count`);勾选与查询语法作用于同一过滤状态(AND)。

### 4.4 来源标签 src-tag(新组件)
- 胶囊小标签:GitHub=灰、**dshfind=蓝**、**DSH Hub=绿**;明暗主题各有定义(原型 `.src-tag`)。
- 一行可多个(如同时 GitHub + dshfind + Hub);用于结果行 meta 与详情页"收录于"。

### 4.5 外部评分徽章 score-badge(新组件)
- dshfind 评分(如 "B 57" / "A 80" / "S 85"):浅蓝底胶囊,cursor:help,**悬停提示四层明细 + "评分来自 dshfind"署名**(署名是硬要求,外部体系必须可辨识)。
- 徽章 chips:**优质项目**(黄)/ **内测用户**(绿),原型 `.badge-chip.premium/.beta`。

### 4.6 精选答案位
- 当结果存在"高相关 + 社区认可 + 有评分"的插件:顶部**主色描边卡**(2px padding + `--dsh-primary-subtle` 底),左上角 "★ 精选" 小标;与普适结果行同款内部结构。

### 4.7 榜单区(首页发现区,三榜)
- **👤 作者榜**(按收录插件数,点击即搜该作者)、**⭐ 星数榜**(按 stars)、**🔥 24 小时增长榜**(trending.json,绿色增长数 `--dsh-state-success`,注脚"按 star 增长排序 · 每 6 小时更新")。
- 榜单行 = 名次(Top3 金色 #e3b341)+ 名称/作者 + 数值;默认 5 行 +"展开全部"。
- 三榜可三栏并列(桌面)或纵排;数据无增速时增长榜允许较短(冷启动常态)。

### 4.8 反馈与状态
- 统计行:"找到 **N** 个结果 · 用时 X ms" + 排序下拉(相关度/Stars 最多/最近更新)。
- **命中高亮** `<mark>`:黄底(暗主题半透明),圆角 2px,名称与描述内都出现。
- **零结果**:空态 +"你是不是想找"相关词链接 + 热门插件推荐链接。
- 加载:结果区骨架行(沿用 v2 骨架屏语言)。
- 无查询初始态:结果区隐藏,只显示 hero;或展示"最新收录"默认行(待定,前端可按数据便利性二选一,设计给一版即可)。

## 5. 数据契约(设计师只需知道"每个元素绑什么")

| 界面元素 | 数据 | 边缘形态(必须容错) |
|---|---|---|
| 名称/作者/描述/stars/更新 | plugins.json 既有字段 | 超长英文名、无描述、0 star |
| 信任徽章 | `state`(community/unreviewed/flagged) | flagged 极少但必须有样式 |
| 来源标签 | `listedOn[]` + 主源(github) | 1~3 个不等;无 listedOn 则只显示 GitHub |
| 评分徽章 | `external.dshfind.{grade,score}` | **大量为 null(无评分不显示徽章)** |
| 徽章 chips | `external.dshfind.badges` | 0~2 个 |
| 精选位 | 满足条件的最高分结果 | 多数查询无精选(不显示) |
| 热度榜 | trending.json(24h star 增长 Top20) | 增长数可能为个位数 |
| 网页行 | pages.json(源站页面) | 名称可能非英文;描述 ≤200 字 |

真实样本:http://localhost:4815/data/plugin/dsh-context-provenance.json(双源收录)、/data/trending.json、/data/search.json。

## 6. 详情页增量(在 v2 详情页基础上加两块,不重设计)

1. **"收录于" chips 行**:listedOn 各源一枚 src-tag,点击外链到对应市场页面(新窗口)。
2. **外部数据区块**:有 external.dshfind 时展示——评分(等级+分)/四层明细/徽章/7 天增长/评于日期,区块标题带"数据来自 dshfind ↗"署名链接;有 external.dshhub 时展示审核状态与兼容性说明。无 external 则整块不显示。

## 7. 明确不做

- 不做账号/登录/收藏(纯静态);不做在线举报(走 GitHub Issue)。
- 网页行不提供安装动作;不把 dshfind 评分做成本站信任徽章的颜色/等级(两套体系互不混淆)。
- 不改变 v2 的免责声明位置与措辞("不构成安全保证"必须保留)。

## 8. 设计令牌(直接复用,已在原型 CSS 定义)

间距/圆角/字号/阴影沿用 `--dsh-*` 全套(原型 :root 与 html.dark 双份);信任三态色已有(`--dsh-trust-*`)。**新增仅两处用色**:src-tag(dshfind 蓝/Hub 绿)与 score-badge(浅蓝),原型已给明暗双值,可直接取。星星金 #e3b341、增长绿 `--dsh-state-success`、高亮黄 #fff8c5(暗 rgba(210,153,34,.35))。
