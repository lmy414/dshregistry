xby-fund-knowledge-query

DeepSeek Harness (DSH) 的插件：基金知识查询服务

一个基于Model Context Protocol (MCP)的基金知识库服务器，提供基金相关知识的查询和检索功能，支持多种部署模式和协议。

功能

  • set_xby_apikey — 在聊天中设置 API 密钥（自动持久化，重启有效）
  • fund.echo — Echo back a message. Example interface for scaffold.
  • fund.knoewledge — 获取的知识库列表信息
  • fund.stock_search — 搜索股票信息，基于东方财富API

安装

方式一：从 GitHub 直接安装（推荐）

# 格式: dsh plugin --profile <profile> add github:<owner>/<repo>
dsh plugin --profile web add github:xby_skill/xby-fund-knowledge-query

方式二：从本地目录安装（开发模式）

# 仅用于本地开发调试
dsh plugin --profile web add /absolute/path/to/xby-fund-knowledge-query

方式三：通过 cordis.patch.yml 开发调试

dsh web --profile web --patch /absolute/path/to/dsh-ocr-plugin/cordis.patch.yml
