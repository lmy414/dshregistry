DSH Skill Manager

DSH Skill Manager 是 DeepSeek Harness 的独立技能管理器插件。它通过官方插件扩展点加入设置页，并管理官方文件系统 Skill 提供器已经支持的用户技能目录；不修改 Harness 源码，也不替代官方 Skill 注册、发现、加载和调用链路。

项目主页：GitHub；正式安装包：Releases。

第一版能力

  • 在“设置 → 技能”查看当前选中会话通过官方 skill.list 返回的可调用 Skill。
  • 从本地文件夹或 ZIP 安装一个包含 SKILL.md 的 Skill 包。
  • 更新、启用、停用和卸载由本管理器安装的 Skill。
  • 会话可用 Skill 与管理器拥有的用户 Skill 分区显示，不混淆“当前可调用”和“文件已启用”。
  • 安装拒绝同名覆盖；更新先备份旧版本，再替换新版本。
  • 卸载把文件移入管理器回收区，不直接永久删除。
  • 官方文件系统 Skill 提供器负责热刷新；普通 Skill 操作不修改 Profile，也不要求重启 Harness。

边界

管理器只拥有带 .dsh-skill-manager.json 标记的 Skill 目录。项目 Skill、手工安装的用户 Skill、.agents Skill、预设内置 Skill 和其他插件提供的 Skill 都不属于管理器。页面的“当前会话可用技能”直接复用 Harness 官方会话级目录，只读展示；“管理器拥有的用户技能”只展示管理器可以安全执行生命周期操作的目录。

“用户目录已启用”表示文件位于 <DSH_HOME>\skills，不等于它一定在每个会话中胜出。项目或预设中的同名 Skill 仍可能按官方优先级覆盖它；以页面上当前会话区的结果为准。

安装管理器插件本身仍使用 Harness 官方的 dsh plugin 流程，并在安装、更新或移除插件后重启 Harness。管理器界面不会调用 dsh plugin add/remove，也不会修改 Profile 的 package.json。

安装

先在本仓库生成安装包：

pnpm.cmd install
node scripts/build.mjs
npm.cmd pack --pack-destination artifacts

使用正式插件流程安装到 Web Profile：

dsh plugin --profile web add D:\deepseek\dsh-skill-manager\artifacts\dsh-skill-manager-0.1.4.tgz

重启 dsh web 后，打开“设置 → 技能”。完整安装、更新、卸载和使用步骤见 使用手册。

Skill 包格式

文件夹或 ZIP 必须只包含一个 Skill。既支持 ZIP 根目录直接放置 SKILL.md，也支持外层只有一个同名目录：

my-skill/
├─ SKILL.md
├─ references/
└─ scripts/

SKILL.md 至少声明官方要求的字段：

---
name: my-skill
description: 何时使用这个技能
---

# 使用说明

name 必须使用小写 kebab-case。安装后的目录名会统一为 name。

开发验证

node scripts/typecheck.mjs
node node_modules/vitest/vitest.mjs run
node scripts/build.mjs

架构与安全不变式见 架构说明。

第一版暂不包含

  • GitHub 地址安装、在线市场和自动更新源。
  • 管理器回收区与备份区的图形化恢复界面。
  • 跨所有历史会话批量枚举 Skill；页面只查询当前选中的普通会话。
  • 管理任意 Harness 插件或替代官方 Skill 功能。
