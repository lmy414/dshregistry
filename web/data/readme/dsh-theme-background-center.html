dsh-theme-background-center

给 DeepSeek Harness（dsh）Web UI 的主题美化插件，一个面板搞定主题、背景、氛围灯。

功能

  • 🎨 主题切换：深夜蓝 / 护眼绿 / 赛博朋克 / 纸墨白，另有一键随机配色
  • 🌈 梦幻渐变背景：梦幻紫 / 薰衣草 / 极光 / 蜜桃，自带缓慢流动动画
  • 🖼️ 自定义图片背景：上传本地图片作背景，自动压缩，透明度可调
  • 🧊 毛玻璃：一键给面板加磨砂质感
  • 💡 环绕流动氛围灯：输入框边缘霓虹灯管光环 + 邻近色渐变光带流动，7 色可选、速度 1～10 秒可调
  • 💾 自动保存：所有设置刷新 / 重开后自动恢复

效果预览

安装

前置：已安装 DeepSeek Harness（Node.js 22.19+ 或 24+），能运行 dsh。

git clone https://github.com/syOPV/dsh-theme-background-center.git
cd dsh-theme-background-center
dsh plugin --profile web add .

安装后重启 dsh web 即可。

使用

  1. 打开 Web UI，进入 设置 → 常规
  2. 找到「主题背景」面板
  3. 点主题 / 选渐变 / 上传图片 / 开毛玻璃 / 挑氛围灯颜色，即时生效
