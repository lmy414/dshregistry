协作涌现智能（Collaborative Emergent Intelligence）

认知边界钻探机 · DSH 动态插件 一台装在 DSH 里的插件化认知工具：人握方向盘，机器是自动机械。

这是什么

把「发散 → 捕获 → 共振 → 涌断 → 显影 → 凝结」的认知呼吸循环工程化为一个插件。 理论根基：AI 的幻觉与涌现是同一个低概率选择机制的两面（涌现=有利的低概率选择，幻觉=不利的低概率选择），算法无法自己区分——因此算法永远不做最终选择，人永远不自己穷举可能性。

核心公式：协作涌现智能 = 工程化发散（AI）+ 直觉化收敛（人）

安装（DSH 会话内重建）

  1. 新对话中告知："读取 collaborative-emergent-intelligence 包内的 cei-host.js 与 cei-client.js，用 cordis_define 重建协作涌现智能插件并运行"；
  2. Agent 读取源码 → cordis_define（idPrefix: cei）→ cordis_run；
  3. 页面批准插件运行（Client 包需批准）；
  4. 机器启动即从矿区 9 档案恢复全部记忆，对话栏出现灯条。

使用（双轨操控）

  • 对话："进入发散" / "把XX记成碎片，领域YY" / "探测frag-3，auto档" / "选候选B，理由是…" / "盲区是……" / "凝结"
  • UI：对话栏灯条（发散/收敛/过渡 + 裁决/显影按钮）；裁决弹窗仅在三裁决点出现
