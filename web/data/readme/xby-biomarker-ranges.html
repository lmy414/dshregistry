xby-biomarker-ranges

DeepSeek Harness (DSH) 的插件：生物年龄计算服务

基于Morgan Levine PhenoAge时钟模型，通过血液生物标志物计算生物年龄的服务。

功能

  • set_xby_apikey — 在聊天中设置 API 密钥（自动持久化，重启有效）
  • calculate_phenoage — Calculate biological age using the Morgan Levine PhenoAge clock based on blood biomarkers
  • get_biomarker_ranges — Get reference ranges and optimal values for PhenoAge biomarkers

安装

方式一：从 GitHub 直接安装（推荐）

# 格式: dsh plugin --profile <profile> add github:<owner>/<repo>
dsh plugin --profile web add github:xby_skill/xby-biomarker-ranges

方式二：从本地目录安装（开发模式）

# 仅用于本地开发调试
dsh plugin --profile web add /absolute/path/to/xby-biomarker-ranges

方式三：通过 cordis.patch.yml 开发调试

dsh web --profile web --patch /absolute/path/to/dsh-ocr-plugin/cordis.patch.yml
