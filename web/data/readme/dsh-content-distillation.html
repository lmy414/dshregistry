dsh-content-distillation

DSH（DeepSeek Harness）技能插件：把书/长视频/播客蒸馏成可调用的 AI skills。

RIA-TV++ 七阶段流水线：Adler 分析阅读 → 5 个并行提取器（框架/原则/案例/反例/术语）→ 三重验证筛选（跨域佐证/预测力/独特性，通过率 25-50%）→ RIA++ 构造（引用/重写/案例/触发场景/可执行步骤/边界）→ Zettelkasten 链接 → 压力测试（诱饵题）→ 交付（DIGEST.md + 可安装 skills）。受 kangarooking/cangjie-skill（8.4k★）启发的中文原创精简版。

安装

dsh plugin add dsh-content-distillation

触发方式

描述中包含"把书蒸馏成 skill / 方法论提取 / 内容蒸馏 / 看完书用起来 / 长视频转技能包"等关键词时自动触发。

能力

  • Adler 分析阅读四步拆解
  • 5 个并行提取器
  • 三重验证筛选（严格淘汰）
  • RIA++ 六维构造
  • Zettelkasten 引用图
  • 诱饵题压力测试
  • 交付 DIGEST.md + 可调用 skills
