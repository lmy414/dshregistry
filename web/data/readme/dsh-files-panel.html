dsh-files-panel

中文 | English

会话标题栏最右边多一个图标，挨着 Session log。点开就是当前工作区的文件树：Markdown 直接预览，源码带高亮。

这是 DeepSeek Harness 的非官方插件。不改 DSH 内核，也不抢官方 details 栏——那是工具检查器的位子。

跟 DeepSeek 官方没关系。

安装

git clone https://github.com/aa2246740/dsh-files-panel.git
dsh plugin --profile web add file:./dsh-files-panel

file: 前缀留着，peer 依赖要从 profile 里解析。装完重启 dsh web。

进一个已经开过的会话（空白页没有标题栏），点最右边那个图标。

看一眼

点标题栏图标 → 右侧打开文件树 → 再点一个文件：

文件栏关着。图标在标题栏最右边，紧挨 Session log：

打开之后，右边是当前工作区的文件树：

点一个 .md，面板里是 Markdown 预览：

点一个 .ts / .tsx，面板里是带高亮的源码：

卸载

dsh plugin --profile web remove dsh-files-panel
