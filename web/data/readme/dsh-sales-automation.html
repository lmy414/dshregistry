dsh-sales-automation

DSH（DeepSeek Harness）技能插件：销售自动化与客服。

冷邮件序列（个性化/3-5 触点/单一 CTA）、跟进节奏、提案与社证、异议处理脚本、客服共情响应与闭环、打开/回复/转化度量。受 wshobson/agents（38k★ MIT）启发的中文原创精简版。

安装

dsh plugin add dsh-sales-automation

触发方式

描述中包含"冷邮件 / 销售外联 / 跟进邮件 / 提案 / 异议处理 / 客服响应 / 线索培育"等关键词时自动触发。

能力

  • 3-5 触点邮件序列与个性化变量
  • 提案/案例/异议脚本模板
  • 客服共情响应与闭环
  • 打开/回复/转化跟踪与 A/B 测试
