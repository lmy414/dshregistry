关于本站

DSH-Registry 是 DSH 生态的聚合检索平台：自动扫描门户导航网站（dshfind、DSH Hub 等）以及 GitHub 上的 DSH 插件收录，提取元数据并建立倒排索引，方便快速检索与发现。本站定位是「检索优先」——只存元数据（名称、描述、作者、Stars 等），不镜像任何插件代码。

收录来源共三个：GitHub（带 dsh-plugin topic 或提交收录种子的仓库）、dshfind（插件评分与发现平台）、DSH Hub（社区站）。数据每 6 小时自动同步一次，全部插件默认标记为「未审计」。

站长精选

站长精选：由站长根据维护活跃、生态以及个人体验，选择出的一批插件推荐给大家。由于版本、环境、时效等差异，精选插件不代表一定能运行，也不代表一定安全——安装前请自行评估源码，风险自负。

提交插件

想让你的 DSH 插件被 DSH-Registry 收录？推荐通过 GitHub Issue 主动提交，附上仓库地址与简要说明，站长审核通过后下次同步（≤6 小时）自动上线。

  1. 1
    打开提交模板，填写 owner/name 形式的仓库地址与说明。
  2. 2
    确认仓库满足收录条件：在 package.json 中声明 dsh.bundle.patch，且仓库包含 README 与 LICENSE。
  3. 3
    提交 Issue，站长审核并合入收录种子后，插件在下次爬取时自动收录。
注意：收录不等于审计。进入索引的插件默认状态仍为「未审计」，安装风险自负。

数据 API

DSH-Registry 是纯静态站点，所有数据以 JSON 形式公开（当前 schemaVersion 1.1），零后端、可自由调用。端点为站内静态文件，无速率限制，但请合理使用。

端点 说明

静态 JSON 零后端：数据层就是一个公开的 Git 仓库，每次变更都是一次可审计、可回滚的 commit。
