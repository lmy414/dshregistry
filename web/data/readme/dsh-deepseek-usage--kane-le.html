dsh-deepseek-usage

DeepSeek API 用量与余额查看插件（DSH Plugin）。安装后在 Web 界面输入 /usage 即可查看：

  • 余额：实时查询官方 GET https://api.deepseek.com/user/balance（账户可用状态、各币种总余额 / 充值余额 / 赠送余额）。
  • 用量：DeepSeek 官方 API 没有公开的用量查询接口，因此用量由 本机 DSH 会话日志（$DSH_HOME/sessions/*/*/session.jsonl[.zstd]）汇总，包含插件安装前的历史记录，并在插件运行时实时跟踪新用量。

用法

命令 说明
/usage 完整报告：本机累计 token 用量 + 实时余额
/usage balance 仅查询余额
/usage rescan 强制重新扫描全部会话日志后输出完整报告

API Key 解析顺序

  1. 官方 credentials 服务（Web「设置 → 模型」写入的 $DSH_HOME/.credentials.yaml）；
  2. 环境变量 DEEPSEEK_API_KEY；
  3. $DSH_HOME/.credentials.yaml 中的 DEEPSEEK_API_KEY 行。

接口地址可通过 DEEPSEEK_BASE_URL 环境变量覆盖，默认 https://api.deepseek.com。

数据与幂等性

用量账本保存在 $DSH_HOME/storages/deepseek-usage.json，按 会话:回合:步骤 键去重合并：

  • 实时事件与日志回扫共用同一键空间，不会重复计数；
  • 日志按文件大小 + mtime 做增量扫描，首次扫描后每次 /usage 只读取新增内容；
  • 会话日志为 zstd 多帧格式，插件用 node:zlib 按帧解码，无需外部工具。

安装

dsh plugin --profile web add /path/to/dsh-deepseek-usage

重启 dsh web 后生效（插件会自动加入 profile 的 bundles）。
