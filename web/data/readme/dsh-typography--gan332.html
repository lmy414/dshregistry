dsh-typography

DeepSeek Harness Web UI 的字体自定义插件 —— 界面字体与代码字体两组独立选择，内置在线预设，支持本地字体库（woff2 / ttf / otf，无需转换）。

安装后出现在 设置 → 通用 → 字体（界面 / 代码）。

特性

  • 两组独立控制：界面字体改写 --dsw-font-family，代码字体改写 --ds-font-family-code（DSH 全部组件经 var() 消费的官方入口），互不影响
  • 在线预设：Inter + JetBrains Mono、IBM Plex Sans + Fira Code、Noto Sans SC（简中全覆盖）；字体文件走 jsDelivr CDN，离线自动回退系统字体
  • 本地字体库：把任意 woff2/ttf/otf 丢进 %DSH_HOME%\typography\，刷新后即可在设置里一键应用 —— TTF 直接可用，不需要转换成 woff2
  • 可变字体友好：字重可选“可变·全字重”，生成 font-weight: 100 900 的 @font-face，粗细真实呈现
  • 自定义导入：字体名 + 链接 + 字重；链接接受 http(s) 直链或同源路径
  • 默认即放手：某组选“默认”时不写任何变量，可与其它字体插件共存

安装

DeepSeek Harness 有两个常见入口，各自有独立的 profile：

入口 profile 默认端口 说明
DSH Desktop 桌面应用（日常主入口） desktop 43120（占用时自动 +1 重试） 桌面窗口渲染的 UI
dsh web 命令行 web 3080 终端启动的独立服务器

两者共用同一个 $DSH_HOME，但 bundles 列表相互独立 —— 在哪个入口用，就装进哪个 profile：

# 装进 DSH Desktop 桌面应用
dsh plugin --profile desktop add -w /path/to/dsh-typography

# 装进命令行 dsh web
dsh plugin --profile web add -w /path/to/dsh-typography

# GitHub / npm 同理：dsh plugin --profile <name> add github:<user>/dsh-typography

桌面端注意事项：

  • 终端 dsh plugin ... add 会把变更记入一个恢复事务，重启应用后自动验证并清理，插件随之生效。
  • 该事务全局只有一个槽位：连续安装多个插件时，每装一个需重启一次应用再装下一个。
  • 桌面端「设置 → 插件」里可以看到本插件（bundle dsh-typography）并可停用/启用。

使用

  1. 打开对应入口的界面 → 设置 → 通用 → 字体（界面 / 代码）
  2. 每组在卡片行选择：默认 / 在线预设 / 自定义
  3. 导入自定义字体：填 字体名 + 字体链接 + 字重 后点“添加”；同名字体同一字重复加会覆盖
  4. 本地字体库：文件放入 %DSH_HOME%\typography 后刷新页面，点击文件名即以“可变·全字重”应用到当前组

字体链接写法

导入表单接受三种链接，优先推荐同源相对路径（与端口无关，桌面端端口漂移也不受影响）：

/plugins/dsh-typography/files/MiSansVF.ttf          ✅ 推荐（同源路径）
http://127.0.0.1:43120/plugins/dsh-typography/...   ⚠️ 可用，但端口变化后失效
https://cdn.example.com/some-font.woff2             ✅ 外部 CDN 直链

MiSans 示例（无需转换）

copy C:\Users\fish\Downloads\MiSansVF.ttf %DSH_HOME%\typography\

刷新页面 → 界面字体组 → 本地字体库 → 点击 MiSansVF。本地字体库由两个 profile 共享。

工作原理

  • 浏览器半边 apply 时把注册表挂为 ctx.typography（ctx.get("typography") 可消费）
  • 选择变更时重写注入的 <style id="dsh-typography-style">：@font-face 规则 + 仅覆盖非默认组的 CSS 变量
  • host 半边注册 /plugins/dsh-typography/files/* 路由分发 %DSH_HOME%\typography 下的字体文件（?list=1 返回文件名 JSON）；按扩展名给出 font/woff2 | font/ttf | font/otf
  • 偏好持久化在浏览器 localStorage（dsh-typography:prefs），启动时恢复

与 dsh-fonts 的关系

两者可同时安装：本插件每组选“默认”时完全不输出样式，不会覆盖 dsh-fonts 的选择；任一组选中预设/自定义时，因本插件的设置行与样式表排在后面，对应变量以本插件为准。只想要其中一个时：

dsh plugin --profile desktop remove dsh-fonts   # 桌面端；web 端把 profile 换成 web 即可

已知限制

  • 在线预设需要联网；离线时回退系统字体栈
  • 本地库文件名需以字母/数字开头（Unicode 字母即可，中文文件名可用）
  • 少量组件硬编码了 Inter, var(--dsw-font-family) 优先栈（如工作区浏览器），装了 Inter 的系统上这些位置仍显示 Inter
