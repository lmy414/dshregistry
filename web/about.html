什么是 DSH

DSH(DeepSeek Harness,dsh)是由 DeepSeek AI 开发的开源 agent harness(智能体框架),采用「一切皆插件」的架构,由 Cordis 驱动。目前处于开发者预览阶段,正在快速迭代。安装 Node.js 后运行 npx @deepseek-ai/dsh web 即可启动 Web UI(默认 http://127.0.0.1:3080)。

插件是 DSH 扩展能力的唯一方式——视觉理解、数据看板、环境桥接、工作流集成等都由插件承载。DSH-Registry 是社区驱动的 DSH 插件索引站:自动聚合 GitHub 上的开源 DSH 插件,方便开发者发现、浏览和安装。本站没有数据库和后端,数据层就是一个公开的 Git 仓库——索引每次变更都是一次可审计、可回滚的 commit。

特性 Features

自动索引

爬虫每 6 小时扫描 GitHub 上带有 dsh-plugin topic 的仓库;也可以直接向 config/seeds.json 提交 PR 主动收录。

透明评级

三级信任标识(未审计 / 社区认可 / 有风险报告),达标依据全部公开,风险等级一目了然。

Git 数据层

索引数据全量存于公开 Git 仓库,每次变更一次 commit:可 diff、可回滚、社区可审计,服务器宕机 clone 即恢复。

快速开始 Quick Start

在 DSH 中安装插件只需一条命令(详情页可复制,含锁定的 commit):

$ dsh plugin --profile web add github:<owner>/<repo>#<commit>

浏览插件的步骤:

# 1. 打开 DSH-Registry 插件市场 $ open https://dshregistry.xyz # 2. 搜索/按分类找到感兴趣的插件,进入详情页 # 3. 复制安装命令并在终端执行(重启后生效) $ dsh plugin --profile web add github:<owner>/<repo>#<commit>

如何提交插件 How to Submit

想要让你的 DSH 插件被本站收录？方式一(推荐):提一个 Issue——点导航栏「提交插件」直达提交模板,填上仓库地址即可,无需 fork 本仓库。站长审核加入收录种子后,下次爬取(≤6 小时)自动收录上线。 注意:收录不等于审计,收录仅表示进入索引,插件默认状态仍为「未审计」。

1

打开提交模板

点导航栏「提交插件」,直达本仓库的 Issue 提交表单。

2

填写仓库地址

形如 owner/name;确认仓库已声明 dsh.bundle.patch、有 README 与 LICENSE,然后提交 Issue。

3

自动收录

站长审核通过并合入收录种子后,服务器下次同步(≤6 小时)重新生成索引,插件自动上线,默认标记为「未审计」。

方式二(被动):给你的 GitHub 仓库添加 dsh-plugin topic,并在 package.json 中声明 dsh.registry 元数据(推荐),爬虫每 6 小时扫描时会自动发现符合条件的仓库。
