DSH Plugin: LLM Provider - xAI Grok

中文 | English

允许接入 xAI / Grok 的 Coding Plan 作为 LLM Provider，让 DeepSeek Harness 能够自动同步官方最新的 Grok 系列模型列表，并在模型下拉菜单中一键选用 grok-4.6 等最新强力模型。

适用人群与场景

适合拥有 xAI API Key 或 xAI 订阅，想要在 DeepSeek Harness 工作台中体验 Grok 4.6 最强编程与逻辑推理能力的用户。

核心特性

  • 官方模型实时同步：自动核对 xAI 官方 /models 端点，动态发现账号下可用的 Grok 系列模型。
  • 开箱即用支持 Grok 4.6：内建严格测试过的参数配置（包括上下文容量、最大输出上限与推理控制），选了就能直接稳定工作。
  • 安全凭据隔离：xAI 凭据完全保留在 Harness 宿主安全存储内，插件自身仅接收脱敏后的模型描述数据。
  • 零额外开销：不添加任何额外提示词、请求头、Token 损耗或传输层修改。

极简安装与使用

请把经过评审的提交安装进指定的 DeepSeek Harness profile。仓库携带 dsh.bundle 配置和预构建运行文件，通过 Git 安装无需在本地执行构建：

dsh plugin --profile <profile> add github:OpenSaozi/dsh-xai-catalog#<commit-sha>

安装后，插件会自动在 Cordis 配置中注入以下内容（profile 基础 bundle 已提供 llm-pi-ai 路由）：

- id: model-catalog-xai
  name: '@deepseek-ai/dsh-model-catalog-xai'

配置说明：实际推理继续经由 @deepseek-ai/dsh-llm-pi-ai 的标准 xai 路由执行，本插件专注于模型清单与可用性管理。

参与贡献

欢迎提交 issue 和范围明确的 pull request。新模型描述必须附带准确模型 id、协议、输入类型、上下文与输出上限、推理控制和价格的证据。请同时更新中英文 README，并在版本匹配的 DeepSeek Harness 工作区中运行包测试。

模型看到的内容

没有本包自带的文本。插件只决定现有 pi-ai 适配器可以选择哪个 xAI 模型描述，例如 grok-4.6；请求转换由适配器负责。

Token 影响

没有直接 Token 影响。分词和上下文占用仍由所选 xAI 模型及 pi-ai 协议实现决定。

KV Cache 影响

没有直接影响。切换模型可能改变供应商端缓存的适用性，但本插件不会增加请求内容。

已知限制与暂缓事项

  • 插件挂载、路由设置变化或受管凭据变化时会刷新。刷新失败或尚未配置认证时，会保留代码维护的清单并记录错误，不会用空数据覆盖清单。
  • Models 接口只能证明模型当前可用，不能证明协议、上下文容量、输入类型或推理控制。新 id 必须先补齐经过验证的描述，才会显示。
  • 本包不执行 OAuth 登录；它只使用 llm-pi-ai 已为 xAI 路由配置好的 OAuth 凭据。
