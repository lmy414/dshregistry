Quick Draw Tool

作者：尹本风（Yinbenfeng）

仓库：Yinbenfeng/dsh-plugin-quick-draw-Tool-

A small DSH plugin that adds a ComfyUI text-to-image panel. It pins a tested ComfyUI version and ships an API workflow, while leaving PyTorch and model weights to the user.

Scope

  • Windows x64 + NVIDIA CUDA is the first supported target.
  • PyTorch and GPU drivers are installed by the user.
  • ComfyUI is cloned at a tested tag by scripts/setup.ps1.
  • The workflow uses only built-in ComfyUI nodes; no custom node package is required.
  • Model weights are never included or automatically redistributed.

Install

  1. Install Node.js >=22.19, Git, Python 3.12.x, and a PyTorch build compatible with your NVIDIA driver.
  2. Install DSH and install this plugin from GitHub:
npm install git+https://github.com/Yinbenfeng/dsh-plugin-quick-draw-Tool-.git

The package is not published to the npm registry yet; it is distributed from this GitHub repository.

  1. Run the setup script from the package directory. By default ComfyUI is installed at %USERPROFILE%\.dsh\comfyui-drawing\ComfyUI:
powershell -ExecutionPolicy Bypass -File .\scripts\setup.ps1
  1. Download the three required model files yourself and place them according to manifests/models.json.
  2. Start the pinned ComfyUI instance and restart DSH. The default endpoint is http://127.0.0.1:8188.

Manual profile wiring

Add the package to the DSH profile dependencies and bundle list:

{
  "dependencies": {
    "dsh-plugin-quick-draw-tool": "git+https://github.com/Yinbenfeng/dsh-plugin-quick-draw-Tool-.git"
  },
  "dsh": {
    "profile": {
      "bundles": [
        "@deepseek-ai/dsh-base",
        "@deepseek-ai/dsh-web-app",
        "dsh-plugin-quick-draw-tool"
      ]
    }
  }
}

Keep the profile's existing bundles and append dsh-plugin-quick-draw-tool; do not replace the whole list with this example.

The plugin and scripts also accept these environment variables:

  • DSH_COMFYUI_ROOT: installation directory used by the PowerShell scripts.
  • DSH_COMFYUI_URL: ComfyUI endpoint, default http://127.0.0.1:8188.
  • DSH_COMFYUI_WORKFLOW: absolute path to an API-format workflow.
  • DSH_COMFYUI_PRESETS: path for prompt-2 presets.
