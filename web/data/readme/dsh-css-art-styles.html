dsh-css-art-styles

DSH（DeepSeek Harness）技能插件：CSS 艺术风格配方。

为落地页/UI 提供可复用视觉风格系统：液态玻璃（两档变体）、电影感太空等美学配方——设计系统（色彩/字体/圆角/间距）、工具类 CSS、入场动效、布局骨架。受用户收藏 xuanxuan321/xuanxuan-prompts 启发的中文原创精简版。

安装

dsh plugin add dsh-css-art-styles

触发方式

描述中包含"视觉风格 / 液态玻璃 / glassmorphism / 落地页美学 / CSS 艺术 / 风格配方"等关键词时自动触发。

能力

  • 风格配方结构（设计系统/工具类/动效/骨架）
  • 液态玻璃等风格示例
  • 全站一致应用纪律
  • 可访问性（对比度/减少动效）
