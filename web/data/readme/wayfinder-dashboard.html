Wayfinder Dashboard

DeepSeek Harness 插件

English

把 Matt Pocock 的 Wayfinder 做成一张可交互的决定图：节点是问题，边是依赖，人来做决定，Agent 负责推导下一层。

安装

需要已安装 DeepSeek Harness（dsh）0.1.0-rc.7 或兼容版本。

装进你平时用的 Web 配置即可，不用改配置文件，也不用另开 profile：

dsh plugin --profile web add github:Gyanano/wayfinder-dashboard

然后和平时一样启动：

dsh

侧栏最下方会出现 Wayfinder 地图。打开一个工作区，在右侧输入框输入：

/wf-chart 我们想做插件，但路还看不清

Agent 会在当前会话里画出第一层问题。点开节点，用 /wf-decide 记下决定；用 /wf-research 派研究；用 /wf-advance 推进一步。顶栏可以把当前地图导出成 PNG。

它是什么

Wayfinder 规划的是「一次会话装不下」的工作。图上的节点是决策票——答案必须是一个决定，而不是「去实现 X」。

  • 地图属于一个工作区。一个仓库可以同时有好几张图，一张图对准一个目的地；在这个仓库画的图不会跑到另一个仓库里。
  • 打开插件先看到这个工作区的列表，点进去才是图。没有图时是一段说明，不是演示数据。
  • 图自上而下读：起点（最初那句模糊想法）→ 已经问清的一层 → 迷雾（下一层还没推导出来）→ 目的地。
  • 一次只长一层。下一层长什么样，取决于这一层怎么落地。
  • 每个问题随时能看见、能点开；依赖只挡住执行，不挡住阅读。
  • 研究只带回证据，不替你做决定。

语义见 PRODUCT.md，视觉见 DESIGN.md。

常用命令

命令 作用
/wf-chart <想法> 开一张新图，并让 Agent 推导第一层
/wf-decide <决定> 记下当前选中问题的决定，并推进下一层
/wf-research [说明] 把当前问题派给 Agent 做研究
/wf-advance 让 Agent 只推当前前沿一步
/wf-ask <问题> 手动加一个问题
/wf-focus 在当前图上选中一个问题
/wf-scope [in|out] 把问题划进或划出范围
/wf-reopen 重新打开一个已经记下的决定

配置

一般不用动。需要时写在 profile 的 cordis.patch.yml 里覆盖这一行。

项 默认 含义
dataDir $DSH_HOME/wayfinder 地图文件目录，刻意放在仓库外面
mountBundledSkill true 挂上自带的 Wayfinder skill

Agent 能做什么、不能做什么

Agent 可以列图、读图、更新目的地和迷雾、增改问题、认领并汇报研究。

没有「替人做决定」的工具。 HITL 问题只能你在输入框里用 /wf-decide 收束。
