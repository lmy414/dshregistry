dsh-ui-tool-graph

DeepSeek Harness 的独立 Web UI 插件：在会话中新增「工具图谱」标签页，把对话轨迹中的工具调用折叠成价值权重图——调用成本、次数、时长、失败率、token 归属一目了然，并一键生成引导下一轮优化的分析提示词。

纯呈现层插件，不改变任何模型可见输入（Model Experience 零影响），所有数据从会话事件日志增量折叠，重放安全。

功能

  • 价值权重图谱：节点 = 工具名聚合；半径 ∝ 所选指标占比（总耗时 / 调用次数 / 错误数，可切换）；外环 ∝ 失败率；连线 = 同轮次内调用的先后转移，粗细 ∝ 转移次数
  • 优化洞察：规则化识别首要瓶颈（耗时占比）、高失败率工具、完全相同的重复调用（缓存/去重候选）、连续自转移（批处理候选）、最长等待间隔、输出 token 大户步骤
  • 排名表与下钻：按总耗时排序的工具明细表，点击节点/行查看该工具每次调用的耗时与参数摘要
  • 下一轮引导：
    • 「复制优化提示词」——把指标表 + 洞察渲染成一份自包含的中文分析提示词复制到剪贴板
    • 「发送为下一轮」——二次确认后，直接把该提示词排入会话队列作为你的下一条消息

安装

前提：已安装 dsh CLI。

方式一：tarball（推荐，无需任何构建放行）

# 从 Release 下载或自行 pnpm pack 得到 tgz 后：
dsh plugin --profile demo add ./dsh-ui-tool-graph-<version>.tgz
dsh --profile demo          # 打开 web 界面即可看到「工具图谱」标签页

方式二：git 检出（首次 add 会要求在 profile 的 pnpm-workspace.yaml 里放行本包的 prepare 构建脚本）

dsh plugin --profile demo add github:<owner>/dsh-ui-tool-graph

卸载：dsh plugin --profile demo remove dsh-ui-tool-graph

指标口径

指标 口径
调用时长 tool/result 时间 − 对应 tool/call 时间（墙钟）
工具总耗时 当前窗口内全部已完成调用时长之和
失败率 该工具错误结果数 ÷ 已完成调用数
转移边 同一 turn 内按日志顺序相邻的两次调用；边权为转移次数
平均间隔 边上「上次结果 → 下次发起」的耗时均值（主要包含模型生成等待）
token 每个请求最终 assistant/message 携带的 provider 用量，按 step 去重累计

窗口受客户端历史分页限制：更早的调用需在轨迹页加载后才会进入统计。

兼容性

面向 DeepSeek Harness web 客户端的动态插件协议构建：

  • 运行时仅依赖宿主共享模块（react / cordis / client-runtime 等），bundle 自包含
  • 类型与测试基于 npm 发布版 @deepseek-ai/dsh-client-*@0.1.1-rc.2
  • 使用到的扩展点均为公开面：conversation.view 插槽、conversation Events/Views 注册表、locale 服务、ISession.prompt

本地开发

pnpm install
pnpm typecheck     # tsc --noEmit
pnpm test          # vitest（数据折叠 / 布局确定性 / 提示词模板 / 组件行为）
pnpm build         # 产出 lib/index.js（node 半）+ lib/client.js（浏览器 bundle）
pnpm pack          # 打出可安装 tarball

对源码运行的 Harness 做真机验证：

cd <deepseek-harness-checkout>
pnpm dsh --profile demo --dump-config   # 确认出现 "# == dsh-ui-tool-graph" 层
pnpm dsh --profile demo
