dsh-chat-width

中文文档: README.zh.md

DSH Web GUI 主编辑区域（对话区内容列）自适应宽度插件。

A small DSH (DeepSeek Harness) Web GUI plugin that makes the chat content column adapt to the screen resolution — when both side panels are collapsed, the middle area no longer stays stuck at the fixed 748px.

作用 / What it does

DSH 的聊天内容列默认被写死为 748px 宽（--dsh-chat-content-width: 748px）， 左右面板都折叠后中间区域依然很窄、两边留白。本插件注入 CSS 把内容列改为 min(100%, 自适应上限)：

  • 面板展开 → 内容列恰好填满中间列；
  • 左右折叠 → 内容列随当前屏幕/窗口分辨率自动变宽，最高不超过上限；
  • 历史用户消息气泡同样跟随内容列宽度（覆盖默认 525px 上限）；
  • 输入框下方的统计行（live-stats TPS 合并行）同样跟随内容列宽度（覆盖其默认 620px 上限）。

The DSH chat content column is hard-coded to 748px. This plugin injects CSS that overrides --dsh-chat-content-width to min(100%, adaptive-cap): the content column fills the center column, and grows with your screen resolution when the side panels are collapsed.

安装 / Install

方式一（推荐，一条命令，需重启 dsh web）:

dsh plugin --profile web add <本仓库 Git 地址>
# 然后重启 dsh web

方式二（免重启，手动挂载）: 把下面的内容追加到 ~/.dsh/profiles/web/cordis.patch.yml，刷新一次页面即可（无需重启服务）:

- insert:
    - id: dsh-chat-width
      name: 'dsh-chat-width'

并在 ~/.dsh/profiles/web/node_modules/ 下放置本仓库内容（或 pnpm add 安装）。 注意：方式一与方式二二选一，不要重复挂载。

Install via dsh plugin --profile web add <repo-url> (then restart dsh web), or manually insert the entry above into your profile's cordis.patch.yml (no restart needed, just refresh the page once).

自适应规则 / Adaptive rule (default)

max width = min(100%, clamp(900px, 72vw, 2560px))
视口宽度 / Viewport 内容列宽度 / Content width
1366×768 ≈983px
1920×1080 ≈1382px
2560×1440 ≈1843px
3840×2160 2560px (cap)

窗口大小变化时实时跟随，无需刷新。Tracks window size changes live.

调整参数 / Tuning

Edit the three constants at the top of lib/client.js — changes hot-apply via DSH client HMR (~0.5s), no restart / no refresh:

  • ADAPTIVE_RATIO (default 0.72) — fraction of viewport width
  • MIN_WIDTH (default "900px") — lower bound
  • MAX_CAP (default "2560px") — upper bound (raise it for 4K+)

Or force a fixed width from the browser console (takes effect after refresh):

localStorage.setItem('dsh-chat-width.max', '1920px')  // fixed 1920px
localStorage.removeItem('dsh-chat-width.max')          // back to adaptive

A console log line prints the active viewport and width rule on page load.

卸载 / Uninstall

  • 方式一安装：dsh plugin --profile web remove dsh-chat-width，重启 dsh web；
  • 方式二安装：删除 profile cordis.patch.yml 里的 insert 条目和 ~/.dsh/profiles/web/node_modules/dsh-chat-width/ 目录，刷新页面。

兼容性 / Compatibility

  • 需要 DSH 0.1.0-rc.6 的 web profile 客户端插件系统 （dsh web，window.__ModuleLoader__ bundle 格式）。
  • 选择器使用对话根元素的稳定属性 [data-phase] 双写特异性覆盖， conversation 包升级、哈希类名变化后依然生效。
  • Host half (lib/index.js) is a no-op placeholder so the loader entry mounts.
