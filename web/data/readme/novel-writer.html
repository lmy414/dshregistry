小说创作 · 六角色协同

English | 简体中文

一个装在 DeepSeek Harness（DSH） 里的小说创作模式：六个 AI 角色协调统筹——统筹全局、架构世界、策划剧情、执笔写文、管理人物、质检复核。新建会话时选它，就能用这支「创作工作室」把一部小说从构思一路写到成稿。

这是什么

它不是只会聊天的 AI，而是一支 6 人小说工作室——由一个 AI 轮流扮演 6 个角色，在同一个对话窗口里开会、分工、写稿、互相挑错。

角色 干什么
① 统筹队长 不写稿，负责控节奏、拍板、最后签发定稿
② 世界架构师 管世界规则和专有名词（物理法则、地理、货币、种族、战力天花板）
③ 剧情策划师 管主线节点、支线，以及所有伏笔的「台账」
④ 文笔执行者 唯一真正动笔写正文的，负责镜头、五感、留白
⑤ 人物管理员 管每个角色的档案和「说话风格」（语言基因卡）
⑥ 复核质检官 最后守门员：查人设、战力、逻辑、节奏，用红黄绿灯打回或放行

切换角色时它会用【通信头】标明是谁在说话，例如「【Agent 1 · 统筹队长】」。

安装方法

这是一个 DSH 预设插件：装好后，插件会把「小说创作 · 六角色协同」这个预设自动注册进 DSH，新建会话时直接选它就行。（预设 id 是 novel-writer——小写字母、数字和连字符；显示名是「小说创作 · 六角色协同」。）

方法一：插件安装（推荐）

在 DSH 命令行里执行下面这一行即可（Windows / macOS / Linux 通用）：

dsh plugin --profile web add github:sailoumili/novel-writer

装完后，重启或刷新 DSH web，新建会话时选「小说创作 · 六角色协同」即可。

方法二：手动安装（备选）

不想用命令行的话，也可以手动装：

一键脚本

Windows（PowerShell）：复制下面这一整行，粘贴回车，自动下载安装。

irm https://raw.githubusercontent.com/sailoumili/novel-writer/main/install.ps1 | iex

macOS / Linux（终端）：

curl -fsSL https://raw.githubusercontent.com/sailoumili/novel-writer/main/install.sh | bash

装完后，刷新或重启 DSH 页面，新建会话时选「小说创作 · 六角色协同」即可。

手动下载

  1. 点本仓库绿色 Code 按钮 → Download ZIP，下载并解压。
  2. 把解压出来的文件夹改名为 novel-writer（GitHub 下载的文件夹名通常带 -main 后缀，要去掉）。
  3. 把这个 novel-writer 文件夹放进 DSH 的预设目录：
    • Windows：C:\Users\你的用户名\.dsh\.agent-presets\
    • （~/.dsh/.agent-presets/，~ 表示你的用户主目录）
  4. 刷新（或重启）DSH 页面。
  5. 新建会话时，在「选预设 / 选智能体」处选择 小说创作 · 六角色协同。

怎么用

  1. 选好预设后，直接发一句话给题材和核心梗概，例如：

    题材：东方玄幻 + 克苏鲁融合。核心梗概：一个能看到别人「死亡倒计时」的猎户，如何在不被污染的前提下，拯救即将被旧日支配者吞噬的村庄。

  2. 它会走三步流程，每一步都停下来等你确认，不会一口气乱写：

    • 先让「世界」和「剧情」开联席会，出《叙事宪法》草案和《世界白皮书》大纲 → 等你批准；
    • 批准后生成主要角色档案 → 存进本地文件；
    • 最后申请「写第一章」的许可 → 你同意才动笔。

它会读写文件，请注意

为了让档案和台账跨会话不丢，这个预设会给 AI 读写文件的权限。每开一个新小说，它会在你的工作区建一个项目文件夹：

outputs/日期-项目名/
├─ 叙事宪法.md        核心冲突、禁用项、硬性约束
├─ 世界规则白皮书.md   物理法则、地理、货币、种族、战力
├─ 人物档案.json      每个角色的「灵魂四维」档案
├─ 伏笔台账.md        所有伏笔的埋设/回收状态表
├─ 章节目录.md        每章当前最新版本 + 一句话梗概
├─ 第1章-v1.md        第一章正文（带版本号）
└─ 第1章-v2.md        改过的第二版……

文件操作仍受 DSH 自带的沙箱策略约束，预设本身不会突破沙箱。

章节版本管理

  • 每章正文单独存文件，带版本号：第N章-vX.md（N=第几章，X=第几版，从 v1 开始）。
  • 改稿不覆盖：被打回重写或要求改稿时存成 第1章-v2.md，旧版留作废稿。
  • 续写只认最新版：只读每章版本号最大的那份。

想改它

  • 完整提示词（它的「大脑设定」）在 agent.cordis.yml。
  • 改完保存，下次开新会话生效。
  • 想彻底删除：删掉 ~/.dsh/.agent-presets/novel-writer/ 整个文件夹。
