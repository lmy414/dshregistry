大肥鱼（FatFish Pet Smart Companion）

啊哈哈哈，大肥鱼来喽！一条透明置顶、飘在你桌面上的智能桌宠。

🐋 这是什么

大肥鱼 是一款自包含的智能桌面宠物——下载安装即可使用，无需额外配置。它用一套丰富的表情和动作陪伴你：

  • 🧠 会跟着你的工作状态变表情：深入思考、使用工具、等待批准、任务完成、请求失败
  • 😴 空闲太久就自己睡觉，醒来有起床气（刚睡醒动画）
  • 🍚 单击喂它吃饭、🎮 右键逗它玩、🖱️ 拖它散步、🔄 滚轮调大小
  • 🚶 还会自己在屏幕上溜达散步

它是一条透明、置顶、无边框的小精灵，不占任务栏窗口（只在右下角托盘留一个小鱼图标，右键可显示/隐藏/退出），像真的宠物一样安安静静飘在桌面。

🔌 自包含，开箱即用

大肥鱼内置了全部表情素材，所以：

  • ✅ 下载即可用：安装后直接运行，立即有一条活生生的桌宠
  • ✅ 完全独立：不依赖浏览器、不需要单独安装任何 DSH 插件
  • 😴 安静陪伴：未连接 DSH 时，它会像平时空闲一样自己睡觉、用睡觉动画等待，不打扰你
  • 🔗 可选增强：如果你恰好也在运行 DeepSeek Harness，大肥鱼会自动识别并切换成真实跟随模式——它会跟着你的 DSH 实时状态（正在干活/思考/等待批准/任务完成）变化表情

🙏 致谢原作者

本桌宠改编自 @vlln 的 whale-girl 网页端插件，表情素材与状态语义源自该插件。

  • 🎨 鲸鱼娘表情素材由 ZipZipPipe 创作（来自 whale-girl 的 assets/characters）
  • 💡 状态语义、行为逻辑、素材清单源自 vlln 的 whale-girl（Web GUI 版）

感谢 @vlln 的付出，也感谢 ZipZipPipe 的精美素材！ 本桌宠不仅把原本活在浏览器里的鲸鱼娘搬到了桌面上，更在 whale-girl 的基础上调整并增加了实用的功能——让它能独立运行、离线陪伴，并在运行 DSH 时智能跟随你的实时工作状态。

✨ 特性

陪伴与表情

  • 15 种表情：空闲 / 干活 / 深入思考 / 等待批准 / 任务完成 / 请求失败 / 失望 / 开心 / 刚睡醒 / 睡觉 / 进食 / 玩耍 / 散步 / 拖拽 / 欢迎
  • 工作汇报气泡：干活、思考、等批准、庆祝、出错时，头顶会冒出小气泡实时汇报
  • 自动游走：空闲时会自己在屏幕上散步溜达，方向随机
  • 眨眼与转身：静止时会随机眨眼、偶尔转头，活灵活现
  • 睡觉等待：长时间空闲或未连接 DSH 时，自己打盹睡觉

交互操作

  • 拖拽移动：按住拖到任意位置，松手归位记忆
  • 滚轮缩放：滚动滚轮调整大小（0.6x–2x）
  • 单击喂食：点一下喂它吃，有进食动画和气泡回复
  • 右键玩耍：右键逗它玩，有玩耍动画

形态与体验

  • 透明置顶：透明、无边框、始终置顶，安安静静飘在桌面
  • 托盘图标：右下角托盘留小鱼图标，右键菜单（显示 / 隐藏 / 退出）
  • 不占任务栏：不显示独立窗口按钮，不打扰工作
  • 状态记忆：位置和大小重启后自动恢复
  • 自包含离线：内置全部表情素材，未连接 DSH 也能完整显示
  • 可选真连：运行 DSH 时自动跟随实时状态，与网页端体验一致

平台

  • Windows：NSIS 安装包 / 便携版
  • Linux：AppImage / RPM

🚀 安装使用

本桌宠是独立应用，下载对应平台安装包即可，不需要浏览器、不需要额外装插件。

# 从发行版页面下载
# https://github.com/xiaoshihou514/fatfish-pet-smart-companion/releases
  • Windows：NSIS 安装包 / 便携版
  • Linux：AppImage / RPM

下载后双击运行即可，大肥鱼就会出现在你桌面上～

可选：想让它「真连」跟随你的 DSH 实时状态？装好 DeepSeek Harness 并跑起来，大肥鱼会自动检测并切换到真实跟随模式，无需任何额外设置。

💡 小提示：如果偶尔遇到文字和宠物之间的距离变远的小 bug，用鼠标拖一下宠物就会自动归位，不用重启。
