关于本站

dshregistry 是一个社区驱动的 DSH 插件搜索引擎，聚合了来自 GitHub、dshfind 与 DSH Hub 等多个来源的插件收录信息。我们致力于为开发者提供一个统一、便捷的插件发现入口。

本站仅做索引与元数据聚合，不托管插件源码本身。所有插件的版权归其原作者所有，使用前请仔细阅读各插件的许可证与使用条款。

提交插件

想让你的插件被更多人发现？按照以下步骤提交，我们会尽快审核并收录。

  1. 1
    准备插件信息

    确保你的插件已发布到 GitHub 或 DSH Hub，包含完整的 README 与许可证。

  2. 2
    填写提交表单

    通过 GitHub Issue 提交插件名称、仓库地址、分类与简短描述。

  3. 3
    等待审核收录

    社区审核通过后，插件将在 24 小时内出现在搜索结果中。

提交入口：通过 GitHub Issue 提交，标签为 plugin-submission

数据 API

dshregistry 提供公开的 REST API，方便开发者获取插件索引数据。所有接口均为只读，无需鉴权，速率限制为 60 次/分钟。 

# 搜索插件
GET /api/plugins/search?q={query}&page=1&limit=20

# 获取插件详情
GET /api/plugins/{id}

# 按分类浏览
GET /api/plugins/category/{category}

# 获取排行榜
GET /api/plugins/leaderboard?type=stars&limit=10

# 统计信息
GET /api/stats
