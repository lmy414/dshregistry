dsh-teach

DSH（DeepSeek Harness）技能插件：教学与讲解。

教学工作区（MISSION/参考/学习记录/课程 HTML/组件）、知识-技能-智慧三要素、流畅度 vs 存储强度、合意困难（检索/间隔/交错）、最近发展区、短而单胜利的课程设计。受 mattpocock/skills 的 teach（223k★ MIT）启发的中文原创精简版。

安装

dsh plugin add dsh-teach

触发方式

描述中包含"教我 / 学习 / 讲解概念 / 教学 / 深入理解 / 学会这个主题"等关键词时自动触发。

能力

  • 教学工作区结构与状态记录
  • 合意困难三式（检索/间隔/交错）
  • 课程设计（短/单胜利/最近发展区）
  • 组件复用与参考材料

许可
