dsh-geo-seo

DSH（DeepSeek Harness）技能插件：GEO-first AI 搜索优化。

为 AI 搜索引擎（ChatGPT/Claude/Perplexity/Gemini/Google AI Overviews）优化网站，同时维持传统 SEO 地基：citability 引用就绪评分、AI crawler 访问分析（robots.txt）、llms.txt 生成与验证、品牌提及扫描、Schema 结构化数据、E-E-A-T 内容质量、5 并行子代理全审计。受 zubair-trabzada/geo-seo-claude（9.4k★）启发的中文原创精简版。

安装

dsh plugin add dsh-geo-seo

触发方式

描述中包含"AI 搜索优化 / GEO / 被 LLM 引用 / citability / llms.txt / AI crawler / 品牌提及"等关键词时自动触发。

能力

  • citability 引用就绪评分
  • AI crawler 访问分析
  • llms.txt 生成/验证
  • 品牌提及扫描
  • Schema JSON-LD 模板（含 E-E-A-T）
  • 5 并行子代理全审计
