dsh-marketing-growth

DSH（DeepSeek Harness）技能插件：营销增长技能树。

product-marketing 根基（所有技能先读它理解产品/受众/定位）→ CRO/文案/SEO/A-B 测试/冷邮件/广告/营销心理学/营销 loops/增长工程七大技能簇；技能互引用与依赖图。受 coreyhaines31/marketingskills（44.9k★）启发的中文原创精简版。

安装

dsh plugin add dsh-marketing-growth

触发方式

描述中包含"转化优化 / 文案 / SEO / A/B 测试 / 冷邮件 / 定价 / 上市计划 / 增长实验 / 营销心理学"等关键词时自动触发。

能力

  • product-marketing 根基（先读再动手）
  • 七大技能簇（SEO/CRO/文案/广告/留存/GTM/策略）
  • 技能互引用依赖图
  • 营销 loops（可自动跑循环）
  • 实验设计可度量（A/B 假设先行）
