dsh-startup-business-analyst

DSH（DeepSeek Harness）技能插件：创业业务分析。

市场测算（TAM/SAM/SOM，自上而下/自下而上/价值理论）、竞争格局（波特五力/定位图/蓝海）、财务模型（队列营收/成本结构/烧钱率与跑道/三档情景）、创业指标框架（北极星/漏斗/留存/LTV-CAC）。受 wshobson/agents（38k★ MIT）启发的中文原创精简版。

安装

dsh plugin add dsh-startup-business-analyst

触发方式

描述中包含"创业分析 / 市场测算 / TAM / 竞品分析 / BP / 融资 / 财务预测 / 烧钱率"等关键词时自动触发。

能力

  • TAM/SAM/SOM 三层市场测算
  • 波特五力 + 定位图竞争分析
  • 3-5 年财务模型与跑道测算
  • 北极星指标与单位经济（LTV/CAC）
