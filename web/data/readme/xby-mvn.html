xby-mvn

DeepSeek Harness (DSH) 的插件：Maven依赖管理服务

Maven MCP Server是一个通过自然语言交互的AI驱动Maven依赖管理工具，提供版本检查、安全扫描和依赖分析功能。

功能

  • set_xby_apikey — 在聊天中设置 API 密钥（自动持久化，重启有效）
  • check_version_tool — Check a Maven version and get all version update information in a single call
  • check_version_batch_tool — Process multiple Maven dependency version checks in a single batch request
  • list_available_versions_tool — List all available versions of a Maven artifact grouped by minor version tracks
  • scan_java_project_tool — Java-specific tool for scanning Maven projects for vulnerabilities
  • analyze_pom_file_tool — Analyze a single Maven POM file without scanning the entire workspace

安装

方式一：从 GitHub 直接安装（推荐）

# 格式: dsh plugin --profile <profile> add github:<owner>/<repo>
dsh plugin --profile web add github:xby_skill/xby-mvn

方式二：从本地目录安装（开发模式）

# 仅用于本地开发调试
dsh plugin --profile web add /absolute/path/to/xby-mvn

方式三：通过 cordis.patch.yml 开发调试

dsh web --profile web --patch /absolute/path/to/dsh-ocr-plugin/cordis.patch.yml
