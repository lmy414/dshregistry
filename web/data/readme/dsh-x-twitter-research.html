dsh-x-twitter-research

DSH（DeepSeek Harness）技能插件：X/Twitter 研究。

账号调研、时间线阅读、趋势与提及监控、发布信号监测、抽奖活动审计、改账号动作审批门控（先读后写）。受 wshobson/agents 的 hermes-tweet（38k★ MIT）启发的中文原创精简版。

安装

dsh plugin add dsh-x-twitter-research

触发方式

描述中包含"X 研究 / Twitter 调研 / 监控账号 / 提及调查 / giveaway 审计 / 发推"等关键词时自动触发。

能力

  • 研究输入框架（目标/对象/时间窗/动作范围）
  • 先读后写工作流（探索端点→读数据→总结信号）
  • 动作审批门控与已发动作记录
  • 密钥安全纪律

许可
