dsh-reptile-iguana · 鬣蜥

工具

  • reptile_info：返回鬣蜥（Iguana）完整资料：名称、学名/分类、类别、栖息地、体长、食性、寿命、特点、保护等级、趣闻。
  • reptile_field：按字段名查询鬣蜥（Iguana）的单项资料（可用于流程取数）。

纯 Node 实现，无网络依赖。

dsh plugin add github:uckkk/dsh-reptile-iguana

安装

dsh plugin add github:uckkk/dsh-reptile-iguana

使用

安装后在会话中调用该插件注册的工具即可。
