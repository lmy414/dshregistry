dsh-skill-lazy

DeepSeek Harness skill 目录的懒加载器：把每轮注入的完整 skill 摘要替换成「名字 + 一行短摘要」（全库约 500 tokens），完整内容走 skill_search 按需检索。

Lazy loader for the DSH skill catalog: injects name + one-line summary only (~500 tokens for the whole library), full descriptions fetched on demand.

为什么需要它

DSH 官方 skill 机制会把每个 skill 的完整摘要注入每一轮系统提示。skill 只有几个时无所谓；当你有 60+ 个 skill，每轮光目录就要烧掉几千 tokens——还没开始干活，预算先没了。

本插件把目录压缩成一行一条：

压缩前（官方）：每个 skill 一段完整描述，60+ 个 skill ≈ 3000+ tokens / 轮
压缩后（本插件）：a-share-daily-analyst: A股每日数据分析师——基于结构化交易数据复盘
                  全库 ≈ 500 tokens / 轮，按调用频率排序

需要完整描述时，agent 调 skill_search 按需检索——该花的钱花，不该花的一分不花。

工作原理

官方 skill-catalog 注入（完整摘要）
        ▼  agent/pre-step（prepend 到 waterfall 最前，等官方注入完成后再替换）
目录文本替换为精简版（名字 + 一行短摘要，source 不动 → 官方去重逻辑不受影响）
        ▼  tools/post-execute 记录 skill 调用频率
目录按使用频率排序，常用的排前面

工具（2 个）

工具 作用
skill_search 按关键词检索完整 skill 库。结果按 MECE 域分组返回完整描述，附域覆盖报告（标出空域/弱域）。任务可能命中多个 skill 或目录摘要不够决策时使用
skill_mece_check 创建/评审 skill 前的 MECE 检查：① 互斥性——与每个现有 skill 的关键词重叠率；② 完备性——全库域覆盖矩阵，推荐新 skill 的落点

安装

dsh plugin --profile web add github:boomzikazita/dsh-skill-lazy

配置

cordis.patch.yml：

- insert:
    - id: skill-lazy
      name: 'dsh-skill-lazy'
      config:
        catalogDescriptionMaxLength: 40   # 目录中每个 skill 摘要的最大字符数
        topK: 6                           # skill_search 每个域分组返回的最大条数
        sortByUsage: true                 # 目录按调用频率排序

与 dsh-skill-authoring 配合

dsh-skill-authoring 负责「创建高质量 skill」，本插件负责「大量 skill 下的成本控制」：创作侧保证每个 skill 值得存在，加载侧保证它们不挤占上下文。
