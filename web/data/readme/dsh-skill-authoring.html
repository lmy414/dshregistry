dsh-skill-authoring

DeepSeek Harness 的 skill 创作流水线：脚手架生成 → 9 项质量门禁审计 → 写入自动复检，让每个 skill 都达到可复用标准。

Skill authoring pipeline for DSH: scaffold, audit against a 9-gate quality checklist, and auto re-audit on every SKILL.md write.

为什么需要它

skill 是 agent 能力的复用单元，但随手写的 SKILL.md 往往缺触发条件、缺边界、缺示例——下次想用时自己都看不懂。本插件把「skill 创作」变成一条带质量门禁的流水线：

skill_check_name ──▶ skill_scaffold ──▶ （填充内容）──▶ skill_audit ──▶ 9/9 ✓ 才算完成
                          ▲                                        │
                          └──── 写入 SKILL.md 时自动复检并注入警告 ◀─┘

工具（3 个）

工具 作用
skill_check_name 校验命名规范：小写字母/数字 + 连字符（如 my-skill）。创建前先校验
skill_scaffold 生成新 skill 骨架：目录 + SKILL.md（frontmatter / whenToUse / Boundaries / QuickRef / Examples 占位）+ references/index.md。创建任何新 skill 前必须先走脚手架
skill_audit 按 9 项门禁逐条审计 SKILL.md，输出 ✓/✗ 报告。传入路径或 skill 名（自动定位 ~/.dsh/skills/<name>/SKILL.md）

9 项质量门禁

# 门禁 标准
1 name kebab-case 规范命名
2 description what + when（什么能力 + 什么场景触发），≤1024 字符
3 whenToUse ≥3 条触发场景
4 Boundaries ≥3 条边界声明（明确不做什么）
5 QuickRef ≤20 行速查表
6 Examples ≥3 个端到端示例
7 references/ 长内容分拆 + index.md 导航
8 验证路径 如何验证 skill 生效
9 操作手册风格 命令/步骤可直接执行，非散文

自动复检钩子

  • tools/pre-execute：每次写入 ~/.dsh/skills/**/SKILL.md 时自动跑门禁审计；未达标项聚合为警告
  • agent/pre-step：警告在下一轮注入对话，提醒 agent 补全（不阻塞写操作）

安装

dsh plugin --profile web add github:boomzikazita/dsh-skill-authoring

使用流程示例

你:   帮我做一个「周报生成」的 skill
agent: ① skill_check_name("weekly-report")        → ✓ 命名合规
       ② skill_scaffold(name, description)        → 骨架落盘 ~/.dsh/skills/weekly-report/
       ③ 填充 SKILL.md 各节
       ④ skill_audit("weekly-report")             → 7/9，缺 Examples / 验证路径
       ⑤ 补全后再审计                             → 9/9 ✓ 完成
