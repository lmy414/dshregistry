🎬 dsh-bili-miniplay

在 DeepSeek Harness (DSH) 里悬浮看片的 B 站小窗（跨平台版） — 边 coding 边刷视频，专注摸鱼，快乐加倍 🐟

⚠️ 本项目是 pyf2818/dsh-bili-widget 的跨平台分叉（fork）。 原版仅支持 Windows 桌面应用（依赖 curl.exe / powershell.exe / cwd C:\），在 macOS/Linux 上会「fetch 失败: http 502」。 本分叉把 Host 端网络层改为 Node 原生 fetch，不再依赖任何外部子进程，因此 macOS / Linux / Windows 通用。 原版版权归原作者所有，本分叉按其 MIT 许可分发并在 LICENSE 中保留归属。功能、UI、接口设计均源自原版。

✨ 为什么值得装

在 DSH 里挂一个 永远置顶、可拖动缩放、自动连播 的 B 站小窗。写代码写累了，随手点开一个视频边听边写；摸鱼看番也不会被打扰——窗口永远在最上层，全屏也不丢。

📸 截图

主界面

在 DSH 里悬浮一个 B 站小窗，推荐 / 热门 / 排行 / 精选 / 关注 / AI 六个频道，列表内直接播放，无缝切换。

观看历史

自动记录观看历史，本地持久化存储，重启 DSH 不丢失。

迷你模式

一键最小化到悬浮球，视频继续后台播放；点击悬浮球恢复窗口，进度完整保留。

快捷键面板

快捷键一目了然：←/→ 上下曲、M 迷你、N 专注、Esc 返回/关闭。

🔐 可选登录（B 站账号）

默认匿名即可浏览、搜索和播放绝大多数公开视频。若想解锁"登录可见"内容或进一步降低搜索被限的概率，可扫码登录：

  • 点击小窗顶部工具栏的 登录（未登录）/ 已登录（已登录）按钮，用 B 站 App 扫二维码即可。
  • 登录态安全存进 DSH credentials（底层走系统密钥库；无该服务时回退到 ~/.dsh/bili-data/login.json）。两个位置都在 git 仓库之外，代码里零硬编码密钥。
  • 支持退出登录；登录状态只在本机使用，不会上传或写入本仓库。

📦 安装

方式一：DSH 内直接说（推荐）

在 DSH 对话里输入：

请安装 https://github.com/Suguyun/dsh-bili-miniplay 这个插件

DSH 会自动完成安装，重启后即可在侧边栏找到「B站」。

方式二：手动安装

在你的 DSH profile 的 package.json 中添加：

{
  "dependencies": {
    "@dsh-external/dsh-bili-miniplay": "github:Suguyun/dsh-bili-miniplay"
  },
  "dsh": {
    "profile": {
      "bundles": [
        "@dsh-external/dsh-bili-miniplay"
      ]
    }
  }
}

然后 pnpm install 并重启 DSH。
