dsh-sticky-notes — 便签（DSH Web 客户端插件）

浮在 DeepSeek Harness Web 界面（dsh web）上的便签板：随手记录文字、待办和图片，可拖拽、缩放、折叠、归档，并能绑定到某个对话，在不同对话之间各自维护一套便签。

一句话：浮在界面上的便利贴，可记事、可勾待办、可贴图，还能跟某个对话绑定。

纯浏览器端插件（browser-only client bundle），无服务端逻辑，数据存在浏览器 localStorage。

安装

要求：已安装 dsh（含 web profile），浏览器中使用。

# 方式一：从 GitHub 安装（无需构建授权，纯 JS）
dsh plugin --profile web add github:hufang360/dsh-sticky-notes

# 方式二：tarball（把 sticky-notes-1.1.0.tgz 放到当前目录）
dsh plugin --profile web add ./sticky-notes-1.1.0.tgz

安装完成后硬刷新浏览器（macOS Cmd+Shift+R）。便签入口出现在侧边栏底部、设置按钮上方。

本包是标准 dsh bundle：自带 cordis.patch.yml（声明 dsh.bundle），dsh plugin add 一条命令即可完成依赖 + 层注册。

功能

便签本体

  • 文字便签：正文 Markdown 渲染（加粗 / 斜体 / 标题 / 列表 / 表格 / 待办 - [ ] / 已完成删除线 / 代码 / 链接）。
  • 智能标题：忽略 Markdown 标记、取首个非空行、最多 10 字；无内容显示「便签」。
  • 双击标题栏折叠 / 展开；标题栏拖动移动；右下角手柄缩放。
  • 右上「⋯」菜单：新建 / 插入图片 / 追加到聊天框 / 归档 / 设为全局或绑定当前会话 / 换色（6 色）/ 导出 / 删除（需确认）。

贴图便签

  • 编辑态直接粘贴图片，或菜单「插入图片」，自动生成独立贴图便签。
  • 只显示一张图、等比缩放；双击空白处自动裁剪多余空白（auto-fit）。
  • ⋯ 菜单「下载」以真实图片文件保存（贴图N.<真实扩展名>）；单击图片打开全屏查看器（缩放 1–8×、Esc 关闭）。

对话绑定（核心）

  • 每张便签有「范围」：全局（所有对话显示）或绑定到当前会话（只在该对话显示）。
  • 切换对话时只显示「全局 + 绑定该对话」的便签；新建便签默认绑定当前会话，无会话时自动视为全局。
  • 便签菜单「范围」可随时切换。

设置面板（设置 → 便签）

  • 左侧过滤：全部 / 全局 / 各会话（记住上次选择）；右侧「未归档 / 已归档」双 tab。
  • 每张卡片的操作：导出 Markdown（文字）/ 下载图片（贴图）/ 恢复 / 删除（需确认）。
  • 顶部按范围导出：选中会话 → 该会话一个 .md；「全部」→ 按对话拆分成多个 .md。

其他

  • 便签相互叠放时，拖动经过更高的便签会自动置顶。
  • 侧边栏折叠 / 展开不平移便签。
  • 侧边栏入口按钮显示 可见/总数 计数。

数据与存储

  • 便签、偏好与设置存于浏览器 localStorage：
    • dsh.web.sticky-notes.v5.notes（便签数组）
    • dsh.web.sticky-notes.v5.prefs（hidden / entryPos）
    • dsh.web.sticky-notes.v5.settings（设置面板过滤）
  • 图片以压缩后的 DataURL 存储。
  • 数据仅在浏览器本地，不同设备 / 浏览器之间不同步。

限制

  • 会话显示名来自宿主会话服务；会话无标题或未在列表时，从该会话便签派生标题兜底（再无则显示会话 id）。
  • 设置卡片为只读展示，卡片内图片不可点击放大。
  • 部分操作为鼠标指针事件（拖拽 / 缩放），键盘可操作性有限。

开发与打包

node --check lib/client.js   # 语法检查
git commit -am "..."         # 常规提交
pnpm pack                    # 产出 sticky-notes-<version>.tgz
npm publish                  # （可选）发布到 npm
  • lib/client.js — 唯一逻辑文件（浏览器 bundle）。
  • lib/index.js — host 侧 no-op 入口。
  • cordis.patch.yml — bundle 的 patch 层（注册 sticky-notes 插件行）。
