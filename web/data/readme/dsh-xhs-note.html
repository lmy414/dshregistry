dsh-xhs-note

Format a Xiaohongshu note (title max 20 Unicode code points) as a DeepSeek Harness tool. Do not pip the wrong dsh.

GitHub topic: dsh-plugin. Chinese: README.zh.md

Try without dsh

node demo.mjs

Prints the sample title and the course URL.

Install into a profile

This package is plain JavaScript. There is no prepare or build step, so a git install does not need allowBuilds.

dsh plugin --profile web add github:guobinmengxiang-rgb/dsh-xhs-note

Check the composed layer without booting:

dsh --profile web --dump-config

You should see a dsh-xhs-note layer. Then start the profile as usual.

Official CLI is @deepseek-ai/dsh (today 0.1.0-rc.6). The PyPI package deepseek-harness-cli is a different tool (dsh doctor / dsh chat).

Honest limits

  • npx may not load local overlays. The course overlay in dsh-getting-started still needs an absolute path to a TypeScript file.
  • This bundle cordis.patch.yml uses the package name dsh-xhs-note, not a filesystem path.
  • DeepSeek Harness is a developer preview: THERE WILL BE COMPATIBILITY-BREAKING CHANGES.
  • The plugin runs on your machine.
