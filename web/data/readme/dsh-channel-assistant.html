dsh-channel-assistant

DSH（DeepSeek Harness）技能插件：渠道化个人助手。

单操作员的个人 AI 助手，通过一个 Gateway 连接模型/工具/消息频道/伴侣应用：频道即界面（WhatsApp/Telegram/Slack/Discord/Signal/iMessage…）、Control UI/CLI/TUI 三种界面、配对安全模型（未知发件人默认待批准）、工具沙箱化执行、ClawHub 插件市场。受 openclaw/openclaw（247k★）启发的中文原创精简版。

安装

dsh plugin add dsh-channel-assistant

触发方式

描述中包含"渠道助手 / 个人助手 / 多频道 / Gateway / 消息平台指挥 agent / OpenClaw"等关键词时自动触发。

能力

  • 频道即界面（8+ 消息平台）
  • Gateway 统一控制平面
  • Control UI/CLI/TUI
  • 配对安全模型
  • 工具沙箱化执行
  • ClawHub 插件生态
