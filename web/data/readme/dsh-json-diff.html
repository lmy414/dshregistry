dsh-json-diff · JSON 语义对比

深比较两个 JSON，返回新增/删除/变更的键路径。纯 Node 实现。

提供的工具

工具 作用
diff_json 深比较 JSON → 差异路径

安装

dsh plugin add dsh-json-diff

安装后在 profile 的 package.json 的 dsh.profile.bundles 中加入 "dsh-json-diff"。

用法示例

对比这两个接口响应有什么变化
→ 调用 diff_json(a=<旧>, b=<新>)
