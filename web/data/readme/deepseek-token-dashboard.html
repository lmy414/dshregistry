deepseek-token-dashboard

DSH（DeepSeek Harness）Web 界面左下角的 Token 用量仪表盘：实时显示当前会话的 Token 使用量、预估花费与 DeepSeek 账户剩余额度。

功能

  • Token 用量：当前选中会话累计的 输入 / 输出 / 缓存读取 / 缓存写入 / 合计（来自 每次模型调用上报的真实 usage，经会话投影实时推送）。
  • 预估花费：按 deepseek-chat 官方单价（每百万 token 人民币）估算，标注“估算”， 可通过环境变量调整单价（见下）。
  • 账户余额：DeepSeek 官方 GET /user/balance，显示总额 / 赠送 / 是否可用； 每 60 秒刷新。
  • 紧凑进度条读数：常驻侧边栏底部“设置”旁边—— 第一行 Token 合计 · 花费，第二行 Token 构成堆叠条（输入=品牌蓝 / 输出=绿 / 缓存=灰）， 第三行 花费/余额利用率条（按比例变色并显示百分比，余额不可用时隐藏）； 侧边栏收起（56px rail）时缩为一个状态圆点，悬停可见全部详情。信息精简、不遮挡任何界面。

安装

# 1. 安装包到 profile（本仓库已打包为 .tgz 并安装，见 docs/INSTALL.md）
cd "$HOME\.dsh\profiles\web"
pnpm add <path-to>/deepseek-token-dashboard-1.1.0.tgz

# 2. 在 profile 的 package.json 中把 "deepseek-token-dashboard" 追加到 dsh.profile.bundles
#    （包已内置 dsh.bundle.patch 声明与 cordis.patch.yml，启动器挂载插件行，无需额外配置）
# 3. 重启 dsh 服务（Host 插件与 Client bundle 均在启动时加载），刷新浏览器页面

PowerShell 执行策略默认拦截 npm.ps1/pnpm.ps1，请改用 npm.cmd/pnpm.cmd。

详细步骤与卸载/故障排查见 docs/INSTALL.md。

配置

项 方式 默认
API Key 复用宿主凭据 DEEPSEEK_API_KEY（$HOME/.dsh/.credentials.yaml 或环境变量） —
单价（¥/百万 token） 自动：按当前模型 + 当前时段从内置单价表选取；环境变量 DEEPSEEK_TOKEN_DASHBOARD_RATES（JSON）可显式覆盖（优先级最高） 见下表（峰谷定价，2026-08-17 起生效）

余额刷新间隔 代码常量 BALANCE_INTERVAL_MS（lib/index.js） 60s

内置单价表（每百万 token，人民币；来源：官方定价页 2026-08-16 抓取 + 账单校准）：

模型 时段 缓存命中 缓存未命中 输出
deepseek-v4-flash 现行价（8-17 前） ¥0.02 ¥1 ¥2
deepseek-v4-flash 空闲时段 ¥0.05 ¥1.5 ¥4.5
deepseek-v4-flash 高峰时段 ¥0.10 ¥3.0 ¥9.0
deepseek-v4-pro 现行价（8-17 前） ¥0.025 ¥3 ¥6
deepseek-v4-pro 空闲时段 ¥0.15 ¥4.5 ¥13.5
deepseek-v4-pro 高峰时段 ¥0.30 ¥9.0 ¥27.0
deepseek-chat / reasoner 历史公开价（旧模型） ¥0.5 / ¥1 ¥2 / ¥4 ¥8 / ¥16

高峰时段 = 北京时间 9:00–12:00、14:00–18:00（空闲为其半价），自 2026-08-17 00:00 自动生效； 花费为估算值，tooltip 标注所用模型；缓存写入无独立单价，按“未命中输入”计； 官方调价时更新内置 MODEL_PRICES 表（lib/rates.js）即可。
