dsh-sky-skin · Sky · Home Arena

A Sky: Children of the Light themed skin for the DeepSeek Harness web UI — three Light Children standing on a glowing constellation board, candlelight gold and a deep-blue starry night. The light theme shows two silhouettes against the setting sun.

Map themes

Seven map themes ship with the skin, each with its own backdrop and color palette, switchable in one click from the dedicated 光遇·遇境 section in Settings — no restart, hot-applied instantly:

  • 遇境 Home — night sky, glowing star-map board, arched halos (default).
  • 晨岛 Dawn — morning light, breathing sun glow.
  • 云野 Prairie — drifting cloud sea.
  • 雨林 Forest — rain-damp forest with fireflies.
  • 霞谷 Valley — rosy valley sheen.
  • 暮土 Wasteland — dark golden dust.
  • 禁阁 Vault — deep-blue vault starlight.

The active map is persisted in the ui-sky settings namespace (GET|POST /api/sky-skin/map) and applies immediately to the open page.

Visuals

  • Dark: night sky, glowing star-map board, arched halos, central candle.
  • Light: dusk gradient, twin silhouettes against the big sun.
  • Full remap of the official design tokens (light + dark sets).
  • A MutationObserver state machine drives the backdrop, candle glow and decorations as the chat activates, the sidebar resizes, and the settings panel opens/closes.
  • Decorative chrome: top/bottom trim, candle corner accents in the sidebar, a star-map circular mascot, gold-framed chat input.
  • Real raster art served by the host /sky-assets/ allow-listed route — no SVG.

Install

dsh plugin --profile web add github:Entity-Him/dsh-sky-skin

Then open 设置 → 皮肤 and switch to 光遇·遇境 (or set ui-skin-sky disabled: false in cordis.patch.yml and disable the other skins).

Requires the dsh web profile. Pure JavaScript — no native dependencies.

Assets

The raster assets are Wallhaven wallpapers and Sky Fandom official map images used as a local personal skin resource (see skin.json for per-asset sources). The host route only serves the allow-listed filenames under assets/.
