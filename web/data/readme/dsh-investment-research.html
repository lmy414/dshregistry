dsh-investment-research

DSH（DeepSeek Harness）技能插件：个人投研方法论（A股/美股/港股）。

五维分析框架（估值/资金面/财报质量/行业景气/事件催化与风险）、多空辩论（事实底稿 → 多方/空方研究员 → 中立主持归纳分歧与验证清单，刻意不产出买卖结论）、反思审计（揪出无数据支撑的脑补结论）、每日复盘与资讯雷达提炼要点。受 simonlin1212/Vibe-Research（2.1k★）启发的中文原创精简版。

安装

dsh plugin add dsh-investment-research

触发方式

描述中包含"个股投研 / 多空辩论 / 每日复盘 / 反思审计 / 五维分析 / 基本面分析"等关键词时自动触发。

能力

  • 五维分析框架（只规定怎么读数据，不规定买卖）
  • 多空辩论：事实底稿先行 + 论点标注数据来源
  • 中立主持归纳：共识/真正分歧/验证清单/数据缺口
  • 反思审计：揪出"听起来合理但没依据"的表述
  • 每日复盘要素（大盘/情绪/板块资金/资讯要点）
  • 合规约束：不荐股、不预测、不承诺收益
