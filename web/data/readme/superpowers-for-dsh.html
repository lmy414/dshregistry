SuperPowers for DSH

把 obra/superpowers 的通用工程工作流带到 DeepSeek Harness（DSH）：14 个技能、自动 bootstrap、DSH 原生工具映射，以及 Windows sandbox 的同级升级兼容层。

这是一个独立的 DSH bundle，研究并吸收了 LayneChai/superpowers-dsh 的可安装 provider 结构；preset、bootstrap 和 pwsh 运行时适配是本仓库自己的实现。

功能

  • vendoring obra/superpowers v6.3.0（commit b36e082）的 14 个技能，保留 upstream 工作流正文，并仅在 using-superpowers 增加 DSH 平台 reference 链接。
  • 通过 host 层 Cordis skill provider 发现和按需加载技能。
  • 提供一个可复制的 SuperPowers for DSH agent preset。
  • 在新会话启动时自动加载 using-superpowers bootstrap。
  • 保留 DSH 的 plan mode、goal、subagent、workflow、ralph、todo 和 job 工具。
  • 在 Windows 上处理 danger-full-access 已经生效时模型仍传入 sandbox_permissions 的旧调用。

安装

1. 安装 bundle

在 DSH 所在环境执行：

npx @deepseek-ai/dsh plugin --profile web add github:Meteor-system/superpowers-for-dsh

也可以从本地 clone 安装：

git clone https://github.com/Meteor-system/superpowers-for-dsh.git
npx @deepseek-ai/dsh plugin --profile web add C:\path\to\superpowers-for-dsh

2. 安装 preset 模板

从本仓库目录运行：

node scripts/install-preset.mjs

脚本默认写入：

%USERPROFILE%\.dsh\.agent-presets\superpowers-dsh

已有 preset 时脚本会拒绝覆盖；使用 --force 时会先把旧目录重命名为带时间戳的 backup，再安装新版本。

3. 重启 profile 并新建会话

bundle 在 profile 启动时挂载。停止并重新启动 DSH profile，然后刷新 Web 页面；在新会话中选择 SuperPowers for DSH。旧会话保留创建时的 preset generation，不能用来验证新 bootstrap。

确认 bundle 已组合：

dsh --profile web --dump-config

输出中应出现 superpowers-for-dsh 行。

Windows sandbox 规则

在当前 effective mode 已经是 danger-full-access 时，普通 pwsh 调用不要传 sandbox_permissions 或 justification。preset 中的兼容 wrapper 还会在执行前清理旧模型发出的同级或不完整字段；真正更宽的请求在低权限 mode 中仍交给 DSH 正常的 approval/policy 流程。

普通调用形态：

{
  "command": "Get-Location",
  "description": "确认当前项目目录",
  "workdir": "D:\\Code\\project",
  "run_in_background": false
}

验证

node scripts/verify.mjs

verifier 会检查 14 个 skill 的 frontmatter、bundle patch、preset 可移植性、bootstrap 生命周期、模块语法和 pwsh wrapper smoke test。

本适配已在 DSH 中验证：新 agent 的 danger-full-access request header 不再暴露两个升级字段；即使模型强行发出 legacy 字段，pwsh 结果仍为非错误结果。

架构

  • cordis.patch.yml：把 bundle provider 插入 host composition。
  • lib/index.js：从包内 skills 目录发现 SKILL.md，并通过 ctx.skills 注册 provider。
  • preset/agent.cordis.yml：完整的 agent-plane preset 模板，不依赖本机绝对路径。
  • preset/superpowers-bootstrap.mjs：只注册 system-prompt/section，不拦截 agent/pre-step。
  • preset/superpowers-pwsh-compat.mjs：按 session sandbox mode 隐藏 schema，并清理 legacy 同级字段。
  • skills/using-superpowers/references/dsh-tools.md：Claude Code 工具到 DSH 工具的映射。
