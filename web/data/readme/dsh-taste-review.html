dsh-taste-review

DSH（DeepSeek Harness）技能插件：审美判断调用。

对模糊的 UI 打磨/文案/命名/排版决策，启动一个 taste-driven judgment call——列出文件、给几个方案权衡、给推荐并列出备选；深度与决策匹配（设计决策可能几段，命名决策不用）。受 bholmesdev/skills（taste-review）启发的中文原创精简版。

安装

dsh plugin add dsh-taste-review

触发方式

描述中包含"拿不准审美 / 设计犹豫 / 第二双眼 / 文案/命名/排版判断"等关键词时自动触发。

能力

  • taste-driven judgment call
  • 多选项权衡
  • 推荐 + 备选并列
  • 深度匹配决策量级
  • 相关文件上下文
