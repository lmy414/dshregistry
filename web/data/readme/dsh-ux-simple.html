dsh-ux-simple

DSH 界面两档模式插件：简化 / 原生一键切换，工具卡片白话化，降低 DeepSeek Harness 的上手门槛。

⚠️ 项目状态：暂时停止维护

这是一个练手项目：插件功能粗略开发了一点、本地验证可用，但没继续推下去（未发布 npm、未跟进官方接口更新）。代码保留供参考，不保证在新版本 DSH 上可用，暂时不更新。 项目价值：仅作为提供想法用。

为什么做这个

DeepSeek Harness 发布后，社区对它的批评集中在一点：门槛。

  • 界面新闻：「一切皆插件」的设计十分依赖配置（YAML + 插件 + 效果组件 + 服务），「对高级用户而言功能强大，但对于只想快速用上可用智能代理的人来说，上手门槛较高」
  • 极客公园：DSH「对非编程用户不是很友好」，像框架、不像成品，是给开发者的尝鲜版
  • 社区开发者：「这玩意鬼才用，我为什么没事要插拔」

DSH 的毛坯房是刻意为之，但「想省事的人」和「要全功能的人」不该被迫接受同一套界面。dsh-ux-simple 用两档模式回应这个矛盾：

档位 适用的人 界面表现
简化 想先用起来、不想研究术语的人 工具卡片全部白话化，参数与结果摘要显示，术语变人话
原生 老手、需要完整信息的人 完整原生界面，一个像素都不改

默认原生档，切换一次即生效，刷新页面回原生档。不想用的时候，卸掉插件，界面回到出厂状态，没有任何残留。

功能

  • 左下角「界面」悬浮入口：点开二级菜单，切换「简化 / 原生」，每档带一句说明
  • 工具卡片白话化：33 个工具全覆盖白话文案（如 pwsh → 「正在电脑上执行一条命令」），实际接管 19 个没有原生卡片的工具；有原生卡片的 read / write / web_search 等保持产品原版
  • 简化档摘要显示：工具参数与结果自动摘要（文件只显示文件名、命令截断 80 字符、结果截断 100 字符），点「看细节」展开完整内容
  • 状态一目了然：每个工具卡片带状态圆点（进行中 / 完成 / 出错）与白话状态标签

设计原则

  • 纯展示层：只改界面呈现，模型输入输出零改动，不影响 agent 的任何工作
  • 增量接管：只接管没有原生卡片的工具，不覆盖官方 UI
  • 内存态切换：刷新回原生档，简单、干净、无配置污染
  • 跟随主题：全部使用官方 --dsw-alias-* 设计变量，明暗主题自适应

安装

需要先装好 DeepSeek Harness（Node.js 22.19+ 或 24+）。

⚠️ 未发布到 npm，无法用一行命令安装。请克隆本仓库后用本地路径安装：

npx -y @deepseek-ai/dsh plugin --profile web add <本仓库目录>

然后正常启动 Web UI 即可，左下角会出现「界面」入口。

使用

  1. 启动后点击左下角「界面」按钮
  2. 选择「简化」：工具卡片变白话，参数结果自动摘要
  3. 选择「原生」：恢复完整原生界面
  4. 刷新页面回到原生档

常见问题

为什么刷新后回到原生档？ 档位存在内存里，这是刻意设计：简化档是临时辅助，不想用的时候刷新即消失，不留任何状态。

为什么有些工具卡片看起来没变？ read、write、web_search 等工具官方已有产品级原生卡片，插件不覆盖它们，只接管没有原生卡片的 19 个工具，保证原生体验不被破坏。

简化档会影响 agent 干活吗？ 不会。插件只改界面显示，模型收到的输入输出与原生完全一致。

兼容性

基于 @deepseek-ai/dsh 0.1.0-rc.6 开发。项目已停止维护，DSH 预览期的接口变动后大概率不兼容，请勿用于生产环境。
