dsh-volcengine-usage

一个用于 DeepSeek Harness Web 的火山引擎 Coding Plan 用量监控插件。

插件在 DSH 页面显示可拖动的用量卡片，展示会话、每周和每月用量百分比。卡片坐标保存在浏览器本地，刷新或重启后仍会保留。

功能

  • 展示会话、每周和每月用量百分比
  • 点击 ↻ 手动刷新，每 5 分钟自动刷新
  • 拖动标题栏移动卡片并记忆位置
  • Cookie 和 Web ID 只在 DSH 服务端读取，不发送给浏览器
  • 提供稳定的本机 JSON 接口，便于二次开发

安全说明

本仓库不包含、也不应提交任何 Cookie、API Key、Web ID 或 .credentials.yaml 文件。

插件服务端通过 DSH credentials 服务解析以下引用：

VOLCENGINE_COOKIE
VOLCENGINE_WEB_ID

浏览器端只能访问经过整理的用量数据，无法读取原始凭据。服务端接口默认只接受本机环回连接。

让 Agent 帮你安装

把下面这段话连同本仓库链接发给你的 Agent：

请先阅读这个仓库的 README.md 和 docs/AGENT_INSTALL.md，然后把该插件安装到我的 DeepSeek Harness web profile。安装前备份 profile/package.json、cordis.patch.yml 和凭据文件；不要输出或记录任何凭据值。检查 VOLCENGINE_COOKIE 与 VOLCENGINE_WEB_ID 是否存在，只报告键名和状态。安装后重启 dsh web，并验证主页和 /api/dsh-volcengine-usage/v1/usage 均能访问。不要修改无关文件。

安装方式

仓库发布到 GitHub 后：

dsh plugin --profile web add github:helloworld1631/dsh-volcengine-usage

如果以后发布到 npm：

dsh plugin --profile web add dsh-volcengine-usage

安装完成后重启：

dsh web

凭据结构

当前 DSH credentials-local 使用 version 1 文档：

version: 1
refs:
  VOLCENGINE_COOKIE: "完整 Cookie"
  VOLCENGINE_WEB_ID: "Web ID"

请使用 DSH 自带凭据管理能力或 YAML 序列化器写入，不建议手工拼接长 Cookie。

使用

  • 按住“火山 Coding Plan”标题栏即可拖动卡片。
  • 点击右上角 ↻ 立即刷新。
  • 卡片每 5 分钟自动刷新。
  • 火山会话过期时，更新本机凭据后重新刷新。
