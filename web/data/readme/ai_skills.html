Daydream Break

干活累了，让 Agent 发一下呆。

daydream-break 提供两个版本：轻量的 Codex Skill，以及真正计时、随机触发并读取会话状态的 DeepSeek Harness Cordis 插件。启用后，Agent 在持续工作一段时间时，可能会短暂地“忘记刚才想到哪里”，快速回顾当前任务状态，然后接着完成工作。

诶，我刚刚在想到哪儿了来着？
当前状态：已经确认目标，正在处理测试，下一步是修复剩余失败项。
好，接上。

安装

DeepSeek Harness 插件

DeepSeek Harness 版本可直接作为 bundle 安装到 web profile：

dsh plugin --profile web add github:Stone623/ai_skills
dsh --profile web --dump-config
dsh web

它使用 agent/pre-step 运行时事件进行真实随机调度，并从当前 Session 事件日志生成恢复快照。完整配置、卸载方法和能力边界见 deepseek-daydream-break/README.md。

Codex Skill

使用 Skill Installer（推荐）

在 Codex 中调用内置的 $skill-installer：

使用 $skill-installer 从 https://github.com/Stone623/ai_skills/tree/main/daydream-break 安装这个 skill

安装完成后，新 Skill 会在下一轮对话中可用。如果没有出现，请重启 Codex。

手动安装

下载或克隆本仓库，然后将整个 daydream-break 文件夹复制到以下任一位置：

作用域 安装位置 适用场景
用户级 ~/.agents/skills/daydream-break 在所有仓库中使用
仓库级 <repo>/.agents/skills/daydream-break 只在某个仓库中使用

Windows 中的 ~ 通常对应 %USERPROFILE%，例如：

C:\Users\你的用户名\.agents\skills\daydream-break

Codex 会自动检测 Skill 变更；如果没有立即出现，请重启 Codex。

使用

在任务中显式提及 Skill：

使用 $daydream-break 帮我重构这个模块。

也可以在同一句话中配置行为：

使用 $daydream-break 完成这个任务，最多发呆 2 次，在 3 到 6 分钟内触发，用中文，轻微一点。

Codex 也可能在用户描述符合 Skill 用途时隐式启用它，但显式写出 $daydream-break 最可靠。

配置

配置通过调用 Skill 时的自然语言传入，不需要修改配置文件。

配置项 默认值 示例
最大发呆次数 每个任务 1 次 最多发呆 2 次
触发时间范围 5-10 分钟 3 到 6 分钟内触发
语言 跟随用户语言 用英文发呆
风格 简短、克制 轻微一点、戏剧化一点

完整示例：

使用 $daydream-break 检查并修复这个项目的测试。
触发范围改为 2 到 4 分钟，最多触发 2 次，使用英文，保持克制。

默认行为

启用后，Agent 会：

  1. 为当前任务保留一次发呆机会。
  2. 在持续工作接近随机触发时间时提高触发概率。
  3. 用一句短话表示走神。
  4. 用可观察的任务状态快速回顾已完成工作、当前步骤和下一步。
  5. 立即继续原任务，不要求用户重新解释。

短任务如果在触发范围前已经完成，不会为了展示效果强行发呆。Skill 也不会打断最终答复、权限确认、破坏性操作确认或安全敏感指导。

能力边界

Codex Skill 版本是 instruction-only：它通过行为指令让 Agent 模拟一次短暂走神和状态恢复。DeepSeek Harness 插件版则使用真实时钟、随机数和 Session 事件快照；但和所有 Harness 扩展一样，它只能在 Agent 步骤边界注入上下文，不能中断已经运行的模型请求或工具调用。

  • 它不会让 Agent 真正遗忘上下文，也不会展示或重放隐藏思维过程。
  • 时间和概率由 Agent 在工作阶段之间估算，不是操作系统级后台计时器或严格随机数生成器。
  • 它无法在单个正在运行的长命令中途强制插入消息。
  • “重新思考”指回顾文件、命令、决定、进度和下一步等可观察状态。

因此，这个 Skill 适合增加一点自然、有趣的工作节奏，而不适合依赖精确时间或强制中断的自动化场景。

兼容性

独立 Skill 可用于 ChatGPT 桌面应用中的 Codex、Codex CLI 和 Codex IDE 扩展。Skill 的加载和目录规则可参考 OpenAI 官方文档。
