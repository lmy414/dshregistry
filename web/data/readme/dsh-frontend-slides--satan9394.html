dsh-frontend-slides

DSH（DeepSeek Harness）技能插件：零依赖 HTML 演示文稿。

帮非设计师做出好看的网页演示：show-don't-tell 视觉风格发现（生成 3 个预览让用户选，而非文字描述审美）、PPT 转网页（保留全部图片内容）、anti-AI-slop 精选风格（拒绝紫渐变白底通用 AI 审美）、34 个 bold 设计系统渐进加载（先索引 → 候选预览 → 选中才加载完整设计）。受 zarazhangrui/frontend-slides（27k★）启发的中文原创精简版。

安装

dsh plugin add dsh-frontend-slides

触发方式

描述中包含"做演示文稿 / 网页幻灯片 / HTML slides / PPT 转网页 / pitch deck / 技术分享 slides"等关键词时自动触发。

能力

  • 视觉风格发现（3 预览供选）
  • PPT 转换（素材全保留）
  • 12 内置预设 + 34 bold 设计系统
  • 渐进加载（控制上下文成本）
  • anti-AI-slop 风格把关
  • 单 HTML 零依赖、16:9、可访问
