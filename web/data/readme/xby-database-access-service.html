xby-database-access-service

DeepSeek Harness (DSH) 的插件：数据库访问服务

数据库元数据获取

功能

  • set_xby_apikey — 在聊天中设置 API 密钥（自动持久化，重启有效）
  • list_tables — List all tables in the database.
  • get_table_schema — Get column information for a specified table in the database.
  • sql_query — MCP Tool to execute a SQL query.

安装

方式一：从 GitHub 直接安装（推荐）

# 格式: dsh plugin --profile <profile> add github:<owner>/<repo>
dsh plugin --profile web add github:xby_skill/xby-database-access-service

方式二：从本地目录安装（开发模式）

# 仅用于本地开发调试
dsh plugin --profile web add /absolute/path/to/xby-database-access-service

方式三：通过 cordis.patch.yml 开发调试

dsh web --profile web --patch /absolute/path/to/dsh-ocr-plugin/cordis.patch.yml
