dsh-shared-memory · 跨对话记忆（Shared Memory）

DeepSeek Harness 的跨对话记忆系统（Hermes 式）：把一份持久化的记忆文件注入每个会话的系统提示词，并提供一个 memory 工具（agent 笔记）+ 可视化记忆面板（GUI），让新对话自动知道旧对话沉淀的内容。

Cross-conversation memory for DeepSeek Harness, Hermes-style: a durable memory file injected into every session's system prompt, with a memory maintenance tool and a GUI panel.

功能 / Features

  • 跨对话记忆：MEMORY.md（agent 笔记，上限 8000 字符）+ USER.md（用户画像，上限 4000 字符）自动注入每个新会话的系统提示词
  • memory 工具：add / replace / remove / list 维护记忆条目；写入自检规则引导只存「原则 / 工作数据 / 持久事实」
  • 记忆面板 GUI：侧边栏「记忆」按钮打开面板——浏览、编辑、添加、删除两个文件，实时显示容量（N 条 · X/8000 字符）
  • 条目格式：§ 分隔，推荐 [发现]/[决策]/[偏好]/[纠正] 分类前缀
  • 容量可控：环境变量 DSH_MEMORY_CHAR_LIMIT / DSH_MEMORY_USER_CHAR_LIMIT 可调

要求 / Requirements

  • DeepSeek Harness rc.6+（dsh web）
  • Windows / macOS / Linux 通用（纯 Node ESM + 浏览器端）

安装 / Install

方式一：dsh 插件命令（推荐）

dsh plugin --profile web add github:futongxu9-maker/dsh-shared-memory

方式二：手动

  1. 把 dsh-shared-memory 目录复制到 ~/.dsh/profiles/web/node_modules/dsh-shared-memory/
  2. 在 ~/.dsh/profiles/web/cordis.patch.yml 追加：
- insert:
    - id: shared-memory
      name: 'dsh-shared-memory'
  1. 刷新页面（或重启服务）

使用 / Usage

  • 模型侧：每个会话的系统提示词自动带上 MEMORY.md + USER.md 内容；agent 用 memory 工具维护（add 新条目、replace 更新、remove 删除、list 查看用量）
  • 用户侧：点击侧边栏底部的「记忆」按钮 → 面板里查看/编辑两个文件（支持增删改、容量提示）
  • 记忆文件位置：~/.dsh/memories/MEMORY.md 与 USER.md（可直接手动编辑）

架构 / Architecture

浏览器 (Client)                              Node (Host)
┌──────────────────────────┐              ┌──────────────────────────────┐
│ @local/dsh-memory-ui     │ GET/POST     │ shared-memory.mjs            │
│ 侧边栏「记忆」按钮 + 面板  │──/api/──────▶│ · system-prompt section（注入）│
│                          │ shared-memory│ · memory 工具（model-visible）│
└──────────────────────────┘              │ · /api/shared-memory 路由    │
                                          └──────────────────────────────┘
  • Host（shared-memory.mjs）：注册系统提示词 section（注入记忆文件）、memory 工具（add/replace/remove/list + 容量自检）、HTTP API /api/shared-memory（GET 读取 / POST 写入，供 GUI 用）
  • Client（@local/dsh-memory-ui）：通过 dsh.client 协议注入侧边栏按钮 + overlay 面板，fetch 同源 API 读写记忆
