xby-epub-template-server

DeepSeek Harness (DSH) 的插件：模板搜索服务

智能模板发现助手 - 为 AI 应用提供强大的 epub360 模板搜索能力

功能

  • set_xby_apikey — 在聊天中设置 API 密钥（自动持久化，重启有效）
  • search_templates — 根据关键词搜索 epub360 模板

Args: query: 搜索关键词，例如：商务、教育、科技等 limit: 返回结果数量限制，默认10个，最多50个

Returns: JSON 格式的搜索结果

安装

方式一：从 GitHub 直接安装（推荐）

# 格式: dsh plugin --profile <profile> add github:<owner>/<repo>
dsh plugin --profile web add github:xby_skill/xby-epub-template-server

方式二：从本地目录安装（开发模式）

# 仅用于本地开发调试
dsh plugin --profile web add /absolute/path/to/xby-epub-template-server

方式三：通过 cordis.patch.yml 开发调试

dsh web --profile web --patch /absolute/path/to/dsh-ocr-plugin/cordis.patch.yml
