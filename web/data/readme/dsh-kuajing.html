dsh-kuajing

HS/HTS code lookup and classification, commercial invoices, live exchange rates, IBAN and EAN/UPC checks, amount-in-English for documents, and whether your site is actually reachable from inside mainland China.

What & why

china_reachability answers from a server that genuinely sits on a China Mobile backbone — latency, HTTP status and the IP China DNS resolves to. That is not inferable from an overseas VPS. On HS classification, be told the honest number: measured accuracy on our evaluation set is around 30%, below the 46.8% we were aiming for, so classify_hs_code returns candidates with confidence and the reasoning, and is a starting point for a broker — not a filing.

Every set ships what_can_you_do — describe a task in any language, get the exact tool plus a ready-to-run call.

Install

dsh plugin --profile <your-profile> add github:mario03690/dsh-kuajing

Thin config layer only (one @deepseek-ai/dsh-mcp-client row, shipped as cordis.patch.yml) — no tool code runs on your machine. Built against the MCP client config shape of the dsh v0.1 developer preview; verified against the live endpoint on 2026-08-22.

Cost, quota, privacy

Mixed. Lookups and validators are $0.001–$0.004. classify_hs_code is $0.05 (model-backed), make_invoice $0.01, china_reachability $0.003 (a real network probe). Failed calls are not charged.

No signup for the free anonymous quota. Documents are processed in memory and not retained. The config URL carries ?s=dsh-kuajing — a channel tag identifying the install path, not you.
