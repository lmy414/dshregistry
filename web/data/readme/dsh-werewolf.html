dsh-werewolf

English | 中文

An AI-powered Werewolf game for the DeepSeek Harness Web UI. Watch a complete AI game or join one seat as a human player.

Features

  • 6, 9, and 12-seat games.
  • AI-only spectator mode and single-human participation mode.
  • Werewolf, Seer, Witch, Villager, Guard, and Hunter roles.
  • Sheriff election, badge transfer, speeches, voting, tie-break rounds, and night actions.
  • Uses the model currently selected in DeepSeek Harness.

Install

After the first npm release, install the prebuilt package into the Web profile, then restart DSH Web:

dsh plugin --profile web add dsh-werewolf --registry=https://registry.npmjs.org/
dsh web

For local development:

pnpm install --registry=https://registry.npmjs.org/
pnpm run check
dsh plugin --profile web add .

Development

pnpm run typecheck
pnpm run test
pnpm run build
npm pack --dry-run

The Host entry is maintained in src/index.js and copied to lib/index.js during the build. TypeScript domain modules compile into lib/, and src/client/index.js is bundled into the browser entry at client/client.js.

Runtime scope

The game is process-local and currently supports one active game per DSH Web process. Its RPC channel is loopback-only. Restarting the DSH process discards the active game.
