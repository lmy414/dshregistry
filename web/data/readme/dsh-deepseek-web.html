dsh-deepseek-web

把 DeepSeek 网页版（chat.deepseek.com）当作可编程 Agent 的 DeepSeek Harness (DSH) 插件： 在 DSH 内直接列会话、读全文、发消息、创建/Fork 分享、同步归档、生成高密度摘要。

Operate chat.deepseek.com as a programmable agent from inside DeepSeek Harness.

能力 / Tools

工具 功能
deepseek_web_list 列会话（100 段历史，可按标题过滤）
deepseek_web_recent 最近 N 个会话速览（轻量）
deepseek_web_get 下载指定会话全文到本地归档
deepseek_web_chat 发消息（继续会话或新建；深度思考/联网搜索可开关）
deepseek_web_sync 增量同步新会话到本地（L0 存档）
deepseek_web_search 重建并搜索本地会话索引（需 deepseek_index.py）
deepseek_web_digest 100 会话 → 一页高密度摘要（含 token 估算，信息密度 L1 层）
deepseek_web_share_create 创建分享（可限定消息范围）
deepseek_web_share_fork Fork 别人的分享为我的会话
deepseek_web_share_list 列出我的分享

前置依赖（deepseek-ops 脚本）

本插件通过子进程调用 deepseek-ops 的 Python 脚本（deepseek_client.py / deepseek_index.py / deepseek_auth.py）， 复用其已验证的认证（扫码 + Bearer token + POW 求解）与 Cloudflare 限流保护。

  • 首次使用先跑 python deepseek_auth.py 扫码登录（生成 _deepseek_token.json）
  • 在插件配置里指定 scriptDir 指向脚本目录

安装 / Install

dsh plugin --profile web add dsh-deepseek-web

配置 / Config

- id: dsh-deepseek-web
  name: 'dsh-deepseek-web'
  config:
    pythonPath: python
    scriptDir: D:/data/BaiduSyncdisk/knowledge-lab/生产管线/scripts
    defaultThink: true
    defaultSearch: false

安全

  • Token 存本地文件（_deepseek_token.json），插件不落日志
  • 写操作（chat/share）走系统 curl 子进程，与 deepseek-ops 一致
  • 插件本身只做子进程转发，不收集任何遥测

开发 / Development

pnpm install
pnpm build     # tsc → lib/
pnpm test
