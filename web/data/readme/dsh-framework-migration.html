dsh-framework-migration

DSH（DeepSeek Harness）技能插件：框架迁移。

AngularJS→Angular（混合模式/增量组件重写/DI 与路由迁移）、React 现代化改造、依赖逐级升级策略（codemod/破坏性变更核对）、迁移风险管理（可回退/测试契约/性能基线）。受 wshobson/agents（38k★ MIT）启发的中文原创精简版。

安装

dsh plugin add dsh-framework-migration

触发方式

描述中包含"框架迁移 / AngularJS 升级 / React 现代化 / 大版本升级 / 依赖升级 / 混合模式"等关键词时自动触发。

能力

  • 三种迁移策略选型（Big Bang/增量/垂直切片）
  • AngularJS→Angular 迁移要点（ngUpgrade/DI/路由）
  • React 函数组件+Hooks 现代化
  • 依赖逐级升级与风险管理纪律
