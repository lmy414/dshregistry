dsh-notify

DSH（DeepSeek Harness）插件：当会话代理任务完成或出错时，弹出 Windows 桌面通知；远程设备（平板/手机通过 LAN 或 VPN 访问 DSH Web）则弹出浏览器通知。

功能

  • 根会话代理 running → idle 时通知「任务完成」
  • 代理出错时通知（同轮同步骤去重，最多记住 64 条）
  • /notify 命令：/notify 查看状态，/notify on|off 开关，/notify test 试弹
  • 设置页「远程通知」选项卡开关，与 /notify 共用同一个全局开关（持久化在 ~/.dsh/notify-state.json）
  • 只通知用户直接面对的根会话，子代理静默

安装

纯本地插件（不 import 任何 @deepseek-ai 包），用 link: 依赖安全：

# 假设插件放在 ~/.dsh/plugins/dsh-notify
dsh plugin --profile web add ~/.dsh/plugins/dsh-notify

或在 Cordis 组合补丁中插入一行：

- insert:
    - id: notify
      name: dsh-notify
      inject: [webServer]   # 必须：等待 webServer 服务就绪后再注册路由

改完组合后重启 dsh web。

使用

  • 桌面：任务完成/出错时弹 Windows 系统通知（WinRT 原生 Toast，带默认提示音）
  • 远程设备（浏览器）：页面自动注册 Service Worker（/dsh-notify/sw.js），通过浏览器通知弹出；首次使用浏览器会请求通知权限，若曾拒绝需在站点设置中重新开启
  • 开关：设置页 → 远程通知；或 /notify off（远程页面会在标签重新可见时同步开关状态）

兼容性

  • 桌面 Toast 依赖 Windows + WinRT
  • 开发/测试环境：DSH rc.8

测试

node test/notify-state-test.mjs

17 项离线回归（mock ctx，无需重启 dsh web）：GET/POST /dsh-notify/state 语义、持久化、参数校验、同源守卫（含跨源 403、缺 Origin 403）、405、413 上限、sw.js 内容。
